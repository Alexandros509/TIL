### 5장 SQL
#### 2.1 데이터 조회하기
DML 中 1가지 SELECT (조회)
SELECT 컬럼1, 컬럼2, ... FROM 테이블명, ... [WHERE 조건식] ;

`*` : 모든 열
SELECT * FROM 테이블명;
	1. 불필요한 데이터 > 성능 저하
	2. 테이블 구조 변경 시 예상 외 열 포함 (개인정보 등)
	3. 코드 가독성 떨어짐

SELECT [ALL | DISTINCT]
-  ALL : 기본값 ( 중복 포함한 전체 )
-  DISTINCT : 중복 없이 조회 DISTINCT

WHERE 조건식
-  조회의 범위를 좁힌다
	1. 비교 연산자 () , < , >= , =
	2. 논리 연산자 AND , OR , NOT
	3. IN : 포함여부
		- NOT IN (...) : 미포함시 TRUE
	4. BETWEEN A AND B : A에서 B 사이
	5. IS NULL : 값이 빈 상태인지 체크
		- IS NOT NULL : 값이 있는 상태인지 체크
		- =>** NULL은 값이 없는 상태이므로 비교, 산술 등의 연산이 불가**

값이 있을 때만 연산 처리 > NULL + 100 = NULL

CASE WHEN : 조건[^1]에 따른 다른 값을 부여하는 경우

~~~SQL
SELECT CASE WHEN 조건식1 THEN 결과1
			WHEN 조건식2 THEN 결과2
			
			ELSE 결과 -- 모든 조건이 거짓일 때 값
		END AS  새로운 컬럼명
FROM 테이블명
~~~

AS : 별칭 / 생략가능
-  컬럼명 뒤에 > 다른 컬럼명으로 변경
-  테이블명 뒤에

키워드 검색
- LIKE : 해당 문자열을 포함하는 값 (앞뒤 % 활용)
-  % 와일드카드
	- LIKE "키워드" : 키워드에 정확히 매칭
	- LIKE "키워드%" : 키워드로 시작하는 매칭
	- LIKE "%키워드" : 키워드로 끝나는 매칭
	- LIKE "%키워드%" : 키워드가 포함된 매칭

ORDER BY 컬럼명 [ ASC | DESC ] [, 컬럼명 ... ]
-  ASC : 오름차순 | 기본값
-  DESC : 내림차순
-  ORDER BY 컬럼명 1, 컬럼명 2 > 1차 정렬 이후 동일한 정렬  순서로 2차 정렬
	-  ORDER BY product_name ASC, list_price DESC
	-  상품명으로 오름차순 정렬 > 같은 정렬순서 > 가격을 가지고 내림차순
	**PostgreSQL / Oracle :** `NULL`을 가장 큰 값으로 취급, NULLS LAST로 수동 제어


LIMIT 조회할 행 수  [OFFSET 시작인덱스번호]
-  ORDER BY 다음으로, 제일 뒤에 
-  조회할 행의 최대 갯수
-  페이징할 때 
	- LIMIT 10 OFFEST 0; 
	- LIMIT 10 OFFEST 10;
	- LIMIT 10 OFFEST 20; 
 

#### 2.2 데이터 집계와 분석
통계 (집계)
1. 집계 함수
	1. COUNT (컬럼명 [컬럼명]) : 레코드 갯수
		- 컬럼이 NULL이 아닌 갯수
		- `*` : 전체 컬럼에 대한 레코드 갯수
	2. SUM (컬럼명) : 합계
	3. AVG (컬럼명) : 평균
	4. MIN (컬럼명) : 최소값
	5. MAX (컬럼명) : 최대값
2.  GROUP BY
	-  SELECT .. FROM .. WHERE ..GROUP BY 컬럼명 1 [,컬럼명 2 , ...]
	 1. 특정 컬럼 기준으로 그룹을 만든다 (컬럼의 동일 값 기준)
	 2. 집계 함수와 함께 쓰이는 경우가 많다
	 3. 레코드 갯수는 그룹핑된 결과 갯수만큼 조회
	 4. 조회 컬럼은 반드시 GROUP BY에 명시된 컬럼만 사용 가능
	 5. 집계 함수를 포함한 조건은 절대 WHERE 절에서 사용 불가
		-  GROUP BY __ HAVING 집계 함수 조건
3. HAVING
	-  GROUP BY 이후

#### 2.3 테이블 결합
RDBMS 관계형 데이터베이스 관리 체계
Relation 테이블 간의 관계

1.집합 - 중복 X - 행 방향 합치기
1. 합집합 : UNION - 합친 후 중복 제거
	- UNION ALL : 중복 허용, 더 빠름
2. 교집합 : 공통적인 것 INTERSECT
3. 차집합 : EXECEPT

2.JOIN - 열 방향 합치기
: 두 테이블에서 공통적인 값을 기준으로  테이블을 하나처럼 조회되도록 결합해주는 것

INNER JOIN
-  동등 조인, 내부 조인 ( **교집합** )
-  INNER 키워드는 생략 가능

OUTER JOIN
 -  외부 조인 - OUTER 생략 가능
	1. LEFT [OUTER] JOIN
	- 주 테이블 반드시 모두 출력 | 보조 테이블 있는 것만 출력
	- 매장 목록 조회를 조회하는데 주문이 있다면 주문이 출력
		 -> 주문이 있던 없던 무조건 출력 + 주문이 있다면 추가 
	2. RIGHT [OUTER] JOIN 
	-  보조 테이블 있는 것만 출력 | 주 테이블 모두 출력
	3. FULL [OUTER] JOIN
	-  전부 출력
