### 5장 SQL & 데이터베이스
#### 1.1 SQL, Data 기초
데이터 : 처리되지 않은 값(원시 값)
정보 : 데이터에 의미 부여

DBMS(DataBase Management System)
> 데이터를 관리하는 소프트웨어

문법적 규칙 SQL (Structured Query Language)
> 쿼리: 데이터베이스에 보내는 질문,질의

RDBMS (Relation) : 테이블 간의 관계
- MySQL /오픈소스
- Oracle /유료
- MSSQL /유료
- PostgreSQL /오픈소스

테이블(Table) : 데이터를 저장하기 위한 공간 (행과 열로 구성된 2차원 구조)

행 (Row/Record)
열 (Column/Field/속성)
셀 : 각각의 데이터 (주문 번호, 주문 상품)

스키마 (Schemn) : 테이블 구조와 제약 사항을 정의한 명세서

#### 1.2 데이터베이스 구조

   (동일 컬럼 동일한 자료형)

3. 참조 무결성 제약 조건

자료형 (Data Type)
1. 숫자형
   - 정수
     - SMALLINT (2byte)
     - INT (4byte)
     - BIGINT (8byte)
   - 실수
     - REAL (4byte)
     - DOUBLE PRECISION (8byte)
     - DECIMAL (p,s) p - 전체 자리수, s - 소수점 자리수
2. 문자형
   - CHAR (자리수) : 고정 사이즈 문자
   - VARCHAR (최대 자리수) : 최대 자리수 만큼의 문자 (최대를 넣지 않으면 문자 크기만큼만 공간 할당)
   - TEXT : 여러 줄 텍스트 (길이 제한 X 가변문자열)   
3. 논리형 BOOLEAN : TRUE, FALSE, NULL (1byte)
4. 날짜와 시간 
	- DATE : 날짜
	- TIME : 시간
	- TIMESTAMP : 날짜+시간
	- TIMESTAMPZ : (Zone) 날짜+시간+시간대 (기본적으로 UTC+0)
5. JSON
	- JSONB : 바이너리로 저장된다. > 속도가 빠르다
	- JSON
6. 기타
	- ENUM : 열거형 - ENUM('READY', 'ORDER', ...)
		- 주문상태
			- READY
			- ORDER
			- IN_CASH
			- DELIVERY
				
-  vector(차원수) : 나중에 벡터 DB 사용할 때 쓰는 자료형
