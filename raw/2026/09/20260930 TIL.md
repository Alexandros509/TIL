# 오늘의 TIL

## 어제의 복습
1. 다음 코드의 실행 결과로 올바른 것을 고르세요.

~~~javascript
const original = { title: "자바북", score: 90 };
const target = original;
target.score = 100;
console.log(original.score);
~~~
	- 100 
	- 객체는 참조 타입이므로 target에 original을 대입하면 동일한 객체의 메모리 주소(참조)가 복사됨
2. 배열 메서드 중 splice, push, pop처럼 원본 배열 자체를 직접 변경하는 메서드와 달리, slice, map, filter처럼 원본은 그대로 두고 새로운 배열이나 값을 반환하는 메서드를 통칭하는 용어(분류)
	-  접근자 메서드
3. 화살표 함수(Arrow Function)의 특징에 대한 설명으로 가장 올바른 것
	-  자체적인 this를 가지지 않고 선언 시점의 상위 스코프 this를 그대로 사용
4. 외부 함수의 실행이 종료되어 스택에서 제거된 뒤에도, 그 외부 함수가 반환한 내부 함수가 외부 함수의 지역 변수를 계속 참조할 수 있어 해당 변수가 메모리에서 소멸되지 않고 유지되는 현상
	-  클로저
5. call, apply, bind 메서드에 대한 설명으로 옳지 않은 것
	-  call, apply, bind 모두 함수의 this를 변경할 수 없고 인수 전달 방식만 다르다.
	-  해설 : call, apply, bind는 모두 함수 내부의 this를 개발자가 지정한 객체로 강제 바인딩하는 명시적 this 바인딩 도구입니다. 차이는 즉시 실행 여부와 인수 전달 방식(개별 나열 vs 배열 vs 지연 실행)에 있으므로, this를 변경할 수 없다는 설명은 틀렸습니다.


## 오늘의 학습

호스트 객체
-  런타임마다 다르게 구겅되어 있는 특화 개체
1. 웹브라우저 객체
	-  브라우저의 기능과 밀접하게 관련 
2.  window
	1. location 객체 : 주소창과 관련된 정보,기능 제공
		-  속성 : 실시간성 - 변경 내용이 실제 반영 (주소창에 변화)
		-  assign(이동 주소): 지정된 주소로 이동, 새 기록 추가 (방문 기록 추가), 뒤로 가기 가능
			-  location.href - 속성을 변경하면 페이지 이동
		-  replace(...) : 지정된 주소로 이동, 현재 기록 덮어쓰기(방문 기록 추가 X), 뒤로 가기 불가능
		-  reload(...) : 페이지 새로고침
	2. history 객체 : 방문 기록과 관련된 기능 제공
		-  length : 방문기록
		-  scrollRestoration
			-  auto : 스크롤 위치 기억 복구
			-  manual : 복구 X
		-  back() : 한 단계 뒤로 가기
		-  forward() : 한 단계 앞으로 가기
		-  go() : 숫자만큼 가기 (음수,양수)
	3. screen 객체 : 브라우저 사용 화면 기능 제공
	4. navigator 객체 : 브라우저 OS 사용환경, 기타 API
	5. document 객체 :  HTML 문서와 관련된 정보,기능 제공

Document 객체
1. DOM Tree : 빠른 요소 탐색에서 필요
2. 요소(DOM)을 선택하는 방법
	1. 아이디(id)로 선택
	   -  document.getElementById("아이디명");
	   -  단일 선택
	2. 클래스(class)로 선택
	   -  document.getElementsByClassName("클래스명");
	   -  복수 선택 Elements
	3. 태그 이름으로 선택
	   -  document.getElementsByTagName("태그명");
	1. name 속성명으로 선택
	   -  document.getElementsByName("Name 속성명");
	1. CSS 선택자로 선택
	   -  document.querySelector("CSS 선택자"); -> 첫 번째 요소 1개 선택
	   -  document.querySelectorAll("CSS 선택자"); -> 복수개 선택
	1. 문서 전체 (html)
	   -  window.document
		   - head - window.document.head
		   - body - window.document.body
	1. 양식 (form) 이름 - frmNIDLogin
	   -  양식 하위 입력 태그는 이름으로 바로 접근
		   - 예시) frmNIDLogin.id
	1. 요소 노드 (상대적 접근)
		-  parentElement : 부모 요소
		-  childrenElement : 자식 요소
		-  firstElementchild : 첫 번째 자식
		-  lastElementchild : 마지막 자식
		-  nextElementsibling : 다음 형제 요소
		-  previousElementsibling : 이전 형제 요소


요소의 추가 정보
 - 속성 (Attribute)
   1. document.getAttribute("속성명") : 속성 조회
   2. document.setAttribute("속성명","속성값") : 속성 추가/변경
   3. document.removeAttribute("속성명") : 속성 제거
   4. document.hasAttribute("속성명") : 속성의 존재 여부
   5. 많이 쓰는 속성은 바로 접근 가능
      - id, type, src, href, target, action ...
      -  className, style
