### Flexbox (1차원 정렬)

- 설정 - 부모요소
  - `:display:flex;`
- 적용 - 자식요소
- 정렬 방향
  - `flex-direction`
    - `row`(기본값) : 좌 → 우
    - `row-reverse` : 우 → 좌
    - `column` : 위 → 아래
    - `column-reverse` : 아래 → 위
- 정렬 속성 제어
  - `justify-content`
    1. `flex-start` : 왼쪽 정렬 (기본값)
    2. `flex-end` : 오른쪽
    3. `center` : 가운데
    4. `space-between` : 좌우 요소 1개를 끝에 배치 , 나머지 요소 공백 균등 부여
    5. `space-around` : 각 요소 주위 동일 공백 부여
    6. `space-evenly` : 공평하게
- `align-items` : 자식 요소들의 위치배치
  - `stretch` (기본값) : 부모 요소의 크기에 맞춰 늘리는 것
  - `flex-start` : 위쪽 배치
  - `flex-end` : 아래쪽 배치
  - `center` : 가운데 배치

`flex-grow`
1. 자식 요소 적용
2. 남아있는 공백을 차지할 비율 설정

`flex-shrink`
1. 부모 요소의 공간이 부족할 때 자식 요소의 크기 줄임 비율
2. 비율 가중치
3.  0 : 요소를 축소 X
4. `flex-basis` : 요소의 기본 사이즈
	-  auto (default)
	-  px, %

`flex-wrap`  
- wrap 부모 요소의 너비가 부족하면 다음 칸에 개행
- nowrap (default) : 개행 X


CSS Grid (2차원 격자 레이아웃)
`grid-template-columns` (열 정의)
1. 픽셀(px) 단위 지정
	-  grid-template-columns: 150px 150px 300px;
	-  열 3개 생성 : 1번째 열 150px, 2번째 열 150px, 3번째 열 300px
2.  fr (Fraction) 단위 사용
	-  fr: 남은 공간에 대한 비율
	-  grid-template-columns: 150px 1fr 2fr;
	-  첫 번째 열 150px 고정
	-  두 번째 열 150px 제외 남은 공간의 1/3
	-  세 번째 열 150px 제외 남은 공간의 2/3
3. repeat(컬럼갯수 , 사이즈)
	-  같은 사이즈의 지정된 컬럼개수만큼 설정

`gap` (격자 여백 설정)
-  row-gap : 행별 여백
-  column-gap : 열별 여백
-  gap : 20px 10px; 행 열
-  gap : 30px; 행열 모두

`grid-column`
1. grid-column: 1/3;
	-  1번~3번열까지, 2칸
2. grid-column: span 2;
	-  열의 2칸 차지

`grid-row`
1. grid-row: 1/3;
2. grid-row: span 2
	-  2개 행 차지

`place-items`
-  stretch (default)
-  start : 왼쪽 상단
-  end : 우측 하단
-  center : 정가운데

`background`
1. background-color
2. background-image : url("이미지 경로")
3. background-repeat 
	-  repeat (default) : x,y축 모두 
	-  repeat-x : x축

	-  no-repeat : 하나만 출력
4. background-position 
	-  배경이미지 위치 설정
	-  ex) background-position : 100px 50px; (좌에서 우로 100px, 위에서 아래로 50px)

	-  background-size : 가로 세로;

	-  background-contain : contain; (이미지 모두 보이게 채움, 요소 비율이 다르면 상하좌우에 여백이 생김)

	-  background-attachment : scroll; (스크롤 시 배경 이미지도 함께 스스로)
	-  background-attachment : local;
-  단축 표현법
	-  background : 색상 이미지 반복 고정 위치 사이즈; (색상 이미지 적어도 하나는 정의해야함, 뒤는 선택)
	-  background: [color] [image] [repeat] [attachment] [position / size];

`position`
-  위치(배치)
-  static (default)
-  절대 위치 - absolute,fixed
-  상대 위치 
	- relative
-  층위 설정 가능 - z-index
	-  static 제외
	-  값 ↑ 앞쪽 배치
	-  값 ↓ 뒤쪽 배치

| **속성값**    | **기준점**                                | **핵심 특징**                        |
| ---------- | -------------------------------------- | -------------------------------- |
| `static`   | 없음                                     | 기본 순서 배치, 좌표(`top` / `left`) 미적용 |
| `relative` | 본인 원래 자리                               | 원래 공간 유지한 채 미세 이동                |
| `absolute` | `position ≠ static`인 최근접 조상, 없으면 문서 전체 | 흐름 이탈, 조상 기준 절대 좌표               |
| `fixed`    | Viewport (`transform` 조상 있으면 그 조상)     | 흐름 이탈, 스크롤 무관 화면 고정              |
| `sticky`   | 최근접 스크롤 컨테이너 + 임계점                     | 평소 `relative` → 임계점에서 컨테이너 안 고정  |

| **선택자** | **대상** | **메모** |
| --- | --- | --- |
| `.a, .b` | 자체가 `.a`이거나 `.b` | 선언 복제. 콤마는 OR |
| `.a .b` | `.a` 안의 자손 `.b` | 공백 = 자손 |
| `.a > .b` | `.a`의 직계 자식 `.b` | `>` = 한 단계만 |
| `.a.b` | 한 요소가 `.a`이면서 `.b` | 붙여 쓰면 AND |
| `:is(.a, .b)` | 자체가 `.a`이거나 `.b` | `.a, .b`와 매칭 동일. 묶기용 |
| `:is(.a, .b) .x` | `.a` 또는 `.b` 안의 자손 `.x` | 부모 OR + 자손 |
| `:is(.a, .b) > .x` | `.a` 또는 `.b`의 직계 자식 `.x` | 부모 OR + 자식 |
| `:where(.a, .b)` | `:is()`와 대상 같음 | 명시도 **0** |
| `:where(.a, .b) .x` | `.a` 또는 `.b` 안의 자손 `.x` | 매칭은 `:is`와 같고 특이도만 0 |
| `:has(.x)` | 자손 `.x`를 **가진** 요소 | 부모 방향으로 조건 |
| `.a:has(.x)` | 자손 `.x`를 가진 `.a` | “이런 자식을 둔 `.a`” |
| `:is(.a, .b):has(.x)` | 자손 `.x`를 가진 `.a` 또는 `.b` | OR 부모 + 자식 존재 |
| `:has(> .x)` | 직계 자식 `.x`를 가진 요소 | 한 단계만 검사 |


## 찾아본 내용

1.  `list-style`

	`<ul>` / `<ol>` 항목 앞 **불릿·번호**를 한 번에 정하는 단축 속성.
	
	~~~css
	list-style: <type> || <position> || <image>;
	~~~
	
	| 조각 | 역할 | 예 |
	| --- | --- | --- |
	| `list-style-type` | 기호·번호 | `disc` · `circle` · `square` · `decimal` · `none` |
	| `list-style-position` | 박스 안/밖 | `outside`(기본) · `inside` |
	| `list-style-image` | 기호 대신 이미지 | `url(...)` · `none` |
	
	~~~css
	ul { list-style: none; }           /* 불릿 제거 후 직접 디자인 */
	ol { list-style-type: decimal; }   /* 번호 목록 */
	~~~
	
	- `none` = 기호만 제거. 들여쓰기는 그대로 → 보통 `padding-left: 0`과 같이 씀
	- 교재(`FE_04`)에 전용 단원 없음. 실습만 `.task-list li { list-style: none; }`로 불릿을 끄고 카드형 UI
	- `color`는 불릿 색에도 적용될 수 있음
