## 오늘의 학습
동시성 제어 기법
1. 비관적 락
	-  SELECT ... FOR UPDATE
		-  수정이 완료되면 잠금 해제
		-  성능 저하 가능성
		-  강한 잠금
2. 낙관적 락
	-  테이블 구성
		-  테이블의 구조가 수정이 되면 증가시킴
3.  **원자적 조건부 갱신** (Conditional UPDATE)
    조건을 UPDATE 한 문장에 넣어서, 별도 읽기/버전 비교 없이 선점 여부를 판정.
4. **외부 분산락** (Redis)  
    DB 밖에 락 저장소를 두고, 여러 인스턴스 사이 순서를 조정.


RLS ( Row Level Security)
-  CRUD
	-  회원의 권한을 체크 (DB) (SELECT ,INSERT ,UPDATE, DELETE)
