#### 4.2 JavaScript 기초 문법
5. 기본 연산자
	1. 산술 및 복합 대입 연산자
		-  증가 감소 연산자 ( ++, -- )
			-  ++ : 1씩 증가
			-  -- : 1씩 감소
			-  전위(`++n`)는 더하고 대입, 후위(`n++`)는 대입하고 더함
	2. 엄격한 일치 연산자
		-  동등성 비교 vs 동일성 비교
			-  동등성 비교 : ==
			-  동일성 비교 : ===
			-  ! → 부정연산 (참→거짓,거짓→참)
			-  != → 다르다
			-  !== → 주소가 다르다
			-  `!=`는 타입 변환 후 값만 다르면 참, `!==`는 타입이나 값 중 하나라도 다르면 참
	3. 논리 연산자
		-  && : AND 연산자
		-  || : OR 연산자
		-  ! : NOT 연산자 (부정연산)
6. 제어문
	1. 조건문 (if,if-else,if-else if - else)
		-  조건식 : 참, 거짓을 판별하는 연산 식(비교, 논리연산이 주로 쓰인다)
		-  
		  ~~~JavaScript
		  if (조건식) {
			  // 조건식 참일때 실행되는 구간
		  }
		  
		  if (조건식) {
			  // 조건식 참일때 실행되는 구간
		  } else if (...) {
			  ...
		  } else if (...) {
			  ...
		  } else { // 모든 조건이 거짓일때 실행되는 구간
			  ...
		  }
		  ~~~

		-  **삼항 조건식**
			-  `변수 =  (조건식) ? 참일때 실행되는 코드 값 : 거짓일 때 실행되는 코드나 값;`
		-  값이 없을 때의 기본값 입력 (Short-circuit Evaluation 활용)
			- name = name || "게스트"; console.log(`안녕하세요, ${name}님!`);
			- greet(); // "안녕하세요, 게스트님!"
			- `||` 연산자는 모든  Falsy값을 거짓으로 판단해 기본값으로 덮어쓰는 문제점 있음
		-  ?? : nullish 연산자
			-  null, undefined일때만 판단
		-  && : 단락회로평가를 이용한 간단한 조건식 수행
			-  message && console.log(message);
			-  `&&`는 앞이 참일 때만 뒤의 식을 실행하므로, `if (message)`를 대신하는 간결한 조건부 실행문 역할
	2. 선택문 (switch-case)
		-  **폴스루(Fall-through)** 현상
			-  일치하는 case 지점부터 `break`가 나올 때까지 **연속 실행**
		-  break : 실행 흐름 중단
		-  default:
	3. 반복문 (for, while, do-while)
		1. `for (초기화식; 조건식; 증감식) { // 실행할 코드 }`
		-  순서의 의미가 강한 반복문은 관례적으로 변수명을 i (index)
		-  다음 변수명은 알파벳 순서 (j,k,l,m,...)
		-  for (let i = 0, j=10;i <10;i++,j--){console.log("i=",i,"j=",j);}
			1. 초기화식 
				-  반복문 시작 시 최초 1회 실행
				-  카운터 변수의 시작값을 설정하는 식
			2. 조건식
				-  매 반복 전에 조건 검사하여 참이면 블록 내부 실행, 거짓이면 루프 종료
			3. 증감식
				-  조건을 멈추기 위한 숫자 증가 감소 식
				-  반복 변수를 변화시켜 언젠가 조건식을 만족하지 않게(종료되게) 만드는 식
		-  break : 반복 중단
		-  continue : 반복 건너뛰기
		2. while
			- `while(조건식) {//조건식이 참일때 반복되는 구간 //반복을 중단시키는 코드가 있어야한다 - break와 함께 쓰인다}`  
		3. do while 
			-  `do {//조건식이 참일때 반복되는 구간} while(조건식);`
				-  조건식이 거짓이더라도 한번 실행을 보장
	
		~~~JavsScript
		// 단보다 곱하는 수가 클때만 출력하세요
		for (let i = 2; i <= 9; i++) {
		    console.log(`-------${i}단--------`);
		    for (let j = 1; j <= 9; j++) {
		        if (j > i) {
		            console.log(i, "*", j, "=", i * j);
		        }
		    }
		}
		
		for (let i = 2; i <= 9; i++) {
		    console.log(`--------- ${i}단 ---------`);
		    for (let j = i + 1; j <= 9; j++) { // 2단이면 j=3부터 시작
		        console.log(`${i} X ${j} = ${i * j}`);
		    }
		}
		
		for (let i = 2; i <= 9; i++) {
		    console.log(`-------${i}단--------`);
		    for (let j = 1; j <= 9; j++) {
		        if (i >= j) {
		            continue // 반복 건너뛰기
		        }
		        console.log(i, "*", j, "=", i * j);
		    }
		}
		
		~~~

7. 예외 처리 (try - catch - finally)
   -  `try {//예외가 발생할 가능성이 있는 코드} catch(err) {//예외가 발생하면 유입되는 구간 - 대외적인 처리,err: 발생할 예외에 대한 정보}`
   -  throw : 예외 발생 시키기 / throw new 예외 객체(Error의 하위 생성자 객체)
   -  new 연산자
   -  JavaScript stack = Python Traceback
		~~~JavaScript
		try {
		    let str;
		    const str2= str.toUpperCase();
		    console.log(str2,"대문자 변경 완료");
		} catch (err) {
		    console.dir(err);
		    console.error(err);
		}
		
		try {
		    let str;
		    const str2= str.toUpperCase();
		    console.log(str2,"대문자 변경 완료");
		} catch (err) {
		    //console.dir(err);
		    //console.error(err);
		    console.log(err.message,err.name);
		} finally {
		    console.log("무조건 실행");
		}    
		~~~
