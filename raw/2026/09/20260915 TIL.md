##### 7.1.2 하이퍼링크, 멀티미디어 및 폼 태그

하이퍼링크 : 페이지 이동

1. 양식 (Form) 태그
    - **action** : 제출 처리 URL, 서버 URL
    - **method** : 전송 방식
        - **GET** (기본값) : 자원조회/ 검색, 전송할 데이터는 URL에 포함 <ruby>_?이름=값&이름=값<rt style="font-size: 0.66em;">쿼리 스트링 (QueryString)</rt></ruby> 
	        -  쿼리 스트링 (Query String) :  웹 브라우저 등 클라이언트가 서버로 데이터를 전달할 때 URL 끝에 물음표(`?`)와 함께 붙이는 `키=값` 형태의 문자열
        - **POST** : 서버에 변경을 가하는 요청, 요청 전문의 body에 실려 전송
        - 추후 설명 예정
    - **target** : _self, _parent, _top, _blank
    1. **input** : 입력을 위한 태그
        - **type** : 입력 유형
            -  **text** (기본값)
            -  **password** - 비밀번호
            -  **radio** - 여러 개 중 1개 선택, name 값 동일하게 묶어야함
            -  **checkbox** - 여러 개 중 여러 개 선택
            -  **submit** - 약식 제출, **reset** - 입력 항목 초기화, **button** - 일반 버튼
            -  **email**
            -  **number**
            -  **color**
            -  **range**
            -  **date**
            -  **time**
            -  **datetime**
        - **name**
            1. **전송할 값의 이름**
            2. radio, checkbox의 그룹 명칭
        - **value**
            1. 입력 값
            2. `type="text" | "password" |"number"` : 사용자가 입력 → 값이 할당
        -  **required** : 필수 입력 항목
            - min
            - max
            - step
        -  **placeholder** : 안내 문구
        -  **readonly** : 읽기 전용 (**데이터 전송 O**)
        -  **disabled** : 기능 무력화 (**데이터 전송 X**)
    2. **button**
        - **type**
            - **submit** : 양식 제출
            - **reset** : 양식 입력 취소
            - **button** → 일반 버튼
        -  **`<button>버튼명</button>`**
    3. 태그와 입력 요소를 연결
         1. 입력 요소를 <ruby>태그<rt style="font-size: 0.66em;">주로 label</rt></ruby>로 감싼다
         2. <ruby>for<rt style="font-size: 0.66em;">label</rt></ruby>  <ruby>id<rt style="font-size: 0.66em;">입력요소</rt></ruby>
    4. textarea : 여러 줄 텍스트 입력
    5. select : 여러 개 중 한 개 또는 여러 개
		-  option : 선택항목
			-  selected : 기본값 선택 
		-  multiple : 여러 개 선택
		-  size : 한 번에 보일 개수

2. HTTP 전문 구조 (판서)

**요청 전문** (Request Message, 클라이언트 → 서버)

- **헤더 (`Header`)**: 요청 쪽 정보 (메서드, 브라우저, 데이터 타입)
  - Network **Request headers**
  - 예: `Content-Type: application/x-www-form-urlencoded`
- **바디 (`Body`)**: 전송할 실제 데이터
  - Network **Payload (Form Data)**

**응답 전문** (Response Message, 서버 → 클라이언트)

- **헤더 (`Header`)**: 응답 정보·상태 (상태 코드, 서버 환경, 응답 타입)
  - Network **Response headers**, `Status Code: 200 OK`
- **바디 (`Body`)**: 서버가 돌려준 데이터 (HTML, JSON 등)
  - Network **Response** 탭, 화면에 렌더링된 `회원 가입 처리 완료....`


###### 7.1.2.5 HTML 태그 레퍼런스

1. 리스트

항목 나열, 메뉴·네비게이션

| 태그 | 의미 | 역할 | 활용 |
| --- | --- | --- | --- |
| `<ul>` | Unordered List | 순서 없는 목록, 앞 점(•) | 상단 메뉴, 카테고리 |
| `<ol>` | Ordered List | 순서 있는 목록, 1, 2, 3… | 레시피, 순위 |
| `<li>` | List Item | `<ul>` / `<ol>` 안 개별 항목 | 실제 항목 |
| `<dl>` | Description List | 용어+설명 세트 | 사전, 사양 |
| `<dt>` | Description Term | `<dl>` 안 용어(제목) | 상품명, Q |
| `<dd>` | Description Details | `<dl>` 안 설명(본문) | 상세, A |

~~~html
<ul>
	<li>HTML5 공부하기</li>
	<li>CSS3 공부하기</li>
</ul>

<dl>
	<dt>HTML</dt>
	<dd>웹 페이지의 구조와 뼈대를 만드는 마크업 언어입니다.</dd>
</dl>
~~~

2. 테이블

행·열 격자

| 태그 | 의미 | 역할 | 위계 |
| --- | --- | --- | --- |
| `<table>` | Table | 표 전체 | 최상위 |
| `<thead>` | Table Head | 제목 행 그룹 | `<table>` 상단 |
| `<tbody>` | Table Body | 본문 행 그룹 | `<table>` 중단 |
| `<tfoot>` | Table Footer | 요약·합계 행 | `<table>` 하단 |
| `<tr>` | Table Row | 한 줄(행) | `<thead>` / `<tbody>` 안 |
| `<th>` | Table Header | 열 제목 칸, 굵게·가운데 | `<tr>` 제목 |
| `<td>` | Table Data | 데이터 칸 | `<tr>` 본문 |

	<thead>
		<tr>
			<th>이름</th>

	<tbody>

		</tr>
	</tbody>

##### 7.1.3 HTML5 시멘틱 태그의 구조화

시멘틱 태그 : 이름만 봐도 의미, 역할 명확히 알 수 있게 만든 태그
 -  Semantic : 의미
 -  `<table>,<video>, ...`
 -  필요한 이유
	 1. 검색엔진 최적화
	 2. 웹 접근성
	 3. 코드 가독성 향상

레이아웃을 구성하는 태그
1. `<header>` : 상단 공통 영역
2. `<footer>` : 하단 공통 영역
3. `<main>` : 본문
4. `<section>` :  내용 구분
5. `<article>` : 섹션별 내용
6. `<nav>` : 주 메뉴
7. `<aside>` : 좌우 영역


~~~HTML
            성별 <!-- 태그로 입력 요소 감쌈 -->
                <label>
                    <input type="radio" name="gender" value="FEMALE"> 여성
                </label>

                <label>
                    <input type="radio" name="gender" value="MALE"> 남성 <br>
                </label>

            취미 <!-- for id -->
                <input type="checkbox" name="hobby" value="reading" id="hobby_reading">
                <label for="hobby_reading">독서</label>

                <input type="checkbox" name="hobby" value="study" id="hobby_study">
                <label for="hobby_study">공부</label>			
~~~



#### 7.2 CSS를 활용한 웹 스타일링 및 기본 레이아웃

##### 7.2.1 CSS 기초와 스타일링 문법

CSS ( Cascading Style Sheets ) [14일 Cascading](<20260914 TIL.md#찾아본 내용>)
-  웹 문서에 스타일링 담당
1. 스타일 적용 기본 구조
	-  선택자 ( selector ){ 속성 : 값 }
	-  스타일 속성 : color, background, width, height , ...
2. 적용방법
	1. 인라인 스타일
		-  태그의 style 속성에 직접 적용
	2. 내부 스타일 시트
		-  `<style> ... </style>` 태그 안에 스타일을 정의 방법
	3. 외부 스타일 시트
		-  CSS 파일을 생성하고 연동 (`<link rel="stylesheet" href="./style.css">`)
3.  주석
	-  /`*`설명 `*`/
	-  설명 / 해석 배제
4. 선택자 (selector)
	1. 기본 선택자
		1. 전체 선택자 (`*`)
		2. 태그 선택자 (태그 이름)
		3. 클래스 선택자( .클래스명 )
			-  여러 개 요소 선택, 복수 선택 가능, 여러 개 이름 지정( 클래스 )
		4. 아이디 선택자 ( `#아이디명` )
			-  아이디 명은 하나만 지정 가능, 유일한 이름으로 지정 ( 아이디 ), 1개 만을 선택하는 속성
	2. 복합 관계 선택자
		1. 하위 선택자 (조상-자손)
			-  하위 : 자손
			-  정렬 순서 : 조상 ... 자손
		2. 자식 선택자 (부모>자식)
			-  부모 : 바로 위 요소
			-  자식 : 바로 아래 요소
		3. 일반 형제 선택자 (형~동생)
			-  형 : 기준
			-  동생 : 기준 아래에 정의된 요소
		4. 인접 형제 선택자 (형+동생)
			-  형 : 기준
			-  동생 : 기준 바로 아래 요소 1개
5. 스타일 적용 우선 순위
	-  범위가 넓을 수록 ↓, 좁을 수록 ↑
	-  태그 선택자 < 클랙스 선택자 < 아이디 선택자 < style 속성
	-  가장 많이 사용 : 태그 (공통 스타일), 클래스 (세부 스타일)
	-  참고) 우선순위 강제 적용 - !important 남용 주의!

## 옵시디언 텍스트 밑줄 및 주석/설명 표기법

### 1. 상시 노출 (커서 호버 불필요)

**단어 바로 위 주석 (루비 태그)**

일본어 후리가나 태그를 활용해 텍스트 바로 위에 작은 폰트로 주석을 띄운다.

~~~html
<ruby><u>밑줄 친 단어</u><rt>상시 표시될 설명</rt></ruby>
~~~

**단어 옆 인라인 주석**

`<small>` 태그나 기호로 본문 옆에 작은 글씨를 둔다.

~~~html
<u>밑줄 친 단어</u> <small>(※ 한 줄 설명 내용)</small>
~~~

**단어 바로 아래 (인라인 블록)**

CSS 인라인 스타일과 `<br>`로 하단에 주석을 고정한다.

~~~html
<span style="display:inline-block; vertical-align:top;">
<u>밑줄 친 단어</u><br>
<span style="font-size: 0.75em; color: gray;">└ 여기에 한 줄 설명</span>
</span>
~~~

**강조 블록 (옵시디언 Callout)**

개념 단위의 긴 메모를 박스로 상시 노출할 때 쓴다.

~~~md
> [!note] <u>밑줄 친 핵심 개념</u>
> 여기에 상시 노출할 핵심 설명을 작성합니다.
~~~

### 2. 숨김 / 호버 / 각주

**기본 각주 (문서 최하단)**

클릭하면 하단으로 가거나, 호버 팝업으로 미리볼 수 있다.

~~~md
이 문장에서 <u>강조할 키워드</u>[^1]에 밑줄을 긋습니다.

[^1]: 여기에 밑줄 친 키워드에 대한 한 줄 설명을 작성합니다.
~~~

**마우스 호버 툴팁**

`<abbr>`의 `title`로 올렸을 때만 보이게 한다.

~~~html
<u><abbr title="여기에 표시할 한 줄 설명을 적습니다">설명할 텍스트</abbr></u>
~~~

**편집 모드 전용 메모 (읽기 뷰 숨김)**

읽기 뷰에서는 숨고, 작성·수정 중에만 보인다.

~~~md
<u>밑줄 친 텍스트</u> %% 여기에만 보이는 한 줄 메모 %%
~~~
