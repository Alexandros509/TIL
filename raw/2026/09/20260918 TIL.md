## 오늘의 학습

~~~css
<meta name="viewport" content="width=device-width,initial-scale=1,minimum-scale=1,maximum-scale=1,user-scalable=no,interactive-widget=resizes-content">
~~~

뷰포트 (Viewport) : 보이는 화면
width
-  device-width
-  device-height
user-scalable 
-  : yes - 확대, 축소 가능
	-  minimum-scale : 축소 비율
	-  maximum-scale : 확대 비율
	-  initial-scale : 처음 화면 비율
-  : no - 불가

브레이크 포인트
 -  화면 레이아웃이 전환되는 기준 해상도
 -  CSS 적용이 달라짐
	- 모바일 ( ~767px)
	- 태블릿 ( 768px ~ 1023px )
	- 데스크탑 ( 1024px~ )


미디어쿼리 `@media`
-  `@media 미디어타입 and (미디어특성) {}`
-  미디어타입
	-  all (default)
	-  screen
	-  print : 인쇄 CSS
	-  speech : 시각 장애인용 스크린 리더 CSS
-  미디어특성
	-  width / height
	-  min-width : 화면이 크기 이상 On
	-  max-width : 화면이 크기 이하 On
	-  orientation : 기기 화면 방향
		-  portrait : 세로
		-  landscape : 가로
