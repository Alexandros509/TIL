CVS, SVN > 변경 사항 기록 > 계산 > 복구  
git > 파일 그대로 기록 (snapshot)  
 - working directory > 버전관리 영향을 받는 경로  
  
1. git init  
cmd make directory 줄여서 mkdir (폴더 생성)
2. 스테이징 단계  
git add filename  
git add . (변경사항 모두)  
3. commit 단계  
버전이 실제 기록되는 단계  
git commit -m "메세지"
4. 기록 확인  
hashID로 이동 복구 가능  
git log  
git log --oneline (한줄로)  
git log --graph (시각적 흐름)  
git log --branches  
git log --decorate  
git log --all  
git log -n갯수  
5. 시점 변경  
git checkout commitID (그 시점)
