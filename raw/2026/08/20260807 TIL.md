 #### 2.2.1 Python의 기본 자료형 (Primitive Data Types)
  - 자료 : 연산에 필요한 값(데이터)
  - 자료형 : 값의 유형(데이터의 종류)
   1) **수치형** : 정수(int) 와 실수(float) 
   2) **문자형** : 문자열(str)
      - '',"" 감싸서 선언(한줄), """...""" 여러 줄 문장
   3) **논리형** : 불리언(bool) - 참(True) & 거짓(False)
     - 참(True) : 0 아닌 숫자, 글자 포함 문자열, 채워진 리스트
     - 거짓(False) : 0, 빈 문자열 "", 빈 리스트 [], 데이터 없음 None
   4) **값 없음** : None  

#### 2.2.2 명시적 형변환 (Explicit Type Conversion)
  - **외부 데이터 문자열 형태로 입고, 개발자가 직접 타입 변경 like 포장**
  - 연산은 같은 자료형끼리 가능
  - 형변환 함수
   1. `int()` : 정수로 변환
   2. `float()` : 실수로 변환
   3. `bool()` : True,False로 변환
   4. `str()` : 문자형으로 변환
```
num ="100"
type(num) > str

num+200 
> TypeError
-----------
num ="100"
type(num) > str

int(num)+200 > 300
-----------
"현재 시간은" + 10 + "시" 
> TypeError
"현재 시간은" + str(10) + "시" 
> '현재 시간은10시'
```
#### 2.2.3 묵시적 형변환 (Implicit Type Conversion)
 - 내부에서 자동 변환
   1. 정수+-x/실수 
   2. float upcasting
```
num1=100
num2=3.123
```

### 2.3 연산자
#### 2.3.1 항과 연산자
  - 항 : 연산에 사용되는 값, 변수  
  - 연산자 : 연산에 사용되는 기호  
   1. 사칙연산 및 특수 산술 연산자  
    0. 대입 연산자 : `=` 연산 우선 순위 최하위. 가장 마지막에 연산  
    1. 사칙연산 : `+` , `-` , `*` , `/`  
    2. 몫 연산자 : `//` 몫만 추출, 반환  ex) 10//3 = 3  
    3. 나머지 연산자 : `%` 나머지만 반환  ex) 10%3 = 1  
    4. 거듭제곱 연산자 : `**` 제곱 ex) 2**3 = 8(2^3)  
    - 연산 우선순위: `**` , `*` , `/` , `//` , `%` > `+` , `-`   
    - 우선 순위 강제 적용 : ()
  
   2. 복합 대입 연산자  
    - 코드 단축  
      x= x+10 -> x+=10  
    - 주요 연산자 종류   
      `+=` , `-=` , `*=` , `/=` , `//=` , `%=` , `**=`

   3. 비교 연산자  
    - 연산의 결과는 무조건 True, False  
    - 판별이 필요한 구문 (조건문, 반복문)  
    - 문자열 비교 식별은 알파벳순 정렬  
      `>` , `<` , `>=` , `<=`  
      `==` : 같다  
      `!=` : 다르다

      **동등성 vs 동일성**  
      - 동등성 : 동일한 가치를 비교(==)
      - 동일성 : 동일한 대상인지 비교 (is - 주소 비교)
        ```
        num1=1000
        num2=1000

        id(num1), id(num2)
        > (2394777249744, 2394777249584)   # diff!

        num1==num2 #동등성 비교
        >True

        num1 is num2 #동일성 비교(주소 비교)
        >False
        ```

   4. 논리 연산자  
    - 여러 개의 조건을 연산자로 묶어서 하나의 최종 판단을 내리는 조건 결합기  
     1. `and` : 각 항이 모두 True -> True, 하나라도 False -> False - `논리곱`  
     2. `or` : 각 항의 하나라도 True -> True, 모두 False -> False - `논리합`  
     3. `not` : True 조건 -> False 조건으로 반전, False 조건 -> True 조건으로 반전 - `논리부정`  
   
   5. 부호 반전 연산자  
    - 숫자의 부호를 반대로 변경하는 단항 연산자  
   
   6. 단락 회로 평가 (Shor-Circuit Evaluation)  
    - 논리 연산의 결과가 확정되면 이후 조건을 검사하지 않는 평가 방식

    ```
    result = True or 10**2
    result
    >True

    result=False or 10**2
    result
    >100
    ```
   7. 연산자 우선순위  
        대입 연산자 < 논리 연산자 < 비교 연산자 < 산술 연산자

### 2.4 문자열 형식화
#### 2.4.1 문자열 형식화 3가지 기법
 1. 1세대 : %연산자 방식  
  - % 연산자를 사용해 값을 문자열에 삽입하는 방식  
    1. `%s` : 문자열  
    - %숫자s -> 숫자 자리수 만큼 공간 확보, 우측 정렬 , 남는 공간 공백  
    - %대체문자s -> %05s -> 남는 공백 0으로 대체  
    2. `%d` : 정수  
    3. `%f` : 실수  
     - %.숫자f -> 소수점 숫자까지만큼 소수점 표기 
     - %A.Bf -> 정수부 A , 소수점 B까지 표기
     ```
     print("기본 출력: %s, %d" % ("홍길동", 20))
     print("너비 지정 (5칸 우측 정렬): [%5d]" % 123)
     print("소수점 지정 (소수점 둘째 자리): %.2f" % 3.14159)
     ```
 2. 2세대 : str.format() 메서드 방식
  - {}에 인덱스나 이름을 지정해 값을 삽입, % 방식보다 유연하고 사용이 편리하다
  - 변수 많아지면 복잡  
  - 순서 지정 교체 : {0} {1} {2}  
    단어 지정 교체 : {단어} {단어}
    ```
    message = "내 이름은 {0}이고, 나이는 {1}입니다"
    message.format("철수",20)
    > '내 이름은 철수이고, 나이는 20입니다'

        message = "내 이름은 {name}, 나이는 {age}이다."
    message.format(name="철수",age="20")
    > '내 이름은 철수, 나이는 20이다.'

        message = "내 이름은 {name}, 나이는 {0}이다."
    message.format(20, name="철수")
    '내 이름은 철수, 나이는 20이다.'
    ```

 3. 3세대 : f-string 방식
  - 문자열 앞에 f를 붙여 변수나 표현식을 직접 삽입하는 방식
  - 서식 지정 : 콜론(:) 뒤에 지시자를 사용해 출력 형식을 지정하는 기능
  - 디버깅 조절자(=): 변수명 뒤에 =를 붙여 변수명과 값을 함께 출력, 로그 확인과 디버깅에 유용
    ```
    name="영희"
    age=20

    message = f"내 이름은 {name}, 나이는 {age}이다."
    message
    > '내 이름은 영희, 나이는 20이다.'

    price=10000
    f"가격 : {price:,}"
    > '가격 : 10,000'

    price=10000
    f"가격 : {price:>10,}원"
    > '가격 :     10,000원'
    ```
