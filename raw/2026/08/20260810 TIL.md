#### 3.1.1 순차 자료구조 리스트와 튜플
 - 순서가 잇는 데이터 군집
 1. 인덱스 연산자 : [순서번호], 데이터의 위치를 계산, 0번부터 시작 
 2. 리스트 (List) : 변경 가능 , [1,2,...], 
    추가 (Create) - `append(요소)` : 끝에 추가
                 - `insert(추가위치, 요소)` : 해당 위치에 추가
                 - `extend(콜렉션 - 리스트,튜플)` : 원본 리스트 끝에 여러 개 추가
                 - `[기존 리스트]+[값1,값2,...]` : 끝에 여러 개 추가하고 새로운 리스트 생성
    조회 (Read) - 인덱스 번호로 접근 (fruits1[1])
                - `index(요소)` : 특정 요소의 인덱스 번호
    수정 (Update) - 인덱스 번호로 접근 , 다른 값을 대입 (fruits1[1] =''오렌지'')
    삭제 (Delete) - `remove(요소)` : 첫번째 발견한 특정 요소 제거
                  - `clear()` : 리스트의 모든 요소 제거 
    기타 - `sort()` : 정렬(오름차순), `sort(reverse=True)` : 내림차순
     - `reverse()` : 순서 반전
     - `count()` : 특정 요소의 등장 횟수
    ```
    fruits = ['Apple', 'Orange', 'Banana']
    fruits1 = fruits[1]
    fruits1
    > 'Orange'

    fruits1 = "오렌지"
    fruits
    > ['Apple', '오렌지', 'Banana']

    fruits.append("Melon")
    fruits_copy = fruits
    fruits_copy
    > ['Apple', '오렌지', 'Banana', 'Melon']

    fruits_copy[1] = 'Orange' 
    > ['Apple', 'Orange', 'Banana', 'Melon']

    fruits.extend(["Cherry, "Water Melon"])
    fruits
    > ['Apple', 'Orange', 'Banana', 'Cherry', 'Water Melon']

    fruits = ['Apple']
    fruits + ['Orange', 'Banana']
    > ['Apple', 'Orange', 'Banana']

    fruits_extend = ["Apple"]
    print("추가 전(extend):",id(fruits_extend))

    fruits_extend.extend(["Orange","Banana"])
    print("추가 후(extend):", id(fruits_extend))
    > 추가 전(extend): 1632446564032
    추가 후(extend): 1632446564032
    ```

#### 3.1.2 인덱싱과 슬라이싱
  시퀀스 자료구조 -> 데이터 순차정렬 저장 > 각 데이터 고유 위치 번호
   - 인덱싱 (Indexing) : 요소 찾기
    0부터 시작
    인덱스 번호 음수 (-1,-2,..) : 우측부터 조회
   - 슬라이싱 (Slicing) : 리스트, 튜플 특정 구간 가져올 때 (결과는 새로운 리스트,튜플로)
    `[시작:]` : 시작점 인덱스부터 끝까지
    `[:종료]` : 종료 인덱스는 미포함 [:3] -> 0,1,2
    `[시작 이상:종료 미만]`
    `[시작:종료:증감단위]` : 증감폭 지정 간격으로 데이터 추출
    ```
    numbers = [0, 1, 2, 3, 4, 5]
    print(numbers[1:4])   # 출력: [1, 2, 3] (1번 이상 4번 미만)
    print(numbers[::2])   # 출력: [0, 2, 4] (2칸 간격으로 추출)
    print(numbers[::-1])  # 출력: [5, 4, 3, 2, 1, 0] (역순 정렬)
    ```

### 3.2 매핑 및 집합 자료구조 
#### 3.2.1 사전 자료구조
1. 키(Key)와 값(Value)의 매핑: 딕셔너리(Dictionary) 자료구조
 - key: value 찾을 키워드 , 중복 X ,리스트는 사용 불가

#### 3.2.2 딕셔너리 고급 제어
 - 추가 (Create) : 없는 키 이름으로 값을 대입하면 추가
 - 조회 (Read) : ['키 이름'] - 키가 없으면 KeyError가 발생
    - `keys()` : 모든 키를 담은 View , 읽기 전용
    - `values()` : 모든 값을 담은 View , 읽기 전용
    - `items()` : (키,값) 목록을 담은 View
    - `get('key')` : None을 Error 없이 반환. `('key','Default')` 디폴트값 지정 가능
 - 수정 (Update) : 이미 있는 키값에 대입하면 수정
    - `update({key,value, key,value, ...})`
 - 삭제 (Delete) : 
    - `del items['키']`
    - `clear()` : 잔체 비우기

다른 키·값 쌍 자료형 -> 딕셔너리로 변형
`dict(...)`

### 찾아본 내용
 - `*(애스터리스크 asterisk)` : *변수명 (가변 길이 언패킹 Extended Iterable Unpacking): 할당하고 남은 모든 요소를 묶어 리스트(List) 로 반환하는 기능. (남은 값이 없으면 빈 리스트 [] 반환) 
     위치에 상관없이 단 한 번만 사용할 수 있습니다.
     a, *rest = (1, 2, 3) -> a = 1, rest = [2, 3]
     a, *rest, c = (1, 2, 3, 4) ->  a = 1, rest = [2, 3], c = 4

 - mobile = user.get('mobilde',1) 와 user.get('mobilde','1') 의 차이는?
  ▪ 기본값 자료형의 차이: 1은 숫자형(int), '1'은 문자열형(str)을 기본값으로 반환합니다.
  ▪ 구분이 필요한 이유: 반환된 값을 이후 코드에서 수학 계산에 쓸지, 텍스트 결합에 쓸지에 따라 알맞은 형태를 줘야 하기 때문입니다.
  ▪ 주의점: 연산 목적과 맞지 않는 자료형을 기본값으로 설정하면, 이후 작업(예: 문자열+숫자)에서 타입 에러(TypeError)가 발생합니다.
  
 - 함수와 메서드의 차이
  함수 (Function) : 단독 쓰임, 특정 자료형에 얽매임 X 독립적 존재
  메서드 (Method) : 변수 뒤 `.` 찍고 쓰임, 특정 자료형 전용 기능
  **구분법** : 행동(변수) -> 함수
              변수.행동() -> 메서드
