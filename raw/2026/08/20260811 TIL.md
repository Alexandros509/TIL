### 4.1 조건문
 - 판변실에 따라서 참(True)면 참에 실행되는 코드를 정의하고, 거짓(False)이면 거짓 조건에 실행되는 코드를 정의할 수 있는 문장
 - 판별식 : 비교 연산자, 논리 연산자, 값
 
#### 4.1.1 단일 조건문 : if
```
if 판변식:
    판별식이 참일 때 실행되는 코드
    판별식은 4자 띄워야함 (들여쓰기). Tab 키

num = 10
if num > 5:
    print("5보다 크다")

```
#### 4.1.2 양자택일 구조 : if-else 조건문
 - 조건이 틀린 (False) 경우 실행할 별도의 대응 명령
  ```
    num = 1
    if num == 10:
        print("10 입니다")
    else:
        print("10이 아닙니다")
  ```

#### 4.1.3 다중 조건 분기 : if-elif-else
 - 연쇄 조건 검사
 - 구체적/높은 기준값 조건부터 위에 배치
  ```
    age = int(input("나이를 입력하세요: ")) 
    if age >= 20:
        print("성인")
    elif age >= 17:
        print("고등학생")
    elif age >= 14:
        print("중학생")
    elif age >= 8:
        print("초등학생")
    else: #앞선 모든 조건문 False이면 실행되는 구문
        print("유치원생")
  ```

#### 4.1.4 복잡한 조건 처리: 중첩 조건문과 논리 연산자 결합
 - 계층적 세부 조건 or 다수 조건 동시 만족 

##### 4.1.4.1 중첩 조건문 (Nested if)
 - **논리 연산자** (`and`,`or`) 활용 -> 다중조건을 **한줄의 if**로
   ```

   num = int(input())
   if num>=10:
       if num <100:
           print(f"{num}는 10이상 100미만입니다.")
   > 45는 10이상 100미만입니다.
   
   #논리연산자와 결합
   num = int(input())
   if num>=10 and num<100:
           print(f"{num}는 10이상 100미만입니다.")
   > 55는 10이상 100미만입니다.
   ```

##### 4.2.1.1 리스트 컴프리헨션
 - `for문`과 `if`문을 `리스트 []`안에 작성하여, 새로운 리스트를 **단 한 줄로 압축** 빠르고 간결하게 만듬
  `[표현식 for 변수 in 데이터 (if 조건)]`
   - 표현식
    1. f-string
    2. 메서드 및 함수 호출
    3. 조건부 표현식
    4. 자료구조
  ```

  for i in range(1, 6):
      nums.append(i)
  결과: [1, 2, 3, 4, 5]
  ```

#### 4.2.3 반복문의 중간 제어 : break와 continue
 - continue : 현재 반복을 중단하고 새로운 반복을 시작(건너뛰기), 하위 코드 실행X -> 반복문 처음 조건 or 다음 데이터 순회 단계
 - break : 반복 종료 ,  주로 if 조건문과 짝, if 조건 부합하는 순간 불필요 하위 연산 중단 -> 시스템 성능 높임

## 찾아본 내용
 - 예시 중 print()함수 내용이 다름에 따라 결과물도 차이가 남. 작성 방법들이 어떻게 되는지
    1. 콤마`,` 나열 : `print("문자열",변수)`  
        값과 값 사이 자동 공백 한 칸  
        ex) print("결과는", total, "입니다") ➡️ 결과는 5050 입니다
    2. f-string : `print(f"...")`
       : {} 안에는 변수뿐만 아니라 '결과값이 나오는 파이썬의 모든 코드(표현식)'를 넣을 수 있다. 콤마,더하기 가능
        - 변수
        - 수식(연산)
        - 함수 호출 : 함수 결과값이 출력됨
        - 메서드 사용
    3. 더하기`+`로 묶기 : `print("문자"+"문자")`
        - 문자와 숫자 더하면 에러
    4. 출력 형태 조작하는 특수 옵션
        - sep(구분자) : 콤마로 나열할 때 공백 대신 다른 문자 삽입 
            ex) print("2026", "08", "11", sep="-") ➡️ 2026-08-11
        - end(끝맺음) : print() 출력 시의 줄바꿈 무시, 다른 문자로 끝맺음
            print("첫째 줄", end=" ")
            print("계속 이어짐") ➡️ 첫째 줄 계속 이어짐

 - range()의 반복횟수에 대해 의문이 생김. 반복횟수가 적거나, 많으면(0으로 돌아가나?) 어떤 결과가 나오지?
     1) 아이템이 9개인데 range(8)인 경우
      인덱스 0-7 훑고 반복문 종료
     2) 아이템이 9개인데 range(10)인 경구
      존재하지 않는 인덱스 9 꺼내려다 IndexError

 - 리스트 컴프리헨션의 표현식에서 f-string이 들어갈 수 있는 것을 보고 그러면 다른 것들은 어떤게 되지?
     `[표현식 for 변수 in 데이터 (if 조건)]`

        1. f-string
        2. 메서드 및 함수 호출
        3. 조건부 표현식
        4. 자료구조
