**로컬**
- 명령은 `docker compose up -d --build`. `-build`는 오타.
- 브라우저는 `http://127.0.0.1:8000/docs`. `0.0.0.0`은 주소가 아니라서 `ERR_ADDRESS_INVALID`.

**EC2에서 clone**
- 치는 곳은 `ubuntu@ip-...:~/AWS-261001-Test$`. PowerShell 아님.
- `git@github.com`은 EC2 SSH 공개키를 GitHub에 넣은 뒤.
- fingerprint 질문에는 `yes`.

**Docker 없음**
- `sudo: docker: command not found`면 엔진부터 설치. `.env`만 있다고 실행되지 않음.

**밖이 안 열릴 때**
- `ps`가 `127.0.0.1:8000`이면 EC2 안에서만 열림.
- compose에서 호스트를 `0.0.0.0`으로 바꾼 뒤 `--force-recreate`.
- 목표 표시는 `0.0.0.0:8000->8000/tcp`.

**브라우저**
- `http://퍼블릭IP:8000/docs`
- 보안 그룹 TCP 8000은 내 IP만. 서버 curl은 되고 PC만 실패하면 보안 그룹.
