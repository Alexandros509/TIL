ubuntu@ip-172-31-0-222:~/aws_20260915_test$ sudo cp AWS_selfintro.html /var/www/html/AWS_selfintro.nginx-debian.html 왜 안 바꼈나?

Nginx의 기본 설정(Default)은 접속 시 **`index.nginx-debian.html`** 또는 **`index.html`** 파일을 바라보도록 되어 있습니다.

지금 복사하신 파일명은 앞에 `AWS_selfintro.`가 붙은 `AWS_selfintro.nginx-debian.html`이므로 Nginx가 기본 페이지로 인식하지 못해 기존 화면이 그대로 나오는 것입니다.

**1.기본 파일명으로 덮어쓰기:**10초 소요.

파일을 Nginx가 읽는 기본 인덱스 파일명(`index.nginx-debian.html` 또는 `index.html`)으로 복사합니다.

Bash

```
sudo cp AWS_selfintro.html /var/www/html/index.nginx-debian.html
sudo cp AWS_selfintro.html /var/www/html/index.html
```

_확인:_ `ls -l /var/www/html`을 입력했을 때 두 파일의 용량 및 수정 시간이 방금 복사한 시각으로 변경되었는지 확인합니다.
