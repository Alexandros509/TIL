#### 2.1 문자 클래스 [ ]
포함되면 매칭
- [abc] : 문자 a 또는 b 또는 c에 매칭되는 패턴 # (or?)(결과에 abc인데 a match 이거 short-circuit evaluation인가?)
- [a-z] : a to z 매핑 # 콤마나 공백 없이? [a-zA-Z]?
- [0-9] : 0 to 9 매핑
- [^0-9] : 숫자가 아닌 패턴
- [^a-z] : 알파벳이 아닌 패턴

- 단축 표기법 (digit space word)
    - \d == [0-9]
    - \D : [^0-9]
    - \s : 공백 1개 (공백 1개, 들여쓰기 \t , \n ,\r ,\f)
    - \S : 공백이 아닌 문자 1개
    - \w == [a-zA-Z0-9_] / 의미: 단어 1개
    - \W == [^a-zA-Z0-9_]

#### 2.2 Dot(.) 문자와 반복(, +, {m,n}, ?)
- 패턴{n} : 패턴을 n번 반복
- 패턴{m,n} : 패턴이 m번 이상 n번 이하 매칭
- 패턴{m,} : 패턴이 m번 이상 반복
- 패턴+ : 패턴{1,} : 1번 이상 반복되는 패턴 (한 번은 꼭 있어야함)
- 패턴* : 패턴{0,} : 0번 이상 반복되는 패턴 (없어도 되고 1개 이상 있어도 된다)
- 패턴? : 패턴{0,1} - 없어도 되고 있어도 되지만 있다면 1개만 있어야 함
- . : 줄 개행 문자(\n)을 제외한 모든 문자
- ^패턴 : 패턴으로 시작하는 패턴
- 패턴$ : 패턴으로 끝나는 패턴

### 10. Greedy vs Non-Greedy
s = '<html><head><title>Title</title>'
Greedy 방식 (가장 큰 범위 매치)
pattern = re.compile("<.+>")
print(pattern.match(s).group())
Non-Greedy 방식 (최소한의 범위 매치)
pattern = re.compile("<.+?>") # 논그리디에서 ?는 무슨 멀로 붙은?
print(pattern.match(s).group())
