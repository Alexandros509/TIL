파이썬의 전체 내장 함수 및 타입
알파벳 순서대로 핵심 역할만 한 줄씩 요약

---

### A

* **`abs()`**: 숫자의 절대값을 반환합니다.
* **`aiter()`**: 비동기 이터레이터를 반환합니다.
* **`all()`**: 모든 요소가 참(True)으로 평가되는지 확인합니다.
* **`anext()`**: 비동기 이터레이터의 다음 값을 얻습니다.
* **`any()`**: 하나 이상의 요소가 참(True)으로 평가되는지 확인합니다.
* **`ascii()`**: 객체의 repr() 결과에서 비-ASCII 문자를 이스케이프한 문자열을 반환합니다.

### B

* **`bin()`**: 정수를 2진수 문자열로 변환합니다.
* **`bool()`**: 참(True) 또는 거짓(False) 불리언 값으로 변환합니다.
* **`breakpoint()`**: 현재 코드 위치에서 디버거를 호출합니다.
* **`bytearray()`**: 수정 가능한 바이트 배열 객체를 생성합니다.
* **`bytes()`**: 수정 불가능한 바이트 객체를 생성합니다.

### C

* **`callable()`**: 객체가 호출(함수처럼 실행) 가능한지 확인합니다.
* **`chr()`**: 유니코드 정수값에 해당하는 문자를 반환합니다.
* **`classmethod()`**: 메서드를 클래스 메서드로 변환합니다.
* **`compile()`**: 소스 코드를 실행 가능한 코드 객체로 컴파일합니다.
* **`complex()`**: 복소수를 생성합니다.

### D

* **`delattr()`**: 객체의 속성을 삭제합니다.
* **`dict()`**: 딕셔너리(사전) 객체를 생성합니다.
* **`dir()`**: 객체가 가진 속성과 메서드 목록을 반환합니다.
* **`divmod()`**: 몫과 나머지를 튜플로 반환합니다.

### E

* **`enumerate()`**: 인덱스와 요소를 튜플로 묶은 이터레이터를 반환합니다.
* **`eval()`**: 문자열로 된 파이썬 표현식을 실행하고 결과를 반환합니다.
* **`exec()`**: 문자열로 된 파이썬 코드를 실행합니다.

### F

* **`filter()`**: 조건에 맞는 요소만 걸러내는 이터레이터를 반환합니다.
* **`float()`**: 실수로 변환합니다.
* **`format()`**: 값의 형식 지정 규칙에 따라 문자열 표현을 생성합니다.
* **`frozenset()`**: 수정 불가능한 집합(set)을 생성합니다.

### G

* **`getattr()`**: 객체에서 특정 속성값을 가져옵니다.
* **`globals()`**: 현재 전역 심볼 테이블을 딕셔너리로 반환합니다.

### H

* **`hasattr()`**: 객체가 특정 속성을 가지고 있는지 확인합니다.
* **`hash()`**: 객체의 해시값을 반환합니다.
* **`help()`**: 내장 함수나 객체의 도움말을 출력합니다.
* **`hex()`**: 정수를 16진수 문자열로 변환합니다.

### I

* **`id()`**: 객체의 고유 식별자를 반환합니다.
* **`input()`**: 사용자로부터 입력을 받습니다.
* **`int()`**: 정수로 변환합니다.
* **`isinstance()`**: 객체가 특정 클래스의 인스턴스인지 확인합니다.
* **`issubclass()`**: 클래스가 특정 클래스의 하위 클래스인지 확인합니다.
* **`iter()`**: 객체로부터 이터레이터를 생성합니다.

### L

* **`len()`**: 객체의 길이(개수)를 반환합니다.
* **`list()`**: 리스트 객체를 생성합니다.
* **`locals()`**: 현재 지역 심볼 테이블을 딕셔너리로 반환합니다.

### M

* **`map()`**: 모든 요소에 함수를 적용한 이터레이터를 반환합니다.
* **`max()`**: 가장 큰 값을 반환합니다.
* **`memoryview()`**: 객체의 메모리 버퍼를 참조하는 메모리뷰 객체를 생성합니다.
* **`min()`**: 가장 작은 값을 반환합니다.

### N

* **`next()`**: 이터레이터에서 다음 값을 가져옵니다.

### O

* **`object()`**: 모든 클래스의 기반이 되는 가장 기본적인 객체를 생성합니다.
* **`oct()`**: 정수를 8진수 문자열로 반환합니다.
* **`open()`**: 파일을 열고 파일 객체를 반환합니다.
* **`ord()`**: 문자의 유니코드 정수값을 반환합니다.

### P

* **`pow()`**: 거듭제곱 값을 구합니다.
* **`print()`**: 화면에 데이터를 출력합니다.
* **`property()`**: 속성 접근을 제어하는 프로퍼티 객체를 생성합니다.

### R

* **`range()`**: 지정한 시작·끝·간격에 따른 정수 시퀀스를 나타내는 range 객체를 생성합니다.
* **`repr()`**: 객체의 공식적인 문자열 표현을 반환합니다.
* **`reversed()`**: 순서가 뒤집힌 이터레이터를 반환합니다.
* **`round()`**: 반올림된 값을 반환합니다.

### S

* **`set()`**: 집합(set) 객체를 생성합니다.
* **`setattr()`**: 객체의 속성값을 설정합니다.
* **`slice()`**: 슬라이스 객체를 생성합니다.
* **`sorted()`**: 정렬된 새로운 리스트를 반환합니다.
* **`staticmethod()`**: 메서드를 정적 메서드로 변환합니다.
* **`str()`**: 문자열로 변환합니다.
* **`sum()`**: 모든 요소의 합을 반환합니다.
* **`super()`**: 부모(슈퍼) 클래스의 메서드나 속성에 접근할 수 있게 합니다.

### T

* **`tuple()`**: 튜플 객체를 생성합니다.
* **`type()`**: 객체의 자료형을 반환합니다.

### V

* **`vars()`**: 객체의 `__dict__` 속성(네임스페이스)을 반환합니다.

### Z

* **`zip()`**: 여러 이터러블의 요소를 튜플로 묶어 이터레이터로 반환합니다.

### _

* **`__import__()`**: `import` 문이 내부적으로 사용하는 모듈 `import` 함수입니다.
