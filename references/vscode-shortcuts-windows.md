# VS Code 자주 사용하는 단축키 (Windows)

> **단축키 (제외됨)**
>
> - 새 파일 (`Ctrl + N`)
> - 파일 열기 (`Ctrl + O`)
> - 새 창 (`Ctrl + Shift + N`)
> - 저장 (`Ctrl + S`)
> - 다른 이름으로 저장 (`Ctrl + Shift + S`)
> - 탭 닫기 (`Ctrl + W`)
> - 닫은 탭 다시 열기 (`Ctrl + Shift + T`)
> - 현재 파일 검색 (`Ctrl + F`)
> - 현재 파일 바꾸기 (`Ctrl + H`)
> - 실행 취소 (`Ctrl + Z`)
> - 다시 실행 (`Ctrl + Y` 또는 `Ctrl + Shift + Z`)
> - 한 줄 잘라내기 (`Ctrl + X`)
> - 한 줄 복사 (`Ctrl + C`)
> - 붙여넣기 (`Ctrl + V`)
> - 전체 선택 (`Ctrl + A`)
> - Delete (`Delete`)
> - Backspace (`Backspace`)
> - 줄 시작 (`Home`)
> - 줄 끝 (`End`)
> - 들여쓰기 (`Tab`)
> - 이름 변경 (`F2`)
---

# 📂 프로젝트 및 파일

| 단축키 | 기능 | 설명 |
|---------|------|------|
| `Ctrl + K` → `Ctrl + O` | 폴더 열기 | 프로젝트(폴더) 전체를 연다. |

---

# 🔍 검색

| 단축키 | 기능 | 설명 |
|---------|------|------|
| `Ctrl + Shift + F` | 전체 검색 | 현재 프로젝트(폴더)의 모든 파일에서 검색한다. |
| `Ctrl + Shift + H` | 전체 바꾸기 | 프로젝트 전체에서 문자열을 한 번에 변경한다. |
| `F3` | 다음 검색 결과 | 다음 검색 결과로 이동한다. |
| `Shift + F3` | 이전 검색 결과 | 이전 검색 결과로 이동한다. |

---

# 📝 줄 편집

| 단축키 | 기능 | 설명 |
|---------|------|------|
| `Alt + ↑ / ↓` | 줄 이동 | 현재 줄을 위·아래로 이동한다. |
| `Shift + Alt + ↑ / ↓` | 줄 복사 | 현재 줄을 위·아래로 복제한다. |
| `Ctrl + Shift + K` | 줄 삭제 | 현재 줄 전체를 삭제한다. |

---

# ✨ 다중 커서(Multi Cursor)

| 단축키 | 기능 | 설명 |
|---------|------|------|
| `Alt + Click` | 커서 추가 | 원하는 위치에 커서를 추가한다. |
| `Ctrl + Alt + ↑ / ↓` | 위/아래 커서 추가 | 여러 줄을 동시에 편집한다. |
| `Ctrl + D` | 같은 단어 선택 | 같은 단어를 하나씩 선택한다. |
| `Ctrl + Shift + L` | 같은 단어 모두 선택 | 같은 단어를 모두 선택하여 동시에 수정한다. |

---

# 📍 이동(Navigation)

| 단축키 | 기능 | 설명 |
|---------|------|------|
| `Ctrl + G` | 줄 번호 이동 | 원하는 줄 번호로 이동한다. |
| `Ctrl + P` | 파일 검색 | 파일명을 입력하여 빠르게 연다. |
| `Ctrl + Tab` | 최근 파일 전환 | 최근에 열었던 파일로 전환한다. |
| `Ctrl + PageUp / PageDown` | 탭 이동 | 열린 탭을 좌우로 이동한다. |
| `Ctrl + Home` | 파일 처음 | 파일의 첫 줄로 이동한다. |
| `Ctrl + End` | 파일 끝 | 파일의 마지막 줄로 이동한다. |

---

# 💻 코드 작성

| 단축키 | 기능 | 설명 |
|---------|------|------|
| `Shift + Tab` | 내어쓰기 | 들여쓰기를 한 단계 줄인다. |
| `Ctrl + ]` | 들여쓰기 증가 | 선택한 줄을 오른쪽으로 들여쓴다. |
| `Ctrl + [` | 들여쓰기 감소 | 선택한 줄을 왼쪽으로 내어쓴다. |
| `Alt + Shift + F` | 코드 자동 정렬 | Formatter를 실행하여 코드를 정렬한다. |
| `Ctrl + /` | 한 줄 주석 | 현재 줄 또는 선택 영역을 주석 처리/해제한다. |
| `Shift + Alt + A` | 블록 주석 | 여러 줄을 블록 주석 처리/해제한다. |

---

# 💡 IntelliSense

| 단축키 | 기능 | 설명 |
|---------|------|------|
| `Ctrl + Space` | 자동완성 | 코드 자동완성 목록을 표시한다. |
| `F12` | 정의로 이동 | 함수, 변수 등의 정의 위치로 이동한다. |
| `Alt + F12` | 정의 미리보기 | 정의를 새 창으로 이동하지 않고 미리 본다. |
| `Shift + F12` | 참조 찾기 | 현재 요소가 사용된 위치를 모두 찾는다. |
| `Ctrl + .` | Quick Fix | 오류 수정 및 추천 기능을 표시한다. |

---

# 📂 사이드바

| 단축키 | 기능 |
| `Ctrl + B` | 사이드바 표시/숨김 |

# 🖥️ 터미널

| 단축키 | 기능 | 설명 |
|---------|------|------|
| `Ctrl + Shift + \`` | 새 터미널 | 새로운 터미널을 생성한다. |
| `Ctrl + Shift + 5` | 터미널 분할 | 터미널을 분할하여 여러 개를 동시에 사용한다. |
| `Ctrl + PageUp / PageDown` | 터미널 전환 | 여러 터미널 사이를 이동한다. |

# ⚙️ Command Palette

| 단축키 | 기능 | 설명 |
|---------|------|------|
| `Ctrl + Shift + P` | Command Palette | VS Code의 거의 모든 기능을 검색하여 실행한다. |

대표적으로 다음과 같은 명령을 실행할 수 있다.

- Python Interpreter 선택
- Format Document
- Reload Window
- Git Clone
- Markdown Preview
- Settings 검색

---

# 📝 Markdown

| 단축키 | 기능 | 설명 |
|---------|------|------|
| `Ctrl + Shift + V` | 미리보기 | 현재 Markdown 파일을 미리본다. |
| `Ctrl + K` → `V` | 옆에서 미리보기 | 에디터와 미리보기를 동시에 표시한다. |
| `Alt + Z` | 자동 줄바꿈 | Word Wrap 기능을 켜거나 끈다. |
