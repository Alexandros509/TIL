## 오늘의 학습

### Flexbox (1차원 정렬)

- 설정 - 부모요소
  - `display: flex;`
- 적용 - 자식요소
- 정렬 방향
  - `flex-direction`
    - `row`(기본값) : 좌 → 우
    - `row-reverse` : 우 → 좌
    - `column` : 위 → 아래
    - `column-reverse` : 아래 → 위
- 정렬 속성 제어
  - `justify-content`
    1. `flex-start` : 왼쪽 정렬 (기본값)
    2. `flex-end` : 오른쪽
    3. `center` : 가운데
    4. `space-between` : 좌우 요소 1개를 끝에 배치, 나머지 요소 공백 균등 부여
    5. `space-around` : 각 요소 주위 동일 공백 부여
    6. `space-evenly` : 공평하게
- `align-items` : 자식 요소들의 위치배치
  - `stretch` (기본값) : 부모 요소의 크기에 맞춰 늘리는 것
  - `flex-start` : 위쪽 배치
  - `flex-end` : 아래쪽 배치
  - `center` : 가운데 배치

`flex-grow`

1. 자식 요소 적용
2. 남아있는 공백을 차지할 비율 설정

`flex-shrink`

1. 부모 요소의 공간이 부족할 때 자식 요소의 크기 줄임 비율
2. 비율 가중치
3. `0` : 요소를 축소 X
4. `flex-basis` : 요소의 기본 사이즈
   - `auto` (default)
   - `px`, `%`

`flex-wrap`

- `wrap` : 부모 요소의 너비가 부족하면 다음 칸에 개행
- `nowrap` (default) : 개행 X

### CSS Grid (2차원 격자 레이아웃)

`grid-template-columns` (열 정의)

1. 픽셀(`px`) 단위 지정
   - `grid-template-columns: 150px 150px 300px;`
   - 열 3개 생성 : 1번째 열 150px, 2번째 열 150px, 3번째 열 300px
2. `fr` (Fraction) 단위 사용
   - `fr`: 남은 공간에 대한 비율
   - `grid-template-columns: 150px 1fr 2fr;`
   - 첫 번째 열 150px 고정
   - 두 번째 열 150px 제외 남은 공간의 1/3
   - 세 번째 열 150px 제외 남은 공간의 2/3
3. `repeat(컬럼갯수, 사이즈)`
   - 같은 사이즈의 지정된 컬럼개수만큼 설정

`gap` (격자 여백 설정)

- `row-gap` : 행별 여백
- `column-gap` : 열별 여백
- `gap: 20px 10px;` 행 열
- `gap: 30px;` 행열 모두

`grid-column`

1. `grid-column: 1/3;`
   - 1번~3번열까지, 2칸
2. `grid-column: span 2;`
   - 열의 2칸 차지

`grid-row`

1. `grid-row: 1/3;`
2. `grid-row: span 2`
   - 2개 행 차지

`place-items`

- `stretch` (default)
- `start` : 왼쪽 상단
- `end` : 우측 하단
- `center` : 정가운데

### 2.1 CSS 기초와 스타일링 문법

#### 폰트

1. `color` : 글 색상
2. `font-size` : 글 크기
3. `line-height` : 행간
   - 비율 방식 권장
   - 비율: 기본값 1.2 → 1.글의 높이
     - 20%의 여백을 10% 상단 10% 하단 할당
   - `%`
   - `px`, `em`, `rem`
4. `letter-spacing` : 자간
5. `word-spacing` : 단어 사이 간격
6. `word-break` : `wrap` / `nowrap` / `break-all`
7. `font-weight` : 폰트 두께
   - `normal` (default)
   - `bold` : 100 ~ 900
   - 폰트별 지원 두께 상이함. 확인 필요
8. `text-align`
   - 인라인 요소(글)에 대한 정렬
   - `left` (default)
   - `right`
   - `center`
   - `justify` : 양쪽 정렬
9. `font-style`
   - `normal` (default)
   - `italic` : 기울임체
   - `oblique` 각도 : 흘림체
     - `oblique 90deg;`
10. `text-decoration`
    - `underline`
    - `line-through` : 취소선
    - `none` (default)
11. `font-family` : 글꼴
    - `font-family: 폰트명, 대체폰트1, 대체폰트2, ...;`
      - 폰트명에 공백이 있으면 따옴표로 감싼다
      - 예) `font-family: 'Malgun Gothic', 'Apple Gothic', sans-serif;`
    - 시스템 폰트 : OS 내 설치된 폰트
    - 웹 폰트 : OS 설치 무관하게 동일하게 공유 가능한 폰트

#### `overflow` (x,y default)

- `visible` (default) → 넘치는 컨텐츠가 있어도 보임
- `hidden` → 넘치는 컨텐츠를 감추기
- `scroll` → 넘치는 컨텐츠가 있으면 스크롤바 노출 (**상시**)
- `auto` → 넘치는 컨텐츠가 있으면 스크롤바 노출, 없으면 X
- `overflow-x:`
- `overflow-y:`

#### `border` : 경계선

1. `border-width`
2. `border-style`
   - `none` (default)
   - `solid` : 직선
   - `dashed` : 파선
   - `dotted` : 점선
   - `double` : 이중실선
3. `border-color`
   - 단축 표현법
     - `border: 두께 스타일 색상;`
       - 예) `border: 2px solid red;`
       - `border-top`
       - `border-bottom`
       - `border-left`
       - `border-right`
4. `border-radius` : 모서리 둥글게
   - `px`, `%` (50% = 원)

#### `background`

1. `background-color`
2. `background-image` : `url("이미지 경로")`
3. `background-repeat`
   - `repeat` (default) : x,y축 모두
   - `repeat-x` : x축
   - `repeat-y` : y축
   - `no-repeat` : 하나만 출력
4. `background-position`
   - 배경이미지 위치 설정
   - 예) `background-position: 100px 50px;` (좌에서 우로 100px, 위에서 아래로 50px)
   - `background-position` left, right, top, bottom
   - `background-position: center center;`
5. `background-size`
   - `background-size: 가로 세로;`
   - `background-size: 200px;` (세로는 비율에 따라 자동 조절)
   - `background-size: 50%;`
   - `background-size: cover;` (영역 모두 채움, 이미지 비율이 배경 요소와 차이가 있다면 일부 짤림)
   - ⚠ 교재와 필기의 내용 차이

     필기:
     `background-contain : contain;` (이미지 모두 보이게 채움, 요소 비율이 다르면 상하좌우에 여백이 생김)

     교재:
     `background-size: contain;` (이미지 비율 유지, 전체가 구역 안에 들어가도록 맞춤. 여백 가능)

     가능한 해석:
     속성명은 `background-size`이고 값으로 `contain`을 쓰는 것으로 보이며, 필기의 `background-contain`은 속성명 오기일 수 있음.

     추가 확인 필요
6. `background-attachment`
   - `background-attachment: fixed;` (배경 이미지 고정)
   - `background-attachment: scroll;` (스크롤 시 배경 이미지도 함께 스크롤)
   - `background-attachment: local;`
   - 단축 표현법
     - `background: 색상 이미지 반복 고정 위치 사이즈;` (색상·이미지 적어도 하나는 정의해야 함, 뒤는 선택)
     - `background: [color] [image] [repeat] [attachment] [position / size];`

| 구분 | background-color | background |
| --- | --- | --- |
| 속성 종류 | 단일 속성 (Longhand) | 단축 속성 (Shorthand) |
| 지정 범위 | 오직 배경 색상만 지정 가능 | 색상, 이미지, 반복, 위치, 크기 등 배경 관련 모든 속성 지정 가능 |
| 다른 속성에 미치는 영향 | 다른 배경 속성(이미지, 위치 등)을 건드리지 않음 | 명시하지 않은 다른 배경 속성들을 기본값(초기화)으로 덮어씀 |

| 속성값 | 기준 (고정되는 위치) | 전체 페이지 스크롤 시 | 내부 박스(overflow: scroll) 스크롤 시 |
| --- | --- | --- | --- |
| `scroll` (기본값) | 요소의 배경 영역 | 요소와 함께 위아래로 이동함 | 움직이지 않음 (배경은 가만히 있고 내부 글자만 스크롤됨) |
| `fixed` | 브라우저 창(Viewport)에 고정 | 화면에 고정 | 움직이지 않음 (화면 뷰포트 기준이므로 내부 스크롤과 무관) |
| `local` | 요소 안의 콘텐츠 내용물에 고정 | 요소와 함께 이동함 | 내부 글자와 함께 배경도 위아래로 스크롤됨 |

#### `position`

- 위치(배치)
- `static` (default)
- 절대 위치 - `absolute`, `fixed`
- 상대 위치
  - `relative`
- 층위 설정 가능 - `z-index`
  - `static` 제외
  - 값 ↑ 앞쪽 배치
  - 값 ↓ 뒤쪽 배치

| 속성값 | 기준점 | 핵심 특징 |
| --- | --- | --- |
| `static` | 없음 | 기본 순서 배치, 좌표(`top` / `left`) 미적용 |
| `relative` | 본인 원래 자리 | 원래 공간 유지한 채 미세 이동 |
| `absolute` | `position ≠ static`인 최근접 조상, 없으면 문서 전체 | 흐름 이탈, 조상 기준 절대 좌표 |
| `fixed` | Viewport (`transform` 조상 있으면 그 조상) | 흐름 이탈, 스크롤 무관 화면 고정 |
| `sticky` | 최근접 스크롤 컨테이너 + 임계점 | 평소 `relative` → 임계점에서 컨테이너 안 고정 |

| 선택자 | 대상 | 메모 |
| --- | --- | --- |
| `.a, .b` | 자체가 `.a`이거나 `.b` | 선언 복제. 콤마는 OR |
| `.a .b` | `.a` 안의 자손 `.b` | 공백 = 자손 |
| `.a > .b` | `.a`의 직계 자식 `.b` | `>` = 한 단계만 |
| `.a.b` | 한 요소가 `.a`이면서 `.b` | 붙여 쓰면 AND |
| `:is(.a, .b)` | 자체가 `.a`이거나 `.b` | `.a, .b`와 매칭 동일. 묶기용 |
| `:is(.a, .b) .x` | `.a` 또는 `.b` 안의 자손 `.x` | 부모 OR + 자손 |
| `:is(.a, .b) > .x` | `.a` 또는 `.b`의 직계 자식 `.x` | 부모 OR + 자식 |
| `:where(.a, .b)` | `:is()`와 대상 같음 | 명시도 **0** |
| `:where(.a, .b) .x` | `.a` 또는 `.b` 안의 자손 `.x` | 매칭은 `:is`와 같고 특이도만 0 |
| `:has(.x)` | 자손 `.x`를 **가진** 요소 | 부모 방향으로 조건 |
| `.a:has(.x)` | 자손 `.x`를 가진 `.a` | "이런 자식을 둔 `.a`" |
| `:is(.a, .b):has(.x)` | 자손 `.x`를 가진 `.a` 또는 `.b` | OR 부모 + 자식 존재 |
| `:has(> .x)` | 직계 자식 `.x`를 가진 요소 | 한 단계만 검사 |

## 찾아본 내용

### 1. `list-style`

`<ul>` / `<ol>` 항목 앞 **불릿·번호**를 한 번에 정하는 단축 속성.

~~~css
list-style: <type> || <position> || <image>;
~~~

| 조각 | 역할 | 예 |
| --- | --- | --- |
| `list-style-type` | 기호·번호 | `disc` · `circle` · `square` · `decimal` · `none` |
| `list-style-position` | 박스 안/밖 | `outside`(기본) · `inside` |
| `list-style-image` | 기호 대신 이미지 | `url(...)` · `none` |

~~~css
ul { list-style: none; }           /* 불릿 제거 후 직접 디자인 */
ol { list-style-type: decimal; }   /* 번호 목록 */
~~~

- `none` = 기호만 제거. 들여쓰기는 그대로 → 보통 `padding-left: 0`과 같이 씀
- 교재(`FE_04`)에 전용 단원 없음. 실습만 `.task-list li { list-style: none; }`로 불릿을 끄고 카드형 UI
- `color`는 불릿 색에도 적용될 수 있음

## 핵심 개념

- Flexbox: 부모 `display: flex`, `flex-direction`, `justify-content`, `align-items`, `flex-grow`/`shrink`/`basis`, `flex-wrap`
- CSS Grid: `grid-template-columns`, `fr`·`repeat`, `gap`, `grid-column`/`grid-row`, `place-items`
- 폰트·텍스트: `color`, `font-size`, `line-height`, `font-weight`, `text-align`, `font-family` 등
- `overflow`, `border`, `background`(단축·attachment), `position`·`z-index`, `outline`
- 선택자 조합: `,` / 공백 / `>` / `.a.b` / `:is` / `:where` / `:has`
- `list-style` 단축 (찾아본 내용)

## 교재 보충

※ 아래 내용은 사용자의 필기를 보완하기 위해
교재에서 가져온 내용이다.

### Flexbox 축 (FE 3-1)

- `justify-content` : 주축(메인 축) 정렬
- `align-items` : 교차 축 정렬
- `flex-grow` / `flex-shrink` / `flex-basis`는 **자식 요소에 개별 설정**

### Grid `fr`·`gap` (FE 3-1)

- `fr` : 남은 공간을 비율로 나눔
- `gap: 행여백 열여백;` / `gap: 동일값;`
- `place-items` : `align-items` + `justify-items` 단축

### `background-size` (FE 2-1)

- `cover` : 비율 유지하며 영역 채움 (일부 잘릴 수 있음)
- `contain` : 비율 유지하며 이미지 전체가 보이도록 (여백 가능)
- 단축 권장 순서: color → image → repeat → attachment → position / size

### `position` (FE 2-2)

- `relative` : 원래 자리 기준 미세 이동, absolute 자식의 기준점이 되기도 함
- `absolute` : `static`이 아닌 최근접 조상 기준 (없으면 문서/초기 포함 블록)
- `fixed` : Viewport 기준 고정

## 필기 ↔ 교재 비교

| 항목 | 필기 | 교재 | 결과 |
|------|------|------|------|
| Flexbox 기본 | direction·justify·align·grow/shrink/basis·wrap | 동일 + 주축/교차축 | 교재 보충(축) |
| Grid | template-columns·fr·gap·span·place-items | 동일 | 동일 |
| background contain | `background-contain : contain;` | `background-size: contain;` | 확인 필요 |
| position | static·relative·absolute·fixed·sticky·z-index | static·relative·absolute·fixed (FE 2-2) | sticky 확인 필요 |
| line-height | 비율 1.2, %·px·em·rem | 단위 없는 숫자 권장(상속) | 교재 보충 |
| word-break 값 | wrap / nowrap / break-all | FE 2-1에 해당 절 없음 | 확인 필요 |
| outline | `none` (접근성 주의) | 이번 범위 교재에 전용 절 약함 | 필기 유지 |
| list-style | 찾아본 내용으로 정리 | 실습에서 `list-style: none`만 | 필기 유지 |

## 확인이 필요한 사항

⚠ `background-contain : contain;` — 교재·표준 속성은 `background-size: contain;`. 속성명 오기 여부 확인 필요. 필기 표기와 교재 표기를 위 차이 블록에 병기.

⚠ CSS 변수: `:root`에 `--primary-layerout-size` / `--primary-layerout-min-size`로 선언했으나 `body`에서는 `var(--primary-layout-size)` / `var(--primary-layout-min-size)`를 사용. 이름 불일치로 변수가 적용되지 않을 수 있음. 코드는 원문 유지.

⚠ `word-break: wrap / nowrap / break-all` — `wrap`·`nowrap`은 보통 `white-space` 쪽 값. `word-break` 값인지 `white-space`와 혼동인지 확인 필요. 필기 표기 유지.

⚠ `position: sticky` — 필기 표에 있음. FE 2-2 position 절은 static·relative·absolute·fixed 위주. 수업에서 다룬 sticky인지 확인 필요.

⚠ 어제의 복습 2번 답: 「상속 / Cascading」 — 교재는 상속(Inheritance)과 캐스케이딩(Cascading)을 구분. 복습 문항이 상속을 묻는지 확인용으로 병기 유지.
