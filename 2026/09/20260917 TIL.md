## 오늘의 학습

### Flexbox (심화)

※ direction·justify·align 입문은 전날(09-16). 오늘은 자식 크기·줄바꿈.

- 부모: `display: flex;` → 자식에 정렬·크기 적용

**flex-grow** — 남는 여백을 차지할 비율 (자식)

**flex-shrink** — 공간 부족 시 줄임 비율. `0`이면 축소 X

**flex-basis** — 기본 사이즈 (`auto` / `px` / `%`)

**flex-wrap**

- `wrap` : 너비 부족 시 다음 줄
- `nowrap`(기본) : 개행 X

입문 복기 (짧게)

- `flex-direction`: row·row-reverse·column·column-reverse
- `justify-content`: start·end·center · space-between·around·evenly
- `align-items`: stretch·start·end·center

### CSS Grid (2차원)

**grid-template-columns**

- `px`: `150px 150px 300px` → 열 3
- `fr`: 남은 공간 비율. `150px 1fr 2fr` → 고정 후 1:2
- `repeat(개수, 사이즈)`: 동일 열 반복

**gap** — `row-gap` / `column-gap` · `gap: 20px 10px;` · `gap: 30px;`

**grid-column** — `1/3`(1~3열, 2칸) · `span 2`

**grid-row** — `1/3` · `span 2`

**place-items** — stretch(기본) / start / end / center

### 폰트·텍스트

**2.1 CSS 기초와 스타일링 문법**

| 속성 | 한 줄 |
|------|------|
| `color` | 글 색 |
| `font-size` | 글 크기 |
| `line-height` | 행간. 비율(기본 1.2) 권장 · `%`·`px`·`em`·`rem` |
| `letter-spacing` / `word-spacing` | 자간 / 단어 간격 |
| `word-break` | 필기: `wrap` / `nowrap` / `break-all` (확인 항) |
| `font-weight` | normal · bold · 100~900 (폰트별 상이) |
| `text-align` | left·right·center·justify (인라인 정렬) |
| `font-style` | normal · italic · `oblique 90deg` |
| `text-decoration` | underline · line-through · none |
| `font-family` | `폰트, 대체…` (공백 있으면 따옴표). 시스템 / 웹 폰트 |

### overflow · border · background · position

**overflow**

- `visible`(기본) / `hidden` / `scroll`(상시) / `auto` · `overflow-x`·`y`

**border**

- width · style(`none`/`solid`/`dashed`/`dotted`/`double`) · color
- 단축: `border: 2px solid red;` · `border-top` 등
- `border-radius`: `px`·`%`(50%=원)

**background**

1. `background-color`
2. `background-image: url("…")`
3. `background-repeat`: repeat · repeat-x/y · no-repeat
4. `background-position`: `100px 50px` · left/right/top/bottom · `center center`
5. `background-size`: `가로 세로` · `200px` · `%` · `cover`(채움·잘림 가능)
   - ⚠ 필기 `background-contain : contain;` vs 교재 `background-size: contain;` → 확인 항
6. `background-attachment`: fixed · scroll · local
7. 단축: `background: [color] [image] [repeat] [attachment] [position / size];`

| 구분 | background-color | background |
| --- | --- | --- |
| 종류 | Longhand | Shorthand |
| 범위 | 색만 | 색·이미지·반복·위치·크기 등 |
| 영향 | 다른 배경 속성 유지 | 미지정 배경 속성을 기본값으로 덮음 |

| 속성값 | 기준 | 페이지 스크롤 | overflow 박스 스크롤 |
| --- | --- | --- | --- |
| `scroll`(기본) | 요소 배경 영역 | 요소와 함께 이동 | 배경 고정·글만 스크롤 |
| `fixed` | Viewport | 화면 고정 | 내부 스크롤과 무관 |
| `local` | 콘텐츠 | 요소와 함께 | 글과 함께 스크롤 |

**position**

- 절대: `absolute`·`fixed` / 상대: `relative` / 기본 `static`
- `z-index`: static 제외. ↑앞 · ↓뒤

| 속성값 | 기준점 | 핵심 |
| --- | --- | --- |
| `static` | 없음 | 좌표 미적용 |
| `relative` | 본인 원래 자리 | 공간 유지·미세 이동 |
| `absolute` | `≠static` 최근접 조상(없으면 문서) | 흐름 이탈 |
| `fixed` | Viewport (`transform` 조상 있으면 그 조상) | 스크롤 무관 고정 |
| `sticky` | 스크롤 컨테이너 + 임계점 | 평소 relative → 임계점 고정 |

**outline** — `none` (접근성 주의)

~~~css
/* 초기화 — 브라우저 기본 여백·장식 제거 */
body {
    margin: 0; /* body 바깥 기본 마진 제거 */
}

a {
    text-decoration: none; /* 링크 밑줄 제거 */
}

ul, ol, dl, dt, dd {
    margin: 0;          /* 목록 기본 바깥 여백 제거 */
    padding: 0;         /* 목록 기본 안쪽 여백(불릿 들여쓰기) 제거 */
    list-style: none;   /* 불릿·번호 기호 제거. 들여쓰기는 padding과 별개 */
}
~~~

~~~css
/* 전역 변수 — :root에 토큰 저장, var()로 재사용 */
:root {
	--primary-font-family: "Noto Sans KR", sans-serif; /* 기본 글꼴 + 대체 */
	--primary-font-size: 13px;                         /* 루트 글자 크기 */
	--primary-font-color: #313131;                     /* 본문 글자색 */
	--primary-layerout-size: 727px;                    /* 최대 너비 토큰 (이름 layout 오타) */
	--primary-layerout-min-size: 320px;                /* 최소 너비 토큰 (이름 layout 오타) */
}

/* 공통 — 모든 요소에 박스 계산·글꼴 통일 */
* {
  box-sizing: border-box;                 /* width에 padding·border 포함 */
  font-family: var(--primary-font-family); /* 전역 글꼴 적용 */
}

html {
	font-size: var(--primary-font-size); /* rem 기준 크기 */
	background: #f8f8f8;                 /* 페이지 바깥 배경 */
}

body {
	color: var(--primary-font-color);              /* 본문색 */
	max-width: var(--primary-layout-size);         /* 선언명(--primary-layerout-size)과 불일치 → 미적용 */
	min-width: var(--primary-layout-min-size);     /* 선언명(--primary-layerout-min-size)과 불일치 → 미적용 */
	min-height: 700px;                             /* 본문 최소 높이 */
	background: #fff;                              /* 본문 흰 배경 */
	margin: 0 auto;                                /* 좌우 중앙 정렬 */
}

/* 헤더 — 로고·메뉴를 한 줄 양끝 배치 */
header {
    display: flex;                    /* 가로 플렉스 컨테이너 */
    justify-content: space-between;   /* 주축 양끝 배치 */
    height: 66px;                     /* 헤더 높이 고정 */
    border-bottom: 1px solid #ccc;    /* 하단 구분선 */
    align-items: center;              /* 교차축 세로 중앙 */
}
header > section {
    flex-basis: 20%;  /* 기본 너비 20% */
    flex-shrink: 0;   /* 공간 부족해도 이 섹션은 줄이지 않음 */
}

header > section.right {
   display: flex;                 /* 우측 영역을 다시 플렉스 */
   justify-content: flex-end;     /* 내부 아이템을 오른쪽 정렬 */
}
~~~

| 선택자 | 대상 | 메모 |
| --- | --- | --- |
| `.a, .b` | 자체가 `.a`이거나 `.b` | 콤마 = OR |
| `.a .b` | `.a` 안의 자손 `.b` | 공백 = 자손 |
| `.a > .b` | `.a`의 직계 자식 `.b` | `>` = 한 단계 |
| `.a.b` | 한 요소가 `.a`이면서 `.b` | 붙여 쓰면 AND |
| `:is(.a, .b)` | 자체가 `.a`이거나 `.b` | 묶기용 |
| `:is(.a, .b) .x` | `.a` 또는 `.b` 안의 자손 `.x` | 부모 OR + 자손 |
| `:is(.a, .b) > .x` | `.a` 또는 `.b`의 직계 자식 `.x` | 부모 OR + 자식 |
| `:where(.a, .b)` | `:is()`와 대상 같음 | 명시도 **0** |
| `:where(.a, .b) .x` | `.a` 또는 `.b` 안의 자손 `.x` | 특이도만 0 |
| `:has(.x)` | 자손 `.x`를 **가진** 요소 | 부모 방향 조건 |
| `.a:has(.x)` | 자손 `.x`를 가진 `.a` | |
| `:is(.a, .b):has(.x)` | 자손 `.x`를 가진 `.a` 또는 `.b` | |
| `:has(> .x)` | 직계 자식 `.x`를 가진 요소 | 한 단계만 |

## 찾아본 내용

### list-style

`<ul>` / `<ol>` 앞 불릿·번호 단축.

~~~css
list-style: <type> || <position> || <image>;
~~~

| 조각 | 역할 | 예 |
| --- | --- | --- |
| `list-style-type` | 기호·번호 | `disc` · `circle` · `square` · `decimal` · `none` |
| `list-style-position` | 박스 안/밖 | `outside`(기본) · `inside` |
| `list-style-image` | 기호 대신 이미지 | `url(...)` · `none` |

~~~css
ul { list-style: none; }           /* 불릿 제거 후 직접 디자인 */
ol { list-style-type: decimal; }   /* 번호 목록 */
~~~

- `none` = 기호만 제거. 들여쓰기는 `padding-left: 0`과 함께
- 교재 전용 단원 약함. 실습 `.task-list li { list-style: none; }`
- `color`는 불릿 색에도 적용될 수 있음

## 교재 보충

※ 아래 내용은 사용자의 필기를 보완하기 위해
교재에서 가져온 내용이다.

### Flex 축·자식 크기 (FE 3-1)

- `justify-content` = 주축 / `align-items` = 교차축
- grow / shrink / basis는 **자식에 개별** 설정

### Grid (FE 3-1)

- `fr` = 남은 공간 비율
- `gap: 행 열;` / `gap: 동일값;`
- `place-items` = align-items + justify-items 단축

### background-size (FE 2-1)

- `cover` : 채움(잘림 가능) / `contain` : 전체 보임(여백 가능)
- 단축 권장: color → image → repeat → attachment → position / size

### position (FE 2-2)

- `relative` : 원래 자리 + absolute 기준점
- `absolute` : ≠static 최근접 조상
- `fixed` : Viewport

## 필기 ↔ 교재 비교

| 항목 | 필기 | 교재 | 결과 |
|------|------|------|------|
| Flex 심화 | grow/shrink/basis/wrap | 동일 + 주축/교차축 | 교재 보충(축) |
| Grid | template·fr·gap·span·place | 동일 | 동일 |
| background contain | `background-contain : contain;` | `background-size: contain;` | 확인 필요 |
| position | +sticky·z-index | static·relative·absolute·fixed | sticky 확인 |
| line-height | 비율 1.2 등 | 단위 없는 숫자 권장 | 교재 보충 |
| word-break 값 | wrap/nowrap/break-all | FE 2-1 해당 절 없음 | 확인 필요 |
| outline | `none` | 전용 절 약함 | 필기 유지 |
| list-style | 찾아본 내용 | 실습 `none`만 | 필기 유지 |

## 확인이 필요한 사항

⚠ `background-contain : contain;` — 표준은 `background-size: contain;`. 속성명 오기 여부.

⚠ CSS 변수: `:root`는 `--primary-layerout-*`, `body`는 `var(--primary-layout-*)`. 이름 불일치 → 미적용 가능. 코드 원문 유지.

⚠ `word-break: wrap/nowrap` — 보통 `white-space` 쪽 값. 혼동 여부 확인.

⚠ `position: sticky` — FE 2-2는 static~fixed 위주. 수업 여부 확인.

⚠ 복습 2번 「상속 / Cascading」 — 교재는 상속≠캐스케이딩. 문항이 상속인지 확인용 병기.
