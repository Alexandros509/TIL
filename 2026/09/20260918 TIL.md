## 어제의 복습

1. CSS 구조(HTML)와 디자인(CSS)의 완전한 분리로 재사용성 및 유지보수성을 극대화할 수 있는 방식
   - 외부 스타일 시트
2. 한 요소에 여러 CSS 규칙이 충돌할 때, 선택자가 더 구체적이고 좁은 범위 타켓팅할수록 점수가 높게 산정되어 최우선 적용되는 규칙
   - 명시도
3. 부모 요소 font-size: 16px , 자식 요소 line-height: 1.5를 지정했을 때 실무에서 이 방식(단위 없는 숫자)을 권장하는 이유
   - 계산된 고정 픽셀값이 아닌 '비율' 자체가 상속되기 때문
4. box-sizing: border-box;가 적용된 요소의 width: 200px; padding: 20px; border: 5px solid red; 이 요소가 실제로 차지하는 가로 폭
   - 250px
5. Flexbox 자식 요소가 부모 공간의 남는 여백을 나누어 가지도록 확장 비율을 지정할 때 사용하는 속성명
   - flex-grow

## 오늘의 학습

~~~css
<meta name="viewport" content="width=device-width,initial-scale=1,minimum-scale=1,maximum-scale=1,user-scalable=no,interactive-widget=resizes-content">
~~~

### 뷰포트 (Viewport)

보이는 화면

**width**

- `device-width`
- `device-height`

**user-scalable**

- `yes` : 확대, 축소 가능
  - `minimum-scale` : 축소 비율
  - `maximum-scale` : 확대 비율
  - `initial-scale` : 처음 화면 비율
- `no` : 불가

### 브레이크 포인트

- 화면 레이아웃이 전환되는 기준 해상도
- CSS 적용이 달라짐
  - 모바일 (~767px)
  - 태블릿 (768px ~ 1023px)
  - 데스크탑 (1024px~)

### 미디어쿼리 `@media`

- `@media 미디어타입 and (미디어특성) {}`

**미디어타입**

- `all` (default)
- `screen`
- `print` : 인쇄 CSS
- `speech` : 시각 장애인용 스크린 리더 CSS

**미디어특성**

- `width` / `height`
- `min-width` : 화면이 크기 이상 On
- `max-width` : 화면이 크기 이하 On
- `orientation` : 기기 화면 방향
  - `portrait` : 세로
  - `landscape` : 가로

## 핵심 개념

- 뷰포트(Viewport): 보이는 화면. `width=device-width` 등 meta 설정
- 브레이크 포인트: 모바일(~767px) / 태블릿(768~1023px) / 데스크탑(1024px~)
- `@media 미디어타입 and (미디어특성) {}`
- 미디어타입: `all`, `screen`, `print`, `speech`
- 미디어특성: `width`/`height`, `min-width`, `max-width`, `orientation`

## 교재 보충

※ 아래 내용은 사용자의 필기를 보완하기 위해
교재에서 가져온 내용이다.

### 미디어 쿼리 정의 (FE 3-2)

접속한 기기의 특성(화면 타입, 가로 너비 등)을 브라우저가 감지하여, 지정된 조건에 부합할 때만 특정 CSS 스타일 규칙을 적용하는 기술.

### 문법 예시 (FE 3-2)

~~~css
@media screen and (min-width: 768px) {
  body { background-color: lightgreen; }
}
~~~

스크린이고 가로폭이 최소 768px 이상일 때 배경색을 연초록으로 바꾼다.

### 브레이크포인트 경계 조건 (FE 3-2)

| 디바이스 | 경계 조건 |
|----------|-----------|
| 모바일 | `max-width: 767px` |
| 태블릿 | `min-width: 768px` 및 `max-width: 1023px` |
| 데스크톱 | `min-width: 1024px` |

## 필기 ↔ 교재 비교

| 항목 | 필기 | 교재 | 결과 |
|------|------|------|------|
| 뷰포트 | meta `viewport` + `device-width` 등 | `width=device-width`로 기기 폭 일치 | 동일 |
| 브레이크포인트 | ~767 / 768~1023 / 1024~ | max 767 / min 768·max 1023 / min 1024 | 동일 |
| `@media` | 타입·특성 나열 | 정의 + 문법 예시 | 교재 보충 |
| Tailwind CSS | 없음 | CDN·유틸리티·반응형 접두사 | 필기 누락 가능성만 |

## 확인이 필요한 사항

⚠ 어제의 복습 4번: 필기 답 `250px`. `box-sizing: border-box`일 때 `width: 200px`에 `padding: 20px`, `border: 5px`이면 padding·border가 width 안에 포함되어 실제로 차지하는 가로 폭은 보통 `200px`로 본다. 필기 답은 유지. 계산(200+20×2+5×2=250 vs border-box 200) 확인 필요.

⚠ 뷰포트 샘플 코드 블록이 `~~~css`인데 내용은 HTML `<meta ...>`. fence 언어와 내용이 맞지 않음. 필기 표기(`~~~css`) 유지. `html`로 바꿀지 확인 필요.
