### 기본 연산자

**4.2 JavaScript 기초 문법 — 5. 기본 연산자**

1. 산술 및 복합 대입 연산자
   - 증가·감소 연산자 (`++`, `--`)
     - `++` : 1씩 증가
     - `--` : 1씩 감소
     - 전위(`++n`)는 더하고 대입, 후위(`n++`)는 대입하고 더함
2. 엄격한 일치 연산자
   - 동등성 비교 vs 동일성 비교
     - 동등성 비교 : `==`
     - 동일성 비교 : `===`
     - `!` → 부정연산 (참→거짓, 거짓→참)
     - `!=` → 다르다
     - `!==` → 주소가 다르다
     - `!=`는 타입 변환 후 값만 다르면 참, `!==`는 타입이나 값 중 하나라도 다르면 참
3. 논리 연산자
   - `&&` : AND 연산자
   - `||` : OR 연산자
   - `!` : NOT 연산자 (부정연산)

### 조건문과 단락 평가

**4.2 — 6. 제어문 · 조건문**

- 조건식 : 참·거짓을 판별하는 연산 식(비교·논리연산이 주로 쓰인다)

~~~javascript
if (조건식) {
    // 조건식 참일때 실행되는 구간
}

if (조건식) {
    // 조건식 참일때 실행되는 구간
} else if (...) {
    ...
} else if (...) {
    ...
} else { // 모든 조건이 거짓일때 실행되는 구간
    ...
}
~~~

- **삼항 조건식**
  - `변수 = (조건식) ? 참일때 실행되는 코드 값 : 거짓일 때 실행되는 코드나 값;`
- 값이 없을 때의 기본값 입력 (Short-circuit Evaluation 활용)

~~~javascript
name = name || "게스트";
console.log(`안녕하세요, ${name}님!`);
// greet(); // "안녕하세요, 게스트님!"
~~~

- `||` 연산자는 모든 Falsy값을 거짓으로 판단해 기본값으로 덮어쓰는 문제점 있음
- `??` : nullish 연산자
  - null, undefined일때만 판단
- `&&` : 단락회로평가를 이용한 간단한 조건식 수행
  - `message && console.log(message);`
  - `&&`는 앞이 참일 때만 뒤의 식을 실행하므로, `if (message)`를 대신하는 간결한 조건부 실행문 역할

### 반복문

**4.2 — 반복문 (for, while, do-while)**

1. `for (초기화식; 조건식; 증감식) { // 실행할 코드 }`
   - 순서의 의미가 강한 반복문은 관례적으로 변수명을 `i` (index)
   - 다음 변수명은 알파벳 순서 (`j`, `k`, `l`, `m`, ...)
   - `for (let i = 0, j=10; i < 10; i++, j--){ console.log("i=", i, "j=", j); }`
     1. 초기화식
        - 반복문 시작 시 최초 1회 실행
        - 카운터 변수의 시작값을 설정하는 식
     2. 조건식
        - 매 반복 전에 조건 검사하여 참이면 블록 내부 실행, 거짓이면 루프 종료
     3. 증감식
        - 조건을 멈추기 위한 숫자 증가·감소 식
        - 반복 변수를 변화시켜 언젠가 조건식을 만족하지 않게(종료되게) 만드는 식
   - `break` : 반복 중단
   - `continue` : 반복 건너뛰기
2. while
   - `while(조건식) { //조건식이 참일때 반복되는 구간 //반복을 중단시키는 코드가 있어야한다 - break와 함께 쓰인다 }`
3. do while
   - `do { //조건식이 참일때 반복되는 구간 } while(조건식);`
     - 조건식이 거짓이더라도 한번 실행을 보장

구구단 예 (단보다 곱하는 수가 클 때만 출력) — `if` / `continue`

~~~javascript
// if로 필터
for (let i = 2; i <= 9; i++) {
    console.log(`-------${i}단--------`);
    for (let j = 1; j <= 9; j++) {
        if (j > i) {
            console.log(i, "*", j, "=", i * j);
        }
    }
}

// continue로 건너뛰기
for (let i = 2; i <= 9; i++) {
    console.log(`-------${i}단--------`);
    for (let j = 1; j <= 9; j++) {
        if (i >= j) {
            continue // 반복 건너뛰기
        }
        console.log(i, "*", j, "=", i * j);
    }
}
~~~

### 예외 처리

**4.2 — 7. 예외 처리 (try - catch - finally)**

- `try { //예외가 발생할 가능성이 있는 코드 } catch(err) { //예외가 발생하면 유입되는 구간 - 대외적인 처리, err: 발생할 예외에 대한 정보 }`
- `throw` : 예외 발생 시키기 / `throw new` 예외 객체(Error의 하위 생성자 객체)
- `new` 연산자
- JavaScript stack = Python Traceback

~~~javascript
try {
    let str;
    const str2= str.toUpperCase();
    console.log(str2,"대문자 변경 완료");
} catch (err) {
    console.dir(err);
    console.error(err);
}

try {
    let str;
    const str2= str.toUpperCase();
    console.log(str2,"대문자 변경 완료");
} catch (err) {
    //console.dir(err);
    //console.error(err);
    console.log(err.message,err.name);
} finally {
    console.log("무조건 실행");
}
~~~

**4.3 객체 리터럴, 배열 및 내장 객체** (노트 범위: 객체 리터럴·프로퍼티까지)

객체란? (Object)

자바스크립트 객체

- 원시타입
- 객체타입
- 프로퍼티 (Property)
- 키 (Key)와 값 (Value)
- 빈 객체
1. `{ }`
   - `{ 키:값 , 키:값 , ... }`

프로퍼티 읽기와 조작 (추가, 수정, 삭제)

- 마침표(`.`) 연산자: 속성의 이름이 변수 이름 규칙에 해당하는 속성만 접근 가능
  - 변수명 규칙
    - 알파벳(대소문자), 숫자, `_` ,`$` 문자로만 구성

  - 함수명 관례
    - 변수명 관례와 동일
    - 함수 중에서 생성자로 사용되는 함수는 앞글자를 대문자로
- 대괄호(`[]`) 연산자 :
- 없는 프로퍼티 접근

### RunnableLambda (필기 메모)

- Runnable Lambda → 정의한 함수를 매개변수 넣어서 호출 → Runnable 객체
- 앞에 `@chain` 사용 시 뒤 함수들 자동
- 교재 귀속: 홈 LLM **4-4** (FE 4-2 / 4-3 본문 아님). 비교·확인만.

## 핵심 개념

- `++`/`--` : 전위는 더하고 대입, 후위는 대입하고 더함
- `==` 동등(값), `===` 동일(값+타입). `!=` / `!==`
- `&&` / `||` / `!` 논리. 기본값: `||`(모든 Falsy 덮어씀) vs `??`(null·undefined만)
- `&&` 단락: 앞이 참일 때만 뒤 실행 → 조건부 실행
- switch fall-through: case 일치 후 `break`까지 연속 실행
- for 3요소(초기화·조건·증감). while / do-while(최소 1회). `break`·`continue`
- try / catch / finally / `throw new` Error. JS stack ≈ Python Traceback
- 객체 리터럴 `{키:값}`. `.` vs `[]`. 변수명 규칙·카멜·상수 스네이크
- RunnableLambda / `@chain` : 필기 한 줄 메모 (LLM 4-4)

### FE 4-2 — 연산자·제어문·예외

- `===` / `!==` : 값과 **데이터 타입**까지 엄격 대조 (교재 표현). 필기 `!==`「주소가 다르다」와 표기 차이 → 확인
- switch: `break` 생략 시 Fall-through. `default`는 미일치 시 기본 블록
- for 3대 요소: 초기화(시작 1회) / 조건(매 회차 직전) / 증감(블록 직후)
- while: 조건 먼저 검사. 탈출 장치 없으면 무한 루프 위험
- do-while: 조건과 무관하게 **최소 1회** 실행 후 검사
- try 감시 → catch(err) 대응(`name` / `message` / `stack`) → finally 무조건 실행(선택)

### FE 4-3 — 객체 리터럴 (노트 시작 구간)

- 객체: Key–Value 쌍의 복합 타입. 빈 객체 `{}`
- `.` : `객체.키`. `[]` : `객체['키']` (문자열 키)
- 없는 프로퍼티 읽기 → `undefined`
- (교재 이어짐: 추가·수정·`delete`, `in`, 메서드·this, 참조 타입 — 필기에 없으면 본문 삽입 안 함)

## 필기 ↔ 교재 비교

| 항목 | 필기 | 교재 | 결과 |
|------|------|------|------|
| `++`/`--` 전위·후위 | 더하고 대입 / 대입하고 더함 | 산술·복합 대입 맥락 | 동일 방향 |
| `==` / `===` | 동등 / 동일 | 엄격 일치는 값+타입 | 동일 방향 |
| `!==` | 「주소가 다르다」 + 타입·값 중 하나라도 다르면 참 | 값+타입 엄격 불일치 | 확인 필요 |
| OR(`||`) 기본값 vs `??` | Falsy 전부 덮어씀 / null·undefined만 | 4-2 본문엔 `??` 비중 적음(필기 유지) | 필기 유지 |
| switch fall-through | break까지 연속 실행 | 동일 | 동일 |
| for / while / do-while | 3요소·최소 1회 | 동일 | 동일 |
| try-catch-finally / throw | 필기+코드 | 동일 구조 + err 속성 | 교재 보충 |
| 객체 `{}` · `.` / `[]` · 네이밍 | 필기 키워드 | 정의·접근·없는 키→undefined | 교재 보충 |
| 배열·내장 객체·메서드 | 제목만 / 본문 없음 | 4-3 후반 | 필기 누락 가능성 |
| RunnableLambda / `@chain` | 필기 2줄 | 홈 LLM 4-4 (FE 아님) | 비교·확인만 |

## 확인이 필요한 사항

⚠ `!==` 필기: 「주소가 다르다」와 「타입이나 값 중 하나라도 다르면 참」이 같이 적혀 있다. 교재 엄격 불일치(`!==`)는 **값+타입** 기준이고, 「주소」는 객체 참조 비교 맥락에서 쓰는 말에 가깝다. 표현을 엄격 불일치로 정리할지 확인.

⚠ 대괄호(`[]`) 연산자·없는 프로퍼티 접근: 필기에 제목만 있고 설명이 비어 있다. 교재는 `객체['키']`, 없는 키 → `undefined`. 수업에서 다루었으면 필기 보완.

⚠ RunnableLambda: FE 4-2/4-3이 아니라 홈 LLM **4-4**. 필기 한 줄만 유지. API 덤프는 하지 않음.

## 필기 누락 가능성

다음 내용은 교재(FE 4-3)에는 있으나 오늘 필기는 객체 리터럴·프로퍼티 접근·네이밍까지만이다. 수업에서 더 나갔다면 놓쳤을 수 있다.

- 프로퍼티 추가·수정·`delete`
- `in` 연산자, 메서드와 `this`, 객체 참조(Reference) 공유
- 배열 리터럴·length·메서드, 내장 객체, 래퍼 객체 (제목「배열 및 내장 객체」에만 해당)

※ 배열·내장 객체 본문은 필기에 없으므로 학습 본문에 창작하지 않았다.
