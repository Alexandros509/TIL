## 어제의 복습

1. 다음 코드의 실행 결과로 올바른 것을 고르세요.

~~~javascript
const original = { title: "자바북", score: 90 };
const target = original;
target.score = 100;
console.log(original.score);
~~~

   - 100
   - 객체는 참조 타입이므로 `target`에 `original`을 대입하면 동일한 객체의 메모리 주소(참조)가 복사됨

2. 배열 메서드 중 `splice`, `push`, `pop`처럼 원본 배열 자체를 직접 변경하는 메서드와 달리, `slice`, `map`, `filter`처럼 원본은 그대로 두고 새로운 배열이나 값을 반환하는 메서드를 통칭하는 용어(분류)
   - 접근자 메서드

3. 화살표 함수(Arrow Function)의 특징에 대한 설명으로 가장 올바른 것
   - 자체적인 `this`를 가지지 않고 선언 시점의 상위 스코프 `this`를 그대로 사용

4. 외부 함수의 실행이 종료되어 스택에서 제거된 뒤에도, 그 외부 함수가 반환한 내부 함수가 외부 함수의 지역 변수를 계속 참조할 수 있어 해당 변수가 메모리에서 소멸되지 않고 유지되는 현상
   - 클로저

5. `call`, `apply`, `bind` 메서드에 대한 설명으로 옳지 않은 것
   - `call`, `apply`, `bind` 모두 함수의 `this`를 변경할 수 없고 인수 전달 방식만 다르다.
   - 해설: `call`, `apply`, `bind`는 모두 함수 내부의 `this`를 개발자가 지정한 객체로 강제 바인딩하는 명시적 `this` 바인딩 도구입니다. 차이는 즉시 실행 여부와 인수 전달 방식(개별 나열 vs 배열 vs 지연 실행)에 있으므로, `this`를 변경할 수 없다는 설명은 틀렸습니다.

## 오늘의 학습

### 호스트 객체 · Window(BOM)

**호스트 객체**

- 런타임마다 다르게 구성되어 있는 특화 객체
- 웹 브라우저 객체: 브라우저의 기능과 밀접하게 관련

**Window와 하위 객체**

- `window`: 브라우저 창을 나타내는 최상위 전역 객체. 하위 내장 객체들을 프로퍼티로 포함
- Window 생략 규칙: `window.location`, `window.document`가 원칙이지만, 전역 객체이므로 `location`, `document`만 써도 동일

하위 객체 한 줄 정리

- `location` — 주소창(URL) 정보·이동
- `history` — 방문 기록 단계
- `screen` — 모니터 화면 해상도·크기
- `navigator` — 브라우저·OS 사용 환경, 기타 API
- `document` — HTML 문서 정보·기능

콘솔 tip: `location`을 치면 현재 URL 관련 정보를 바로 볼 수 있어 유용하다.

#### location 객체

주소창과 관련된 정보·기능 제공

- **실시간성**: 속성 변경 내용이 실제 주소창에 반영됨
- `location.href` — 속성을 변경하면 페이지 이동
- `assign(이동 주소)` — 지정 주소로 이동, **새 기록 추가**(방문 기록 남김) → 뒤로 가기 가능
- `replace(...)` — 지정 주소로 이동, **현재 기록 덮어쓰기**(방문 기록 추가 X) → 뒤로 가기 불가능
- `reload(...)` — 페이지 새로고침

※ `assign` vs `replace` 대비: 이력 남김 여부.

#### history 객체

방문 기록과 관련된 기능 제공

- `length` — 방문 기록(세션에 쌓인 페이지 개수)
- `scrollRestoration` ※ 필기(교재 미언급)
  - `auto` — 스크롤 위치 기억·복구
  - `manual` — 복구 X
- `back()` — 한 단계 뒤로 가기
- `forward()` — 한 단계 앞으로 가기
- `go()` — 숫자만큼 이동(음수·양수)

#### screen / navigator / document (한 줄)

- `screen` — 브라우저가 쓰는 화면(디스플레이) 정보. 교재: `width`/`height`(전체 해상도), `availWidth`/`availHeight`(작업 표시줄 등 제외 가용 영역)
- `navigator` — 브라우저·OS 사용 환경. 교재: `userAgent`, `language`, `onLine` 등
- `document` — HTML 문서와 관련된 정보·기능 제공

### Document 객체 · DOM

1. **DOM Tree** — 빠른 요소 탐색에서 필요. 브라우저가 HTML을 분석해 계층으로 연결한 Document Object Model
2. 요소(DOM)를 선택하는 방법

#### 아이디(id)로 선택

- `document.getElementById("아이디명")`
- 단일 선택

#### 클래스(class)로 선택

- `document.getElementsByClassName("클래스명")`
- 복수 선택 (`Elements`)

#### 태그 이름으로 선택

- `document.getElementsByTagName("태그명")`

#### name 속성으로 선택

- `document.getElementsByName("Name 속성명")`

#### CSS 선택자로 선택

- `document.querySelector("CSS 선택자")` → 첫 번째 요소 1개 선택
- `document.querySelectorAll("CSS 선택자")` → 복수 개 선택

#### 문서 전체 (html)

- `window.document`
  - `head` — `window.document.head` (또는 `document.head`)
  - `body` — `window.document.body` (또는 `document.body`)

#### 양식(form) 이름 — `frmNIDLogin`

- 양식 하위 입력 태그는 이름으로 바로 접근
- 예시) `frmNIDLogin.id`
- (교재 단축: `document.폼이름.입력항목이름` 또는 `폼이름.입력항목이름`)

#### 요소 노드 (상대적 접근) — Element* 계열

※ 공백·텍스트 노드를 건너뛰고 **HTML 요소만** 탐색하는 프로퍼티

- `parentElement` — 부모 요소
- `children` — 자식 요소들(유사 배열)
- `firstElementChild` — 첫 번째 자식 요소
- `lastElementChild` — 마지막 자식 요소
- `nextElementSibling` — 다음 형제 요소
- `previousElementSibling` — 이전 형제 요소

### 요소의 추가 정보 — 속성(Attribute)

수신 대상은 **선택해 둔 요소(`element`)** 기준이다. (`document.`가 아님)

1. `element.getAttribute("속성명")` — 속성 조회
2. `element.setAttribute("속성명", "속성값")` — 속성 추가/변경
3. `element.removeAttribute("속성명")` — 속성 제거
4. `element.hasAttribute("속성명")` — 속성 존재 여부
5. 많이 쓰는 속성은 프로퍼티로 바로 접근 가능
   - `id`, `type`, `src`, `href`, `target`, `action` …
   - `className`, `style`

### 데이터 속성 (`data-*`)

- ★중요★ `element.dataset` — dataset 객체로 접근
- HTML 속성 ↔ JS 프로퍼티 변환(카멜 케이스)
  - HTML: `data-product-cnt`
  - JS: `element.dataset.productCnt`
- (필기 메모 「productCnt → product-cnt」는 HTML 쪽 `data-product-cnt` 형태를 가리킴)

### 클래스 속성 — `element.classList`

- `element.classList`로 클래스 목록을 추가·삭제·토글·조회
- 메서드: `add` / `remove` / `toggle` / `contains` (상세는 「교재 보충」표)

- `screen` / `navigator` / `document` 한 줄 역할

## 교재 보충

※ 아래 내용은 사용자의 필기를 보완하기 위해 교재에서 가져온 내용이다.

### Window 하위 객체 (FE_13 §2.1)

| 하위 객체 | 역할 |
|---|---|
| `document` | 페이지 HTML 문서·내용물 구조 |
| `location` | 주소창(URL) 경로·이동 |
| `history` | 탭 방문 기록 단계 |
| `navigator` | 브라우저 종류·언어·기기 사양 |
| `screen` | 모니터 해상도·크기 |

### Location 핵심 프로퍼티 · 메서드 (FE_13 §4)

기준 예: `http://www.example.com:80/test/index.html?q=value#anchor`

| 종류 | 이름 | 설명 / 예 |
|---|---|---|
| 프로퍼티 | `href` | 전체 URL 취득·수정 |
| | `protocol` | `"http:"` |
| | `hostname` | `"www.example.com"` (포트 제외) |
| | `port` | `"80"` |
| | `pathname` | `"/test/index.html"` |
| | `search` | `"?q=value"` |
| | `hash` | `"#anchor"` |
| 메서드 | `assign(url)` | 이동 + 이력 남김 → 뒤로 가기 가능 |
| | `replace(url)` | 현재 이력 덮어쓰기 → 뒤로 가기 불가 |
| | `reload()` | 새로고침 |

### History (FE_13 §4.3)

| 이름 | 설명 |
|---|---|
| `history.length` | 탭 세션 총 방문 페이지 수 |
| `history.back()` | 한 단계 이전 |
| `history.forward()` | 한 단계 다음 |
| `history.go(number)` | 정수만큼 이동 (예: `go(-3)`) |
| `history.pushState(...)` | 새로고침 없이 세션에 상태·URL 추가 (선택) |

### Navigator / Screen 주요 프로퍼티 (FE_13 §5)

| 객체 | 프로퍼티 | 설명 |
|---|---|---|
| `navigator` | `userAgent` | UA 식별 문자열(브라우저 판별) |
| | `language` | 기본 언어 코드 (`"ko"` 등) |
| | `onLine` | 네트워크 연결 여부(Boolean) |
| `screen` | `width` / `height` | 디스플레이 전체 해상도 |
| | `availWidth` / `availHeight` | 작업 표시줄 등 제외 가용 해상도 |

### DOM 요소 선택 (FE_14 §2)

| 메서드 | 기준 | 단수/복수 | 반환 힌트 |
|---|---|---|---|
| `getElementById` | id | 단수 | Element 1개 |
| `getElementsByClassName` | class | 복수 | HTMLCollection (Live) |
| `getElementsByTagName` | 태그명 | 복수 | HTMLCollection (Live) |
| `getElementsByName` | name | 복수 | NodeList |
| `querySelector` | CSS 선택자 | 단수(첫 번째) | Element 1개 |
| `querySelectorAll` | CSS 선택자 | 복수 | 정적 NodeList |

### 요소 노드 상대 탐색 — Element* (FE_14 §1.3)

| 프로퍼티 | 설명 |
|---|---|
| `parentElement` | 부모 HTML 요소 |
| `children` | 자식 HTML 요소 목록(유사 배열) |
| `firstElementChild` / `lastElementChild` | 첫/마지막 자식 요소 |
| `nextElementSibling` / `previousElementSibling` | 다음/이전 형제 요소 |

### Attribute 메서드 (FE_14 §3.1)

| 메서드 | 설명 |
|---|---|
| `element.getAttribute("속성명")` | 속성 값 조회 |
| `element.setAttribute("속성명", "값")` | 설정·수정 |
| `element.hasAttribute("속성명")` | 존재 여부 |
| `element.removeAttribute("속성명")` | 삭제 |

### classList 메서드 (FE_13 §6.2 / FE_14 §6.2)

| 메서드 | 설명 |

## 필기 ↔ 교재 비교

| 항목 | 필기 | 교재 | 결과 |
|------|------|------|------|
| 호스트 객체 | 런타임별 특화 객체로 정의 | 「호스트 객체」절 없음. Window 하위(BOM)로 설명 | 필기 정의 유지 · 비교만 |

| Attribute 수신자 | 필기 `document.getAttribute`… | `element.getAttribute`… | 본문에서 element로 교정 |
| `dataset` / camelCase | ★·productCnt↔product-cnt | 교재 거의 미다룸 | 필기 유지·표기 정리 |
| classList | 추가·수정·삭제·조회 | add/remove/toggle/contains | 본문+보충 표 |
| Form 단축 | `frmNIDLogin.id` | `document.폼이름.입력항목` | 동일 계통 |

## 확인이 필요한 사항

⚠ 「호스트 객체」용어 — 필기 정의 vs 교재 Window/BOM 프레이밍. 수업에서 호스트 객체로 불렀는지 확인.

⚠ `scrollRestoration` — 필기에만 있음. 수업 보충인지 개인 메모인지 확인.

⚠ 필기 Attribute/`dataset`/`classList`를 `document.`로 적은 부분 — API 수신자는 element. 교정본 기준으로 복습할지 원문 표기 유지할지.

⚠ `dataset` 변환 방향 — 필기 「productCnt → product-cnt」는 HTML `data-product-cnt` ↔ `dataset.productCnt`로 해석해 둠. 수업 슬라이드 표기와 맞는지.

## 필기 누락 가능성

오늘 교재(FE_13/14)에 있으나 필기에 없거나 키워드만인 항목(수업에서 다뤘다면 놓쳤을 수 있음).

- `history.pushState` (FE_13 §4.3)
- Location 세부 프로퍼티 전체(`protocol`/`hostname`/`port`/`pathname`/`search`/`hash`) — 필기는 href·메서드 중심
- Live Collection vs 정적 NodeList 주의(FE_14 §2)
- 공백(텍스트) 노드 vs Element* 탐색 대비(FE_14 §1.3 Node 계열)
- `innerHTML` / `textContent` (FE_14 §3.2) — 속성 절 인접이나 필기 없음

※ FE_13 §1 렌더링/async, §3 팝업/SOP, FE_14 §4 노드 생성·삭제, §5 좌표는 **오늘 필기 범위 밖**으로 본문에 넣지 않음.
