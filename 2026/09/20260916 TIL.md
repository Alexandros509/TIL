## 오늘의 학습

### CSS

**1. 기본 선택자**

- 전체 (`*`)
- 태그
- 클래스
- 아이디

**1) 적용 우선 순위**

- 전체 < 태그 < 클래스 < 아이디 < style

**2. 복합 관계 선택자**

- 하위 ` `
- 자식 `>`
- 일반 형제 `~`
- 인접 형제 `+`
- 그룹 `,`
- 속성 `[속성명]` : 지정된 속성이 있으면 선택
  - 다른 선택자와 조합을 통한 선택 주로 사용
    - `선택자[속성명]`
  - `[속성명="값"]` : 속성의 값이 일치하는 요소 선택
  - `[속성명^="값]` : 속성의 값으로 시작하는 요소 선택
  - `[속성명$="값]` : 속성의 값으로 끝나는 요소 선택
  - `[속성명*="값]` : 속성의 값이 포함된 요소 선택

**3. 가상 클래스 선택자**

**1. 가상 선택자 (위치)**

- `:first-child` 첫 번째 자식 요소
- `:last-child` 마지막 자식 요소
- `:nth-child` n번째 자식 요소
  - `:nth-child(num)` : 숫자 위치에 있는 요소 선택
  - `:nth-child(수식)` : 수식에 해당하는 요소 선택
- `같은 자식 요소, 타입 무관`
- `:first-of-type`
- `:last-of-type`
- `:nth-of-type`
- `:only-of-type` : 자식 요소 1개만 있는 경우 선택
- `같은 타입 요소`

**2. 조건 선택자**

- `:not(선택자)` : 지정된 선택자가 아닌 요소 선택
- `:is(선택자1,선택자2,...)` 자식선택자 : 상위요소 그룹 → 하위 요소를 선택

**3. 상태 선택자**

- `:hover` : 마우스가 요소에 올라간 상태
- `:focus` : 특정 요소가 선택, 커서(input)가 있는 상태
- `:blur` : `:focus` <> `:blur`
- `:checked` : 체크된 상태
- `:readonly` : 읽기 전용상태
- `:disabled` : 비활성화
- `:enabled` : `:disabled` <> `:enabled`

**4. 요소 추가 선택자**

- 반드시 추가할 내용이 있어야 노출, `content` 필수
- inline 속성
- 선택자 `::___`
  - `::before` : 자식의 첫번째 요소로 추가
  - `::after` : 자식의 마지막 요소로 추가
  - `::placeholder` : 가이드라인 텍스트
  - `::selection` : 선택된 영역

  - `pt` : 인쇄 기준

  - `em` : 폰트 사이즈가 지정된 상위 태그
  - `rem` : 가장 상위 태그의 글자 사이즈가 기준 (`html` 태그에 설정된 px이 1 rem)
    - root element

### CSS 박스 모델

![css_box_model](../../images/Chapter%2007/CSS_Box_model.png)

- 콘텐츠 (Content)
  - 기본 설정으로 너비(`width`)와 높이(`height`)의 기준
  - 내부 여백이나 경계선을 지정하면 박스의 크기는 커진다
- `padding`
  - 내부 여백
  - 경계선 안쪽
- `margin`
  - 외부 여백
  - 경계선 바깥쪽

**box-sizing** : 너비와 높이의 기준

1. `content-box` (기본값)
   - 내용영역 (content) 기준
   - 밖으로 확장
2. `border-box`
   - 경계선(border)이 기준
   - 내부 여백 (`padding`) , 경계선의 두께 변경
   - 내용 영역의 크기가 변경
   - 안으로 파고듦

**외부 여백 (margin)**
- block 속성 태그 : 제한 X
- inline 속성 태그 : 위, 아래 여백 X, 좌우 여백 O
- `margin: 상 우 하 좌;`
- `margin: 상 좌우 하;`
- `margin: 상하 좌우;`
- `margin: 값;` (모든 방향 동일)
  - 예) `margin: 100px auto;` (상하 100px, 좌우 균등 분배)
  - top
    - 예) `margin-top: 50px;`
  - bottom
  - left
  - right

`padding` 도 축약 순서 동일
### Display

1. `block` → block이 아닌 속성 → block
2. `inline` → inline이 아닌 속성 → inline
3. `inline-block`
   - 줄 개행 X - 공간 O, 외부여백
4. `none` → 감추기
   - `visibility`
     - `visible` (기본값)
     - `hidden` : 감추기 (공간은 유지)

### Flexbox (1차원 정렬)

- 설정 - 부모요소
  - `:display:flex;`
- 적용 - 자식요소
- 정렬 방향
  - `flex-direction`
    - `row`(기본값) : 좌 → 우
    - `row-reverse` : 우 → 좌
    - `column` : 위 → 아래
    - `column-reverse` : 아래 → 위
- 정렬 속성 제어
  - `justify-content`
    1. `flex-start` : 왼쪽 정렬 (기본값)
    2. `flex-end` : 오른쪽
    3. `center` : 가운데
    4. `space-between` : 좌우 요소 1개를 끝에 배치 , 나머지 요소 공백 균등 부여
    5. `space-around` : 각 요소 주위 동일 공백 부여
    6. `space-evenly` : 공평하게
- `align-items` : 자식 요소들의 위치배치
  - `stretch` (기본값) : 부모 요소의 크기에 맞춰 늘리는 것
  - `flex-start` : 위쪽 배치
  - `flex-end` : 아래쪽 배치
  - `center` : 가운데 배치

## 찾아본 내용

**1. 목록 태그 약자 및 역할**

- **`<ul>` (Unordered List):** 순서가 중요하지 않은 불릿 목록
- **`<ol>` (Ordered List):** 순서가 있는 번호 목록
- **`<li>` (List Item):** `<ul>`, `<ol>`의 개별 항목 요소
- **`<dl>` (Description List):** 용어와 설명이 짝을 이루는 목록
  - `<dt>` (Description Term): 용어/제목
  - `<dd>` (Description Details): 상세 설명

**2. `<span>` 태그의 특징**

- **인라인 제네릭 컨테이너:** 의미(Semantic)나 기본 스타일이 없는 인라인 요소
- **용도:** 문장 내 특정 단어/구절에 CSS 스타일링이나 JS 이벤트를 적용할 때 그룹화
- **특성:** 줄바꿈 없이 텍스트 흐름 유지, 콘텐츠 크기만큼 너비 차지 (너비/높이 속성 미적용)
- **`<div>`와의 차이:** `<div>`는 레이아웃 분할용 **블록** 요소, `<span>`은 텍스트 부분 제어용 **인라인** 요소

**3. CSS 속성 선언 순서 컨벤션**

- 실무에서는 보통 **Outside-In** 기준으로 정렬
- 레이아웃 배치 → 박스 모델 → 박스 외형 → 타이포그래피 → 효과 및 상호작용

**1. 레이아웃 배치 (Layout & Positioning)**

- 요소의 **배치 방식과 위치** 결정
- `display`, `position`, `top/right/bottom/left`, `z-index`

**2. 박스 모델 (Box Model)**

- 요소의 **크기와 안팎 여백** 결정
- `width`, `height`, `margin`, `padding`, `box-sizing`

**3. 박스 외형 (Box Appearance)**

- 요소의 **경계, 배경, 그림자 등 시각적 형태** 결정
- `border`, `border-radius`, `background`, `box-shadow`

**4. 타이포그래피 (Typography)**

- 요소 내부 **텍스트의 크기, 굵기, 색상, 정렬** 결정
- `font-*`, `line-height`, `color`, `text-align`

**5. 효과 및 상호작용 (Effects & Interaction)**

- 요소의 **시각 효과, 동작, 애니메이션** 결정
- `opacity`, `overflow`, `cursor`, `transform`, `transition`, `animation`

**핵심 원칙**

- CSS 속성 순서는 문법적으로 강제되지 않는 **컨벤션**
- **Outside-In:** 레이아웃 → 박스 모델 → 외형 → 타이포그래피 → 효과
- 구조에 큰 영향을 주는 속성부터 세부 시각 효과 순으로 정렬

**4. HTML `<head>` vs `<body>` 핵심 비교**

**1. `<head>` : 문서 메타데이터 (비시각적 영역)**

- **역할:** 브라우저 엔진, 검색 엔진(SEO), 소셜 미디어 크롤러를 위한 설정값 전달
- **핵심 요소:**
  - `<title>` : 브라우저 탭 제목, 검색 결과 노출명
  - `<meta>` : 인코딩(`charset`), 반응형 뷰포트(`viewport`), 검색 엔진 요약 및 SNS 공유 카드(`og:*`)
  - `<link>` : 외부 리소스 연결 (CSS 파일, 파비콘, 웹 폰트)
  - `<style>` : 내부 CSS 선언

**2. `<body>` : 화면 콘텐츠 (시각적 영역)**

- **역할:** 사용자가 브라우저 뷰포트에서 직접 보고 상호작용하는 모든 요소
- **핵심 요소:**
  - **구조/레이아웃:** `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`
  - **콘텐츠/서식:** `<h1>`~`<h6>`, `<p>`, `<a>`, `<img>`, `<ul>`/`<ol>`
  - **사용자 입력:** `<form>`, `<input>`, `<button>`
  - `<script>` : 화면 조작 JS 로드 (HTML 렌더링 차단 방지를 위해 주로 `<body>` 닫는 태그 직전에 배치)

**3. 한 줄 구분 기준**

- **`<head>`:** "브라우저야, 이 문서는 **이런 규칙과 설정**으로 읽고 꾸며줘."
- **`<body>`:** "사용자야, 화면에 **이 내용**을 봐줘."

**5. CSS 명시도(우선순위)와 가상 클래스 vs 가상 요소**

**1. 명시도(Specificity) 점수**

충돌 시 `[ID, Class, Type]` 3자리 합산.
점수가 같으면 나중에 선언된 스타일(캐스케이딩)이 반영.

| 가중치 | 대상 선택자 | 점수 (비유) |
| --- | --- | --- |
| 최상위 | `!important` > 인라인 `style="..."` | 논외 / 1000점 |
| ID | `#header`, `#app` | 1-0-0 (100점) |
| Class급 | 일반 클래스(`.box`), 속성 선택자(`[type="text"]`), 가상 클래스(`:hover`, `:first-child`) | 0-1-0 (10점) |
| Type급 | 태그 이름(`div`, `p`, `li`), 가상 요소(`::before`, `::after`) | 0-0-1 (1점) |

**2. 가상 클래스 vs 가상 요소**

**가상 클래스 (`:`)** — 상태·구조

- 문법: 콜론 1개 (`:`)
- 명시도: 클래스와 동일 10점 (`0-1-0`)
- 역할: HTML 구조를 건드리지 않고, 특정 상태·순서·조건을 만족하는 요소를 선택
- 종류
  - 구조: `:first-child`, `:last-child`, `:nth-child(n)`, `:nth-of-type(n)`
  - 상태: `:hover`, `:active`, `:focus`, `:checked`, `:disabled`
  - 조건: `:not(...)`, `:is(...)` (자체 점수 0점, 괄호 안 인자 점수 반영)

**가상 요소 (`::`)** — 가상 DOM·콘텐츠 삽입

- 문법: 콜론 2개 (`::`) (과거 호환으로 1개도 동작, 웹 표준은 2개 권장)
- 명시도: 태그(Type)와 동일 1점 (`0-0-1`)
- 역할: HTML 마크업 없이 CSS로 텍스트·박스 영역을 생성하거나 특정 부위를 타깃
- 종류: `::before`, `::after` (`content` 필수), `::placeholder`, `::selection`

**3. 실전 점수 계산**

- `li:first-child` → 태그(1) + 가상 클래스(10) = 11점 (`0-1-1`)
- `li.active` → 태그(1) + 일반 클래스(10) = 11점 (`0-1-1`)
  - 점수가 같으면 나중에 적힌 코드가 이김
- `li::after` → 태그(1) + 가상 요소(1) = 2점 (`0-0-2`)
- `.card:hover::before` → 클래스(10) + 가상 클래스(10) + 가상 요소(1) = 21점 (`0-2-1`)

**4. 한 줄**

- 가상 클래스(`:`) : 상태·순서를 고르는 클래스급(10점) 선택자
- 가상 요소(`::`) : 없는 요소를 새로 띄우는 태그급(1점) 선택자

## 핵심 개념

- 기본 선택자 우선순위: 전체 < 태그 < 클래스 < 아이디 < style
- 복합 관계 선택자: 하위(` `), 자식(`>`), 형제(`~`/`+`), 그룹(`,`), 속성(`[ ]`)
- 가상 클래스(`:`) vs 가상 요소(`::`) — `content` 필수인 `::before`/`::after`
- 박스 모델: Content / padding / margin, `box-sizing`(`content-box`·`border-box`)
- Display: `block` / `inline` / `inline-block` / `none` vs `visibility: hidden`
- Flexbox: 부모 `display:flex`, `flex-direction`, `justify-content`, `align-items`

### CSS 기본 문법 (FE 2-1)

- 형태: `선택자 { 속성: 값; }`
- 선택자 = 대상, 속성 = 바꿀 성질(`color`, `font-size` 등), 값 = 수치·형식

### 복합 선택자 한 줄 (FE 2-1)

- 자식(`>`) : 바로 한 단계 아래만
- 하위(공백) : 깊이 무관 모든 후손
- 인접 형제(`+`) : 바로 다음 동생 하나
- 일반 형제(`~`) : 뒤에 오는 같은 레벨 형제 전부

### 가상 클래스 vs 가상 요소 (FE 2-1)

- `:` 가상 클래스: 상태·조건 선택 (구조는 그대로)
- `::` 가상 요소: 없는 텍스트·박스를 CSS로 삽입 (`content` 필수)

### 박스 4대 요소 (FE 2-2)

- Content → Padding → **Border** → Margin (안쪽→바깥)
- `display: none` : 공간까지 제거 / `visibility: hidden` : 보이지 않되 공간 유지

### Flexbox 축 (FE 3-1)

- 부모에 `display: flex` 설정 후 자식에 정렬이 적용됨
- `justify-content` : 주축(메인 축) 정렬
- `align-items` : 교차 축 정렬

## 필기 ↔ 교재 비교

| 항목 | 필기 | 교재 | 결과 |
|------|------|------|------|
| 기본·복합 선택자 | 기호·우선순위 나열 | 동일 + 정의·예시 | 교재 보충 |
| 속성 선택자·그룹 `,` | 필기에 있음 | FE 2-1 복합 절에 미기재 | 필기 유지 |
| 상태 선택자 | `:blur`, `:readonly` 포함 | `:hover`/`:active`/`:focus`/`:checked`/`:disabled`/`:enabled` | 확인 필요 |
| 요소 추가(`::`) | 「가상 클래스」 하위 | 가상 요소로 별도 구분 | 필기 구조 유지 |
| color / font-size | 색상·단위 | 동일 + font-family·weight 등 | 필기 범위 유지 |
| 박스·box-sizing·display | Content/padding/margin, 두 box-sizing | 4대 요소(+border), 동일 | 교재 보충 |
| Flexbox | direction·justify·align | 동일 + 주축/교차축·flex-wrap | 교재 보충(축) / wrap은 누락 가능 |
| Grid | 없음 | FE 3-1에 Grid 절 | 필기 누락 가능성만 |

## 확인이 필요한 사항

⚠ 속성 선택자 `[속성명^="값]`, `[속성명$="값]`, `[속성명*="값]` : 닫는 따옴표가 없음. `="값"]` 형태인지 확인 필요. 필기 표기 유지.

⚠ `:blur`를 상태 선택자로 적음. 교재 상태 선택자는 `:hover`/`:active`/`:focus` 등. CSS 가상 클래스인지, `:focus` 대비 개념 메모인지 확인 필요.

⚠ `:readonly` 표기. 교재에는 해당 가상 클래스 목록 없음. HTML `readonly` 속성과 CSS `:read-only` 중 무엇을 뜻하는지 확인 필요.

⚠ Flex 설정 표기 `` `:display:flex;` ``. 교재·표준은 `display: flex;`. 콜론 앞 오타 여부 확인 필요. 필기 표기 유지.

⚠ 박스 모델 이미지 경로 `../../../images/Chapter%2007/CSS_Box_model.png` — 저장소/미리보기에서 404 날 수 있음. 경로 원문 유지.

⚠ 필기에서 `::before`/`::after`를 「가상 클래스 선택자 → 요소 추가」아래로 둠. 교재는 가상 요소(`::`)로 구분. 구조는 필기 유지.
