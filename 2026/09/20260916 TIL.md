## 오늘의 학습

### 선택자

**기본**

- `*` / 태그 / 클래스 / 아이디
- 우선순위: 전체 < 태그 < 클래스 < 아이디 < style

**복합 관계**

| 기호 | 의미 |
|------|------|
| ` ` (공백) | 하위(자손) |
| `>` | 자식 |
| `~` | 일반 형제 |
| `+` | 인접 형제 |
| `,` | 그룹 |
| `[속성]` | 속성 있음 · `[속="값"]` 일치 · `^=` 시작 · `$=` 끝 · `*=` 포함 |

**가상 클래스 (`:`)**

- 위치: `:first-child` / `:last-child` / `:nth-child` · `:*-of-type` / `:only-of-type`
- 조건: `:not()` / `:is()`
- 상태: `:hover` / `:focus` / `:blur`(필기) / `:checked` / `:readonly`(필기) / `:disabled` / `:enabled`

**가상 요소 (`::`) — 필기는 「요소 추가」로 묶음**

- `content` 필수 · inline
- `::before` / `::after` / `::placeholder` / `::selection`

### 텍스트·폰트

| 속성 | 한 줄 |
|------|------|
| `color` | 색상명 / `rgb` / HEX(`#FF0000`→`#F00`) / `rgba`(Alpha) |
| `font-size` | 절대 `px`·`pt` / 상대 `em`(상위) · `rem`(`html`=1rem) |

### 박스 모델

![css_box_model](../../images/Chapter%2007/CSS_Box_model.png)

- Content — width/height 기본 기준. padding·border 넣으면 박스 커짐
- `padding` — 경계선 안쪽 여백
- `margin` — 경계선 바깥. block 제한 X / inline은 상하 X·좌우 O
- 축약: `상 우 하 좌` · `상 좌우 하` · `상하 좌우` · `값` / `margin: 100px auto;`

**box-sizing**

| 값 | 의미 |
|----|------|
| `content-box`(기본) | content 기준 · 밖으로 확장 |
| `border-box` | border 기준 · padding·border가 안으로 · 실무 권장 |

### Display

| 값 | 의미 |
|----|------|
| `block` | 블록화 |
| `inline` | 인라인화 |
| `inline-block` | 줄 개행 X · 공간·여백 O |
| `none` | 감춤(공간 제거) |
| `visibility: hidden` | 감춤(공간 유지) |

### Flexbox (입문)

※ grow·shrink·basis·wrap·Grid는 다음날(09-17)에서 심화.

- 부모: `display: flex;` (필기 `` `:display:flex;` `` — 확인 항)
- 자식에 정렬 적용
- **flex-direction**: `row`(기본) / `row-reverse` / `column` / `column-reverse`
- **justify-content**: start·end·center · `space-between`·`around`·`evenly`
- **align-items**: `stretch`(기본) / start·end·center

## 찾아본 내용

**목록 태그**

- `<ul>` 불릿 / `<ol>` 번호 / `<li>` 항목 / `<dl>`+`<dt>`+`<dd>` 용어·설명

**`<span>`**

- 의미 없는 인라인 컨테이너. 텍스트 일부 스타일·이벤트용
- `<div>`=블록 레이아웃 / `<span>`=인라인 부분

**CSS 선언 순서 (Outside-In 컨벤션)**

1. 레이아웃: `display`·`position`·좌표·`z-index`
2. 박스: `width`·`height`·`margin`·`padding`·`box-sizing`
3. 외형: `border`·`radius`·`background`·`box-shadow`
4. 타이포: `font-*`·`line-height`·`color`·`text-align`
5. 효과: `opacity`·`overflow`·`cursor`·`transform`·`transition`·`animation`

**`<head>` vs `<body>`**

- head: 메타·title·link·style (비시각)
- body: 화면 콘텐츠·시멘틱·폼·script(보통 하단)

**명시도 · 가상 클래스 vs 가상 요소**

| 가중치 | 대상 | 점수 비유 |
|--------|------|-----------|
| 최상위 | `!important` > 인라인 | 논외 / 1000 |
| ID | `#id` | 1-0-0 |
| Class급 | `.class` · `[attr]` · `:hover` 등 | 0-1-0 |
| Type급 | 태그 · `::before`/`::after` | 0-0-1 |

- `:` 가상 클래스 = 상태·구조 (클래스급)
- `::` 가상 요소 = 가상 DOM·삽입 (태그급, `content` 필수)

## 핵심 개념

- 선택자 우선순위: 전체 < 태그 < 클래스 < 아이디 < style
- 복합: 공백·`>`·`~`·`+`·`,`·`[ ]`
- `:` vs `::` — `::before`/`::after`에 `content` 필수
- 박스: Content/padding/margin · `box-sizing`
- Display: block·inline·inline-block·none vs visibility
- Flex 입문: 부모 flex · direction · justify · align (심화는 다음날)

## 교재 보충

※ 아래 내용은 사용자의 필기를 보완하기 위해
교재에서 가져온 내용이다.

### 선택자 (FE 2-1)

- 형태: `선택자 { 속성: 값; }`
- `>` 바로 한 단계 / 공백 모든 후손 / `+` 다음 동생 하나 / `~` 뒤 형제 전부
- `:` 상태·조건 / `::` 삽입(`content` 필수)

### 박스 (FE 2-2)

- Content → Padding → **Border** → Margin
- `none` = 공간 제거 / `visibility: hidden` = 공간 유지

### Flex 축 (FE 3-1) — 입문만

- `justify-content` = 주축 / `align-items` = 교차축

## 필기 ↔ 교재 비교

| 항목 | 필기 | 교재 | 결과 |
|------|------|------|------|
| 기본·복합 선택자 | 기호·우선순위 | 동일 + 정의 | 교재 보충 |
| 속성 선택자·`,` | 필기 있음 | FE 2-1 복합 절 미기재 | 필기 유지 |
| 상태 선택자 | `:blur`·`:readonly` 포함 | hover/active/focus/checked/disabled/enabled | 확인 필요 |
| `::` 위치 | 「가상 클래스 → 요소 추가」 | 가상 요소 별도 | 필기 구조 유지 |
| 박스·display | Content/padding/margin·두 box-sizing | 4대(+border) | 교재 보충 |
| Flex | direction·justify·align (입문) | +주축/교차축·wrap·grow | 09-17로 심화 분리 |
| Grid | 없음 | FE 3-1 | 필기 누락·09-17 |

## 확인이 필요한 사항

⚠ `[속성명^="값]` 등 닫는 따옴표 누락. `="값"]`인지 확인. 필기 유지.

⚠ `:blur` / `:readonly` — 교재 상태 목록과 다름. 가상 클래스인지 메모인지 확인.

⚠ `` `:display:flex;` `` — 표준 `display: flex;`. 필기 표기 유지.

⚠ 박스 이미지 경로 404 가능. 원문 유지.

⚠ `::before`/`::after`를 가상 클래스 하위에 둠. 교재는 가상 요소. 구조 필기 유지.
