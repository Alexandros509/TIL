## 어제의 복습

1. LLM이 사전 학습된 데이터의 범위를 벗어난 최신 사건이나 비공개 정보에 대해 알지 못하는 한계
   - 지식 컷오프 (Knowledge Cutoff)
2. 교안에서 설명하는 RAG(검색 증강 생성)의 핵심 동작 방식으로 가장 적절한 것
   - 답변 생성 전 외부 문서에서 관련 근거를 검색하여 프롬프트에 주입한다
3. 사용자가 질문을 입력하기 전에 문서를 수집·분할·임베딩하여 벡터 저장소에 저장해 두는 사전 준비 단계
   - 인덱싱 단계
4. 텍스트 분할(Chunking) 시 앞뒤 청크 사이에 chunk_overlap(중복 구간)을 설정하는 주된 목적
   - 문장이 잘려 의미나 문맥이 단절되는 현상을 방지하기 위해
5. 검색기(Retriever)가 질문과 관련된 정확한 문서를 찾아 전달해 주었음에도, 모델이 해당 문서를 무시하고 사실이 아닌 답변을 출력했다면 이는 RAG 5단계 중 어느 단계의 병목에 해당하나
   - 생성 단계

장학금 규정 문자열을 같은 크기·오버랩(30/10)으로 두 분할기에 넣는다.

```python
campus_rules = (
    "제1조 (목적)\n본 규정은 장학금 지급 기준을 정의합니다.\n\n"
    "제2조 (선발 기준)\n직전 학기 평점 3.5 이상이어야 하며 F학점이 없어야 합니다."
)

from langchain_text_splitters import CharacterTextSplitter, RecursiveCharacterTextSplitter

text_splitter = CharacterTextSplitter(
    chunk_size=30, # 청크 최대 글자수
    chunk_overlap=10, # 겹침 글자수
    #separator="" 기본값 \n\n - 문단 단위 청킹
)

text_chunks = text_splitter.split_text(campus_rules)

for i, chunk in enumerate(text_chunks, 1):
    print(f"[{i} 번째] - {chunk}")
```

```text
Created a chunk of size 32, which is longer than the specified 30

[1 번째] - 제1조 (목적)
본 규정은 장학금 지급 기준을 정의합니다.
[2 번째] - 제2조 (선발 기준)
직전 학기 평점 3.5 이상이어야 하며 F학점이 없어야 합니다.
```

- `separator`를 비워 두면 기본값이 문단(`\n\n`)이라 조(條) 단위 2조각이 됨
- 두 번째 문단이 32자라 `chunk_size=30`을 넘김 → 경고 후 그대로 한 청크로 유지

```python
# separators=["\n\n", "\n", " ", "."] # 기본값 : 문단 단위 -> 다음 줄 -> 공백 -> 마침표
rec_splitter = RecursiveCharacterTextSplitter(
    chunk_size=30,
    chunk_overlap=10,
)

rec_chunks = rec_splitter.split_text(campus_rules)

for i, chunk in enumerate(rec_chunks, 1):
    print(f"[{i} 번째] - {chunk}")
```

```text
[1 번째] - 제1조 (목적)
[2 번째] - 본 규정은 장학금 지급 기준을 정의합니다.
[3 번째] - 제2조 (선발 기준)
[4 번째] - 직전 학기 평점 3.5 이상이어야 하며 F학점이
[5 번째] - 하며 F학점이 없어야 합니다.
```

- 재귀 분할은 기본 구분자를 차례로 적용해 줄·문장 단위로 더 잘게 나눔 (5조각)
- 오버랩으로 4번째 끝 「하며 F학점이」이 5번째 앞에 반복됨

**1장 6강 : 메타데이터 설계 (1)**

**메타데이터**

> 교재 · 1장 6강

- 데이터 조각에 붙이는 규격화된 신분증. 본문 외에 출처, 생성 일자, 작성자, 카테고리 등을 기록해 맥락을 보존
- 왜 필요한가
  - 시간적 유효성 구분: 구버전과 최신 개정안을 날짜 필드로 분리
  - 문서 출처 추적성: 답변의 원본 위치·근거 페이지를 입증
  - 검색 연산 비용 절감: 조건에 맞는 데이터만 선별해 전체 조각을 벡터 비교하지 않음
- LangChain `Document` 구조
  - `page_content`: 청킹된 순수 텍스트 본문
  - `metadata`: 출처·부가 정보를 키-값 딕셔너리로 관리

```python
from langchain_core.documents import Document

sample_doc = Document(
    page_content="직전 학기 평점 3.5 이상인 학생에게 성적 우수 장학금을 지급합니다.",
    metadata={
        "source": "2026_학사규정.pdf",
        "page": 12,
        "category": "장학",
        "year": 2026
    }
)

print("=== [본문 데이터] ===")
print(sample_doc.page_content)
print("\n=== [부착된 메타데이터] ===")
print(sample_doc.metadata)
```

```text
=== [본문 데이터] ===
직전 학기 평점 3.5 이상인 학생에게 성적 우수 장학금을 지급합니다.

=== [부착된 메타데이터] ===
{'source': '2026_학사규정.pdf', 'page': 12, 'category': '장학', 'year': 2026}
```

검색 목적에 맞는 스키마가 RAG 품질의 출발점. 식별·시간·구조 정보를 균형 있게 정의해야 필터링과 원본 역추적이 가능하다.

| 분류                   | 주요 속성 예시               | 역할 및 검색 시 이점                             |
| ---------------------- | ---------------------------- | ------------------------------------------------ |
| 식별 정보 (Identity)   | source, doc_id, author       | 문서의 출처를 명시하고 답변의 인용 근거를 제시함 |
| 시간 정보 (Temporal)   | created_at, updated_at, year | 구버전 정보 배제 및 최신 유효 문서 우선 선별     |
| 구조 정보 (Structural) | section, page, chunk_id      | 원본 문서 내 위치 파악 및 인접 문맥 역추적 가능  |

> 교재 · 1장 6강

교재 실습은 같은 실습실 규정을 `chunk_size=40`으로 나눈다. 각 청크 metadata에 `chunk_id`를 추가하고, 원문 메타데이터는 계승된다.

```python
raw_text = (
    "제1장 총칙: 본 규정은 컴퓨터공학과의 실습실 이용 규정을 명시합니다.\n\n"
    "제2장 이용 시간: 평일은 오전 9시부터 오후 10시까지 개방합니다. 주말은 미개방합니다."
)
file_info = {"source": "cs_lab_policy.pdf", "department": "컴퓨터공학과", "version": "v1.2"}

original_document = Document(page_content=raw_text, metadata=file_info)

text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=40,
    chunk_overlap=0
)

chunked_docs = text_splitter.split_documents([original_document])

for idx, doc in enumerate(chunked_docs):
    doc.metadata["chunk_id"] = idx + 1
    print(f"청크 {doc.metadata['chunk_id']} 내용: {doc.page_content.strip()}")
    print(f"청크 {doc.metadata['chunk_id']} 메타데이터: {doc.metadata}\n")
```

```text
청크 1 내용: 제1장 총칙: 본 규정은 컴퓨터공학과의 실습실 이용 규정을 명시합니다.
청크 1 메타데이터: {'source': 'cs_lab_policy.pdf', 'department': '컴퓨터공학과', 'version': 'v1.2', 'chunk_id': 1}

청크 2 내용: 제2장 이용 시간: 평일은 오전 9시부터 오후 10시까지 개방합니다.
청크 2 메타데이터: {'source': 'cs_lab_policy.pdf', 'department': '컴퓨터공학과', 'version': 'v1.2', 'chunk_id': 2}

청크 3 내용: 주말은 미개방합니다.
청크 3 메타데이터: {'source': 'cs_lab_policy.pdf', 'department': '컴퓨터공학과', 'version': 'v1.2', 'chunk_id': 3}
```

메타데이터 필터링은 검색 범위를 좁히는 거름망이다.

- **사전 필터링**: 메타데이터 조건을 충족하는 청크만 먼저 걸러낸 뒤 유사도 계산
- **사후 필터링**: 전체 데이터로 유사도 검색을 먼저 한 뒤, 조건에 맞지 않는 결과를 버림

```python
documents = [
    Document(
        page_content="컴퓨터공학과 전공자는 졸업 필수 요건으로 캡스톤 디자인을 이수해야 합니다.",
        metadata={"dept": "컴공", "year": 2024, "type": "졸업"}
    ),
    Document(
        page_content="컴퓨터공학과 전공자는 산학 프로젝트 또는 캡스톤 디자인 중 1개를 택할 수 있습니다.",
        metadata={"dept": "컴공", "year": 2026, "type": "졸업"}
    ),
    Document(
        page_content="경영학과 전공자는 전공 필수 36학점을 이수해야 졸업이 가능합니다.",
        metadata={"dept": "경영", "year": 2026, "type": "졸업"}
    )
]

target_dept = "컴공"
target_year = 2026

filtered_documents = [
    doc for doc in documents
    if doc.metadata.get("dept") == target_dept and doc.metadata.get("year") == target_year
]

print(f"=== [필터링 결과: {target_dept} / {target_year}년도] ===")
for doc in filtered_documents:
    print(f"내용: {doc.page_content}")
    print(f"속성: {doc.metadata}")
```

내용: 컴퓨터공학과 전공자는 산학 프로젝트 또는 캡스톤 디자인 중 1개를 택할 수 있습니다.

필터링된 청크와 출처 메타데이터를 프롬프트에 넣어, 제공된 사실에만 근거하고 출처를 붙여 답하게 한다.

```python
import os
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

load_dotenv()

model = init_chat_model(
    model_provider="openai",
    model="gpt-5-mini",
    temperature=0
)

selected_doc = filtered_documents[0]

prompt = ChatPromptTemplate.from_messages([
    ("system", (
        "제공된 [참고 문서]에만 근거하여 명확하게 답변하세요.\n"
        "답변 끝에는 반드시 [출처: 문서종류 (연도)] 형식으로 근거를 명시하세요.\n\n"
        "[참고 문서]:\n{context}\n\n"
        "[문서 메타데이터]: 학과={dept}, 연도={year}"
    )),
    ("user", "{question}")
])

rag_chain = prompt | model | StrOutputParser()

user_query = "컴퓨터공학과 졸업을 위한 필수 요건이 무엇인가요?"
response = rag_chain.invoke({
    "context": selected_doc.page_content,
    "dept": selected_doc.metadata["dept"],
    "year": selected_doc.metadata["year"],
    "question": user_query
})

print("=== [모델 답변] ===")
print(response)
```

[출처: 참고 문서 (2026)]

    "question": user_query
