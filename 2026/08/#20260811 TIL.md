### 4.1 조건문

- 판별식에 따라서 참(True)이면 참에 실행되는 코드를 정의하고, 거짓(False)이면 거짓 조건에 실행되는 코드를 정의할 수 있는 문장
- 판별식 : 비교 연산자, 논리 연산자, 값

### 4.1.1 단일 조건문 : if

~~~python
if 판별식:
    # 판별식이 참일 때 실행되는 코드
    # 판별식은 4자 띄워야함 (들여쓰기). Tab 키

num = 10
if num > 5:
    print("5보다 크다")
~~~

### 4.1.2 양자택일 구조 : if-else 조건문

- 조건이 틀린 (False) 경우 실행할 별도의 대응 명령

~~~python
num = 1
if num == 10:
    print("10 입니다")
else:
    print("10이 아닙니다")
~~~

### 4.1.3 다중 조건 분기 : if-elif-else

- 연쇄 조건 검사
- 구체적/높은 기준값 조건부터 위에 배치


### 4.1.4 복잡한 조건 처리: 중첩 조건문과 논리 연산자 결합

- 계층적 세부 조건 또는 다수 조건 동시 만족 시 사용

### 4.1.4.1 중첩 조건문 (Nested if)

- **논리 연산자** (`and`, `or`) 활용 -> 다중 조건을 **한 줄의 if**로 통합

~~~python

if num >= 10:
    if num < 100:
        print(f"{num}는 10이상 100미만입니다.")
# 결과: 45는 10이상 100미만입니다.

# 논리연산자와 결합
num = int(input())
if num >= 10 and num < 100:
    print(f"{num}는 10이상 100미만입니다.")
# 결과: 55는 10이상 100미만입니다.
~~~

### 4.2.3 반복문의 중간 제어 : break와 continue

- `continue` : 현재 반복을 중단하고 새로운 반복을 시작(건너뛰기), 하위 코드 실행 X -> 반복문 처음 조건이나 다음 데이터 순회 단계로 넘어감
- `break` : 반복 종료. 주로 `if` 조건문과 짝을 지음. 조건에 부합하는 순간 불필요한 하위 연산을 중단하여 시스템 성능을 높임

~~~python
total = 0
for i in range(1, 101): # 1~100
    if i % 2 == 0: # 짝수인지 판별
        continue # 현재의 반복문의 코드 실행을 중단하고 다시 반복 -> 건너뛰기
    total += i
print(f"합계:{total}")
~~~

#### 오답노트 및 실수 기록 (데이터 필터링)

**1. 딕셔너리의 값에 접근할 때 키 이름만 작성함**
- **실수**
  `if "completed" == True:`
  `vip_price += "price"`
- **문제점**
  `"completed"`와 `"price"`는 딕셔너리의 값을 가져오는 것이 아니라 문자열 자체이다. 반복문에서 `for user in order_database:`와 같이 딕셔너리를 `user` 변수에 하나씩 담았다면, 해당 딕셔너리의 값은 `user["키"]`로 접근해야 한다.
- **수정**
  `if user["completed"] == True:`
  `vip_price += user["price"]`
- **기억할 규칙**
  딕셔너리의 값을 사용할 때는 `변수["키"]` 형태로 접근한다.

**2. for문으로 데이터를 하나씩 꺼냈는데 다시 전체 데이터를 검사하려고 함**
- **실수**
  ~~~python
  for user in order_database:
      if user["completed"] == True:
          if user["price"] >= 50000 in order_database:
  ~~~
- **문제점**
  이미 `for user in order_database:`에서 `order_database`의 데이터를 하나씩 `user`에 꺼내고 있다. 따라서 `if`에서는 전체 리스트를 다시 검사할 필요 없이 현재 꺼낸 `user`의 값만 비교하면 된다.
- **수정**
  `if user["price"] >= 50000:`
- **기억할 규칙**
  `for 변수 in 리스트:`로 하나씩 꺼냈다면, 조건문에서는 현재 변수의 데이터를 검사한다.

**3. 숫자 변수에 문자열을 더하려고 함**
- **실수**
  `vip_price = 0`
  `vip_price += "price"`
- **문제점**
  `vip_price`는 숫자형(`int`)인데 `"price"`는 문자열(`str`)이다. 즉, `숫자 + 문자열`을 하려고 한 것이다.
- **수정**
  `vip_price += user["price"]`
  `user["price"]`는 실제 가격 데이터이므로 숫자끼리 더할 수 있다.
- **기억할 규칙**
  변수에 값을 누적할 때는 변수의 자료형과 더하는 값의 자료형을 확인한다.

**4. print()의 들여쓰기 위치를 잘못 잡음**
- **실수**
  ~~~python
  for user in order_database:
      ...
      print(f"우수 고객 주문 건수 : {vip_order}건")
  ~~~
- **문제점**
  `print()`가 `for`문 안에 있기 때문에 고객 한 명을 검사할 때마다 중간 계산 결과가 계속 출력된다. 원하는 것은 모든 고객을 검사한 뒤 '최종 결과'를 한 번만 출력하는 것이었다.
- **수정**
  ~~~python
  for user in order_database:
      ...
  
  # 반복문이 모두 끝난 뒤 바깥쪽에 작성
  print(f"우수 고객 주문 건수 : {vip_order}건")
  print(f"우수 고객 총 결제 금액 : {vip_price}원")
  ~~~
- **기억할 규칙**
  반복 중간 결과를 출력할 것인지, 반복이 끝난 최종 결과를 출력할 것인지에 따라 `print()`의 들여쓰기를 결정한다.

#### 오답노트 및 실수 기록 (업다운 게임)

**5. 입력값을 여러 번 input()으로 받음**
- **실수**
  `if int(input()) < answ:`
  `elif int(input()) > answ:`
- **문제점**
  `input()`은 호출할 때마다 새로운 입력을 받는다. 따라서 조건문마다 `input()`을 작성하면 사용자가 한 번 입력한 값을 재사용하는 것이 아니라, 계속 새로운 값을 입력해야만 다음 줄로 넘어가게 된다.
- **수정**
  ~~~python
  # 입력값을 먼저 변수에 저장한다.
  try_ans = int(input())

  if try_ans < answ:
      ...
  elif try_ans > answ:
      ...
  ~~~
- **기억할 규칙**
  같은 입력값을 여러 번 사용할 경우 먼저 변수에 저장하고 그 변수를 재사용한다.

**6. input()으로 받은 값을 변수에 저장했지만 다시 사용하지 않음**
- **실수**
  `test = input()`
  `try_ans = int(input())`
- **문제점**
  `test`에 첫 번째 입력값을 저장했지만 이후 코드에서 `test`를 전혀 사용하지 않는다. 결국 아무 의미 없이 입력을 두 번이나 받게 된다.
- **수정**
  `try_ans = int(input())`
  입력값을 실제로 연산에 사용할 변수에 한 번만 저장한다.
- **기억할 규칙**
  변수를 만들었다면 그 변수를 실제로 사용하는지 꼭 확인하고, 사용하지 않는 변수와 코드는 과감히 제거한다.

**7. while 조건에 정답 숫자(answ)를 True와 비교함**
- **실수**
  `while answ == True:`
- **문제점**
  `answ`는 `random.randint(1, 50)`으로 만들어진 1~50 사이의 정수이다. 그런데 위 코드는 "answ가 True(1)인가?"를 검사하는 조건식이다. 게임을 끝없이 계속 반복하려는 의도(무한 루프)와 맞지 않는다.
- **수정**
  `while True:` 로 작성하여 무한 루프를 만들고, 정답을 맞혔을 때 `break`로 반복을 종료한다.
- **기억할 규칙**
  계속 반복하다가 특정 조건에서 강제로 종료하는 구조라면 `while True:`와 `break`의 조합을 사용할 수 있다.

**8. 시도 횟수 증가 위치가 잘못됨**
- **실수**
  ~~~python
  elif try_ans > answ:
      print(...)
      wrong_No += 1
  ~~~
- **문제점**
  `wrong_No += 1`이 `elif` 안에 있기 때문에 입력값이 정답보다 큰 경우에만 시도 횟수가 증가한다. 숫자를 더 작게 부르면 횟수가 안 올라가고, 정답을 한 번에 맞히면 무조건 "0회"라고 출력되는 버그가 발생한다.
- **수정**
  ~~~python
  # 입력을 한 번 받을 때마다 반복문 시작 지점에서 횟수를 증가시킨다.
  try_ans = int(input())
  try_count += 1

  if try_ans < answ:
      ...
  ~~~
- **기억할 규칙**
  '시도 횟수'는 특정 조건을 만족했을 때가 아니라, 사용자가 '입력을 한 번 시도할 때마다' 무조건 1씩 증가해야 한다.

### print() 함수 특수 조작과 출력 형태
예시 중 `print()` 함수 내용이 다름에 따라 결과물도 차이가 남. 작성 방법들은 다음과 같음.

1. **콤마(`,`) 나열 : `print("문자열", 변수)`** 
   - 값과 값 사이 자동으로 공백 한 칸이 생성됨
   - ex) `print("결과는", total, "입니다")` ➡️ `결과는 5050 입니다`
2. **f-string : `print(f"...")`**
   - `{}` 안에는 변수뿐만 아니라 '결과값이 나오는 파이썬의 모든 코드(표현식)'를 넣을 수 있음. 콤마나 더하기도 함께 사용 가능.
   - 변수, 수식(연산), 함수 호출(결과값 출력됨), 메서드 사용 가능
3. **더하기(`+`)로 묶기 : `print("문자" + "문자")`**
   - 문자와 숫자를 더하면 에러 발생
4. **출력 형태를 조작하는 특수 옵션**
   - `sep`(구분자) : 콤마로 나열할 때 자동 공백 대신 다른 문자를 삽입
     - ex) `print("2026", "08", "11", sep="-")` ➡️ `2026-08-11`
   - `end`(끝맺음) : `print()` 출력 시 발생하는 기본 줄바꿈을 무시하고, 다른 문자로 끝맺음
     - ex) 
       `print("첫째 줄", end=" ")`
       `print("계속 이어짐")` 
       ➡️ `첫째 줄 계속 이어짐`

### range() 반복 횟수의 작동 원리 의문 탐구

### 의문
`range()`의 반복횟수가 정해진 아이템의 개수보다 적거나 많으면 어떤 결과가 나오는가? 혹시 부족하면 0으로 돌아가는가?

### 탐색 방향 및 조건
아이템(데이터)이 9개 존재하는 상황을 가정.

### 후보 검토 1: range(8)인 경우
인덱스 0부터 7까지만 정확히 훑고 반복문이 종료됨.

### 후보 검토 2: range(10)인 경우
0으로 다시 돌아가지 않으며, 존재하지 않는 인덱스 9를 꺼내려고 시도하다가 `IndexError` 발생.

### 결론
`range()`는 괄호 안에 지정된 숫자만큼 정직하게 숫자를 만들어낸다.

 - break : 반복 종료 ,  주로 if 조건문과 짝, if 조건 부합하는 순간 불필요 하위 연산 중단 -> 시스템 성능 높임
    ```
    total=0
    for i in range(1,101): # 1~100
        if i%2==0:#짝수인지 판별
            continue # 현재의 반복문의 코드 실행을 중단하고 다시 반복 -> 건너뛰기
        total+=i
    print(f"합계:{total}")
    

    for _ in range(10):
        num = int(input())
    
        if num==99:
            print("종료")
            break # 반복 종
        
        print("입력한 숫자:", num)
    ```

  - 첫 번째 반복은 단(2~8), 8회 반복

   ```
    for i in range(2,10): #단

        for j in range(1,9): #곱하는 수

   ```

## 찾아본 내용
 - 예시 중 print()함수 내용이 다름에 따라 결과물도 차이가 남. 작성 방법들이 어떻게 되는지
    1. 콤마`,` 나열 : `print("문자열",변수)`  
        값과 값 사이 자동 공백 한 칸  
        ex) print("결과는", total, "입니다") ➡️ 결과는 5050 입니다
    2. f-string : `print(f"...")`
       : {} 안에는 변수뿐만 아니라 '결과값이 나오는 파이썬의 모든 코드(표현식)'를 넣을 수 있다. 콤마,더하기 가능
        - 변수
        - 수식(연산)
        - 함수 호출 : 함수 결과값이 출력됨
        - 메서드 사용
    3. 더하기`+`로 묶기 : `print("문자"+"문자")`
        - 문자와 숫자 더하면 에러
    4. 출력 형태 조작하는 특수 옵션
        - sep(구분자) : 콤마로 나열할 때 공백 대신 다른 문자 삽입 
            ex) print("2026", "08", "11", sep="-") ➡️ 2026-08-11
        - end(끝맺음) : print() 출력 시의 줄바꿈 무시, 다른 문자로 끝맺음
            print("첫째 줄", end=" ")
            print("계속 이어짐") ➡️ 첫째 줄 계속 이어짐

 - range()의 반복횟수에 대해 의문이 생김. 반복횟수가 적거나, 많으면(0으로 돌아가나?) 어떤 결과가 나오지?
     1) 아이템이 9개인데 range(8)인 경우
      인덱스 0-7 훑고 반복문 종료
     2) 아이템이 9개인데 range(10)인 경구
      존재하지 않는 인덱스 9 꺼내려다 IndexError

 - 리스트 컴프리헨션의 표현식에서 f-string이 들어갈 수 있는 것을 보고 그러면 다른 것들은 어떤게 되지?
