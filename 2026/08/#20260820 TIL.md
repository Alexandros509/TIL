### 9.1 내장 함수

#### 9.1.3 데이터 가공 및 필터링 함수
- `map(function, iterable)` : 일괄 변환
  - iterable의 모든 요소에 동일한 함수 일괄 적용.
  - 반환값 : Iterator 반복자. 실제 값 사용 시 `list()`나 `tuple()` 등으로 감싸주어야 함.
- `filter(function, iterable)` : 조건별 추출
  - 데이터 목록 중 설정 조건문이 True인 요소만 추출.
  - 반환값 : Iterator 반복자. 실제 값 사용 시 `list()`나 `tuple()` 등으로 감싸주어야 함.

리스트 컴프리헨션으로 대체 가능합니다.
~~~python
nums = [*range(1, 11)]
nums2 = [x**2 for x in nums]
print(nums2)

nums3 = [x for x in nums if x % 2 == 1]
print(nums3)
~~~

#### 9.1.4 루프 제어 및 정렬을 돕는 가이드 함수
- `enumerate(iterable, start=0)` : 인덱스 자동 부여
  - Iterator 반환
  - `(인덱스, 요소)` 형태로 묶어서 반환합니다.
~~~python
for i, fruit in enumerate(fruits):
    print(i, fruit)

# [출력 결과]
# 0 사과
# 1 오렌지
# 2 멜론
# 3 망고
~~~

- `zip(*iterables, strict=False)` : 다중 데이터 결합
  - 2개 이상의 iterable.
  - Iterator 반환.
  - 각 iterable의 동일 인덱스 요소를 모아서 튜플로 묶어 반환합니다.
~~~python
names = ["김철수", "이영희"]
emails = ["cheolsoo@univ.ac.kr", "younghee@gmail.com"]

for name, email in zip(names, emails):
    print(f"이름: {name} | 이메일: {email}")

# [출력 결과]
# 이름: 김철수 | 이메일: cheolsoo@univ.ac.kr
# 이름: 이영희 | 이메일: younghee@gmail.com
~~~

- `sorted(iterable, *, key=None, reverse=False)` : 원본 데이터 새 기준 정렬
  - 정렬 가능한 iterable에 사용.
  - 새로운 List 반환.
  - `key`: 정렬 기준을 지정하는 함수 (선택 사항).
  - `reverse`: 오름차순(False) / 내림차순(True).
~~~python
# 1. 정렬 가능한 iterable (튜플 형태의 과일 이름과 가격)
fruits = [("banana", 3000), ("apple", 1000), ("cherry", 2000)]

# 2. reverse: 내림차순(True) 적용 및 List 반환 확인
# key: 정렬 기준 지정 함수 (가격인 1번째 요소 x[1] 기준)
sorted_fruits = sorted(fruits, key=lambda x: x[1], reverse=True)

print(type(sorted_fruits))  # <class 'list'>
print(sorted_fruits)        
# [('banana', 3000), ('cherry', 2000), ('apple', 1000)]
~~~

- `max()`, `min()` : 최대, 최소값
~~~python
numbers = [3, 1, 4, 1, 5, 9]

print(max(numbers))  # 9
print(min(numbers))  # 1

# key 매개변수 활용 예시 (문자열 길이 기준)
words = ["apple", "banana", "kiwi"]
print(max(words, key=len))  # "banana"

print(max(10, 20, 15))  # 20
print(min(10, 20, 15))  # 10
~~~

### 9.2 표준 라이브러리

1. **datetime & time** (날짜와 시간)

   - `%H`: 24시간 형식의 시

   - `%S`: 2자리 초
   - `%A`: 요일 이름 (영어 full name)

   - `.ceil()` : 소수점 올림
   - `.floor()` : 소수점 내림
   - `.trunc()` : 정수만 반환
   - `.fabs()` : 실수 절대값 반환
   - `.sqrt()` : 제곱근(루트) 반환
   - `.pi()` : 원주율 상숫값 반환

3. **json** (데이터 표준 변환)
   - JavaScript Object Notation (자바스크립트 객체 표기법)
   - 다른 플랫폼 간의 소통을 위한 표준 데이터 형식.
   - 자바스크립트의 객체를 정의하는 형식을 빌려온 것 (**자바스크립트가 아니다!**)
   - `{"이름":"값", ...}` 구조를 가집니다.
   - `.dumps(obj)` : 파이썬 객체를 JSON 형식의 문자열로 변환 (직렬화)
   - `.loads(s)` : JSON 형식의 문자열을 파이썬 객체로 역변환 (역직렬화)
   - `.dump(obj, fp)` : 파이썬 객체를 JSON 형식의 파일로 저장
   - `.load(fp)` : 저장된 JSON 파일을 파이썬 객체로 역변환
~~~python
import json

user = {
    "name": "김철수",
    "age": 20,
}

# ensure_ascii=False : ASCII 코드 변환을 강제하지 않음 (한글 유지)
# indent=4 : 들여쓰기(Indent) 칸 수 설정
json_string = json.dumps(user, ensure_ascii=False, indent=4)
print("json_string:\n", json_string, "type:", type(json_string))

nums_string = "[1,2,3,4,5]"
user_string = '{"name":"오철수","age":22}'

nums = json.loads(nums_string)
user2 = json.loads(user_string)

print("nums:", nums, "type:", type(nums))
# nums: [1, 2, 3, 4, 5] type: <class 'list'>

print("user2:", user2, "type:", type(user2))
# user2: {'name': '오철수', 'age': 22} type: <class 'dict'>
~~~

## 10.1 파일 입출력과 구조화된 데이터 변환

### 10.1.1 파일 입출력과 텍스트 파일 다루기
- 파일 입출력 (I/O)
  - 입력 (Input) : 파일에 있는 데이터를 읽기 (`read`)
  - 출력 (Output) : 데이터를 파일로 작성 (`write`)

1. **`with open()`의 자원 자동 해제**
- `with` 구문 : 첫 라인에서 `__enter__()` 실행, 마지막 라인 실행 후 자동으로 `__exit__()` 실행.
~~~python
# 수동 해제 방식
file = open("test.txt", "w", encoding="UTF-8")
file.close()  # 반드시 수동으로 닫아주어야 함

# "w" 덮어쓰기, "a" (append) 누적 추가
with open("test.txt", "w", encoding="utf-8") as file:
    pass
    # 들여쓰기가 끝나면 자동으로 file.close()가 실행됨

# 내부 동작 원리 이해를 위한 클래스 예시
class MyResources:
    def __enter__(self):
        print("__enter__ 호출")
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        print("__exit__ 호출")

with MyResources() as o:
    print(o)

# "a" (append), \n : 줄바꿈
with open("test.txt", "a", encoding="UTF-8") as fp:
    fp.write("Bye\n")   
~~~

2. **텍스트 파일 읽기 함수 및 메모리 효율성 비교**

| 방식 | 읽는 단위 | 반환 타입 | 메모리 사용량 | 특징 및 장점 |
| :--- | :--- | :--- | :--- | :--- |
| **`for line in fp:`** | **한 줄씩 순차적으로** | 문자열 (`str`) | **매우 낮음** | 파일을 통째로 올리지 않고 한 줄씩 순회하여(Iterator 성질) 대용량 파일에 최적화된 표준 권장 방식 |
| **`.readlines()`** | **전체 내용을 줄 단위로** | 리스트 (`list`) | **높음** | 모든 줄을 파이썬 리스트로 한 번에 변환하므로 작은 파일에 적합 |
| **`.read()`** | **전체 내용 통째로** | 문자열 (`str`) | **매우 높음** | 하나의 거대한 문자열로 가져오므로 파일 크기가 크면 메모리 부담 증가 |

~~~python
with open("test.txt", "r", encoding="UTF-8") as fp:
    while (text := fp.readline()): 
        print(text.strip())
~~~

**`:=` (왈러스 연산자, Walrus Operator)**
- 반복/조건문 안에서 어떤 값을 계산해 변수에 넣는 동시에, 그 값을 조건식에서 바로 사용할 때 사용합니다.
~~~python
# 왈러스 연산자 미사용
n = len([1, 2, 3, 4, 5])
if n > 3:
    print(f"길이가 {n}입니다.")

# 왈러스 연산자 사용 (변수 선언과 조건 검사를 한 번에)
if (n := len([1, 2, 3, 4, 5])) > 3:
    print(f"길이가 {n}입니다.")
~~~

### 10.1.2 구조화된 데이터 포맷(CSV/JSON)과 구조 변환
1. **CSV (Comma Separated Value)**
- 데이터를 쉼표로 구분하여 표 형태의 구조를 표현.
- 용량이 작고 데이터베이스 연동이 쉽습니다.
~~~python
import csv

# newline="" : 행 사이에 불필요한 공백 행이 자동 삽입되는 것을 방지
with open("members.csv", "w", encoding="UTF-8", newline="") as fp:
    writer = csv.writer(fp)
    writer.writerow(["이름", "나이", "전화번호"])
    writer.writerow(["김철수", 20, "010-1000-1000"])

with open("members.csv", "r", encoding="UTF-8") as fp:
    reader = csv.reader(fp)
    members = list(reader)
    print(members)
~~~

## 11.1 동기(Sync) vs 비동기(Async)의 이해
여러 작업을 진행할 때 '시간적 순서를 어떻게 맞출 것인가'에 대한 규칙입니다.

1. **동기 (Synchronous)**
   - 순차적, 직관적.
   - **Blocking**: 호출된 하위 코드가 작업을 마칠 때까지 제어권을 독점하는 현상. 상위 코드는 실행을 중단하고 대기합니다.
   - 예시: 카운터에서 주문 후 길막하며 대기 (요청 후 결과가 올 때까지 직진하며 대기).
   - 필요성: 논리적인 흐름과 무결성이 필수적일 때 (ex. 입금 후 잔액 조회).

2. **비동기 (Asynchronous)**
   - 독립적, 효율적 병렬 처리.
   - **Non-blocking**: 하위 코드에 작업을 요청해도 상위 코드가 제어권을 유지하거나 즉시 돌려받는 방식. 하위 작업 완료를 기다리지 않고 다음 코드를 실행합니다.
   - 예시: 카운터에서 주문하고 앉아서 진동벨 대기 (요청 던져두고 내 할 일 하다가 결과 오면 처리).
   - 필요성: 컴퓨터가 멍하니 대기하는 시간(Idle)을 없애고 자원을 극한으로 효율화하기 위해.

~~~python
# 동기식 함수
import time

def work(title,seconds):
    time.sleep(seconds)
    print(title,"완료!")

start = time.perf_counter() # 작업 시작 시간
work("A작업",2)
work("B작업",3)
work("C작업",1)
end = time.perf_counter() # 작업 종료 시간
print("걸린 시간:", end -start)
>
A작업 완료!
B작업 완료!
C작업 완료!
걸린 시간: 6.001346100005321

# 비동기식 함수
import asyncio
import time

# 비동기 함수는 내부에서 코루틴 대기(await) 활용
async def async_work(title, seconds):
    await asyncio.sleep(seconds)
    print(title, "완료!")

# 다중 비동기 실행을 위한 gather
async def main():
    await asyncio.gather(
        async_work("A작업", 2),
        async_work("B작업", 3),
        async_work("C작업", 1)
    )

start = time.perf_counter()
await main()        
end = time.perf_counter()
print(f"걸린 시간: {end - start:.2f}초")
~~~

## 문제 상황 / 시행착오
`zip()`과 `enumerate()`를 활용해 당첨자 리스트를 결합하고 출력하는 실습에서 구조 파악 및 언패킹 오류 경험.

### 의문
- `enumerate(zip(v_name, v_email))` 구조에서 `for`문을 돌릴 때, 변수를 어떻게 배치해야 정확하게 데이터를 꺼내(Unpacking) 쓸 수 있는가?

### 탐색 방향
- 반환되는 데이터의 튜플 구조를 확인하고, 반복문 변수 선언부를 다양하게 수정.

### 후보 및 비교 검토
- **시도 1: 변수 3개 단순 지정**
  - `for idx, v_name, v_email in enumerate(zip1, start=1):`
  - 결과: `ValueError: not enough values to unpack (expected 3, got 2)`
  - 분석: `enumerate`는 `(숫자, (이름, 이메일))` 형태의 **이중 묶음**을 반환함. 변수를 3개로 나열하면 구조 불일치로 에러 발생.
- **시도 2: `zip()` 객체 자체 재사용**
  - `zip_1 = zip(v_name, v_email)` 정의 후 반복문 여러 번 테스트.
  - 결과: 출력이 안 되거나 이상하게 깨짐.
  - 분석: `zip()` 객체는 일회용 소모성(Iterator)이므로 한 번 순회하면 비어버림.
- **시도 3: 무리한 문법 결합**
  - `for i, name, email in enumerate(zip1, start=1) in zip(v_name, v_email):`
  - 결과: `TypeError: 'bool' object is not iterable` 치명적 문법 에러 발생.

### 판단 및 해결 과정
- 데이터가 겹겹이 포장(Packing)된 구조를 정확히 파악해야 함.
- 바깥쪽 숫자는 `num`이 받고, 안쪽 튜플은 `(name, email)`처럼 **괄호 `( )`로 감싸서 지정하는 이중 괄호 언패킹(Nested Unpacking)** 문법 적용.

~~~python
v_name = ["이민서", "박준형"]
v_email = ["minseo@ssu.ac.kr", "junhyung@daum.net"]

# enumerate와 zip을 결합하고, 이중 괄호를 통해 안쪽 튜플까지 한 번에 언패킹
for num, (name, email) in enumerate(zip(v_name, v_email), start=1):
    print(f"{num}번 당첨자: {name} | 이메일: {email}")
~~~

## 느낀 점
이거 작동 트리 구조를 좀 알아야겠는데?
`for`에서 이렇게 `zip1`을 했는데 `v_name`, `email`을 써도 결과가 나오는 그 과정. 추출돼서 나오는 상세한 과정.
이렇게 이름, 이름 | 이메일, 이메일 묶여서 나오는 것은 패킹을 풀지 못했다고 생각이 든다.
어디서 패킹이 됐고, 언패킹을 어디서 해야 하는지를 몰라서 발생한 문제인가?
아니면 `for` 반복문의 조건과 범위 지정을 제대로 이해하지 못해서 나온 문제인가?
`enumerate`에서 언패킹을 조금 잘하면 분리돼서 나올 것 같은데.
처음에는 2번 2번 나와서 잘하면 되려나 했는데 여러 번 실행하니 맛이 가버림.

## 핵심 개념
- `map()` : Iterable의 각 요소에 동일한 함수를 적용

- `enumerate()` : 순회하면서 인덱스를 함께 제공
- `zip()` : 여러 Iterable의 동일한 위치의 요소를 묶음

- `max()` / `min()` : 최대값 / 최소값 확인
- `json.dumps()` / `loads()` : Python 객체와 JSON 문자열 사이의 변환
- `json.dump()` / `load()` : Python 객체와 JSON 파일 사이의 변환
- `with open()` : 파일 자원을 자동으로 관리
- `read()` : 전체 내용을 문자열로 읽음
- `readline()` : 한 줄씩 읽음
- `readlines()` : 전체 줄을 리스트로 읽음
- `:=` : 왈러스 연산자
- `CSV` : 쉼표로 데이터를 구분하는 구조화된 텍스트 형식

 - > 리스트 컴프리헨션으로 대체 가능

   ~~~python
   nums = [*range(1,11)]
   ~~~

#### 9.1.4 루프 제어 및 정렬을 돕는 가이드 함수
 - `enumerate(iterable, start=0)` : 인덱스 자동 부여
   - Iterator 반환
      ~~~python
      for i,fruit in enumerate(fruits): # (인덱스,요소)
          print(i,fruit)
          >
          0 사과
          1 오렌지
          2 멜론
          3 망고
      ~~~
 - `zip(*iterables, strict=False)` : 다중 데이터 결합
   - 2개 이상의 iterable 
   - Iterator 반환
   - 각 iterable 동일 인덱스 요소 모아서 튜플로 묶어 반환 
      ~~~python
      names = ["김철수", "이영희"]
      emails = ["cheolsoo@univ.ac.kr", "younghee@gmail.com"]
      
      for name, email in zip(names, emails):
          print(f"이름: {name} | 이메일: {email}")
      
      # [출력 결과]
      # 이름: 김철수 | 이메일: cheolsoo@univ.ac.kr
      # 이름: 이영희 | 이메일: younghee@gmail.com
      ~~~
 - `sorted(iterable, *, key=None, reverse=False)` : 원본 데이터 새 기준 정렬
   - 정렬 가능한 iterable
   - 새로운 List 반환
   - key : 정렬 기준 지정하는 함수(선택)
   - reverse: 오름차순 False / 내림차순 True  
      ~~~python
      # 1. 정렬 가능한 iterable (튜플 형태의 과일 이름과 가격)
      fruits = [("banana", 3000), ("apple", 1000), ("cherry", 2000)]

      # 2. reverse: 오름차순(False) / 내림차순(True) 적용 및 List 반환 확인
      # key: 정렬 기준을 지정하는 함수 (여기서는 가격인 1번째 요소, 즉 x[1]을 기준으로 지정)
      sorted_fruits = sorted(fruits, key=lambda x: x[1], reverse=True)

      print(type(sorted_fruits))  # 결과: <class 'list'> (리스트 반환 확인)
      print(sorted_fruits)        
      # 결과: [('banana', 3000), ('cherry', 2000), ('apple', 1000)]
      # (가격이 비싼 순서인 내림차순으로 정렬됨)
      ~~~

 - `max()` , `min()` : 최대,최소값
   ~~~python
   numbers = [3, 1, 4, 1, 5, 9]

   print(max(numbers))  # 결과: 9 (가장 큰 요소)
   print(min(numbers))  # 결과: 1 (가장 작은 요소)

   # key 매개변수 활용 예시 (문자열 길이 기준)
   words = ["apple", "banana", "kiwi"]
   print(max(words, key=len))  # 결과: "banana" (글자 수가 가장 김)
   print(max(10, 20, 15))  # 결과: 20
   print(min(10, 20, 15))  # 결과: 10
   ~~~

### 11.1 동기(Sync) vs 비동기(Async)의 이해
#### 11.1.1 동기와 비동기
 - 여러 작업을 진행할 때 '시간적 순서를 어떻게 맞출 것인가'에 대한 규칙
   1. 동기(Synchronous)
      - 순차적, 직관적
      - CPU Bound (연산 중심 작업)
      - Blocking
        - 호출된 하위 코드가 작업을 마칠 때까지 제어권을 독점하는 현상
        - 상위 코드는 하위 작업이 끝날 때까지 실행을 중단하고 대기
          - ex) 카운터에서 주문 후 길막하며 대기
          - 요청 후 결과가 올 때까지 직진하며 대기
      - **필요성**:  논리적인 흐름과 무결성 like 입금 후 잔액 조회 not 조회 후 입금
   
   2. 비동기(Asynchronous)
      - 독립적, 효율적 병렬 처리
      - I/O Bound (입출력 중심 작업)
      - Non-blocking
        - 하위 코드에 작업을 요청하더라도 제어권을 상위 코드가 그대로 유지하거나, 요청 즉시 제어권을 다시 돌려받는 방식
        - 상위 코드는 하위 작업의 완료를 기다리지 않고 다음 코드를 계속 실행
          - ex) 카운터에서 주문하고 앉아서 진동벨 대기
          - 요청 던져주고 내 할 일 하다가 결과 오면 처리
      - **필요성** : 컴퓨터가 멍하니 대기하는 시간(Idle)을 없애고 자원을 극한으로 효율화하기 위해

~~~python
# 동기식 함수
import time

def work(title,seconds):
    time.sleep(seconds)
    print(title,"완료!")

start = time.perf_counter() # 작업 시작 시간
work("A작업",2)
work("B작업",3)
work("C작업",1)
end = time.perf_counter() # 작업 종료 시간
print("걸린 시간:", end -start)

# 비동기 함수
import asyncio
import time

async def async_work(title, seconds):
    await asyncio.sleep(seconds)
    print(title,"완료!")

# 비동기 함수는 비동기 내에서만 실행 가능하다.
async def main():
    await asyncio.gather(
        async_work("A작업",2),
        async_work("B작업",3),
        async_work("C작업",1)
    )
start = time.perf_counter()
await main()        
end = time.perf_counter()
print("걸린 시간:",end-start)
~~~

# 📝 Python 학습 오답 노트: `zip()`과 `enumerate()` 활용 및 이중 언패킹(Unpacking) 정복

## 1. 개요 및 학습 목표
* **목표:** 당첨자 이름 리스트와 이메일 리스트를 `zip()`으로 묶고, `enumerate(start=1)`를 활용해 1번부터 시작하는 번호를 부여한 뒤 지정된 포맷(`n번 당첨자: 이름 | 이메일: 주소`)으로 출력하기.
* **핵심 학습 포인트:** 
  * `zip()` 객체(이터레이터)의 소모성 특성 이해
  * `enumerate(zip(...))` 구조에서 발생하는 **이중 묶음(Packing)** 형태 파악
  * `for`문의 자동 언패킹 및 **이중 괄호 언패킹(Nested Unpacking)** 기법 습득

---

## 2. 시행착오 및 오답 분석

### ❌ 시행착오 1: `ValueError: not enough values to unpack` 에러 발생
* **시도했던 코드:**
  ~~~python
  for idx, v_name, v_email in enumerate(zip1, start=1):
      print(f"{idx}번 당첨자: {v_name} | 이메일: {v_email}")

~~~

* **원인 분석:**
* `enumerate(zip1, start=1)`가 반환하는 데이터의 구조는 `(숫자, (이름, 이메일))` 형태의 **이중 묶음(튜플 안에 또 튜플)** 구조입니다.
* 파이썬은 이를 2개의 덩어리(인덱스 번호, 내부 튜플)로 제공하는데, 좌변의 변수를 `idx, v_name, v_email`로 3개나 지정하여 언패킹 개수 불일치 에러가 발생했습니다.



---

### ❌ 시행착오 2: `zip()` 객체의 일회용 소모성(Iterator) 문제로 인한 데이터 유실

* **시도했던 코드:**
~~~python
zip_1 = zip(v_name, v_email)
for idx, zip_1 in enumerate(zip_1, start=1):
    # 여러 번 출력 테스트를 진행할 때 데이터가 정상 출력되지 않고 깨짐

~~~


* **원인 분석:**
* `zip()` 함수나 `enumerate()`가 반환하는 객체는 메모리를 아끼기 위해 요소를 한 번에 리스트로 만들지 않고 하나씩 꺼내주는 이터레이터(Iterator)입니다.
* 순회가 한 번 끝나고 나면 객체가 소모되어 비어버리기 때문에, 반복문을 재실행하거나 상태를 착각하면 데이터가 출력되지 않는 문제가 발생합니다. (안전하게 `list()` 등으로 변환하거나 매번 새로 정의해야 함)

* **시도했던 코드:**

~~~python
for i, name, email in enumerate(zip1, start=1) in zip(v_name, v_email):
~~~

## 3. 최종 정답 코드 및 해설

데이터가 겹겹이 포장(Packing)된 구조를 정확히 파악하고, `for`문의 변수 선언부에서 괄호를 활용한 이중 언패킹(Nested Unpacking)을 적용하여 문제를 해결했습니다.

~~~python
v_name = ["이민서", "박준형"]
v_email = ["minseo@ssu.ac.kr", "junhyung@daum.net"]

# enumerate와 zip을 결합하고, 이중 괄호를 통해 안쪽 튜플까지 한 번에 언패킹
for num, (name, email) in enumerate(zip(v_name, v_email), start=1):
    print(f"{num}번 당첨자: {name} | 이메일: {email}")

~~~

### 핵심 요약

1. **포장 구조 파악:** `enumerate(zip(...))`를 사용하면 `(숫자, (이름, 이메일))` 구조의 데이터가 만들어집니다.
2. **이중 언패킹:** 바깥쪽 숫자는 `idx`가 받고, 안쪽의 튜플은 **`(name, email)`처럼 괄호 `( )`로 감싸서** 지정하면 파이썬이 연쇄적으로 껍질을 까서(언패킹해서) 각 변수에 쏙쏙 집어넣어 줍니다.
3. **변수 이름은 자유:** 인덱스를 받는 `idx`나 `i` 같은 이름은 파이썬 예약어가 아니므로 기능상 무엇을 써도 무방하지만, 가독성을 위해 의미가 통하는 관습적인 이름을 사용하는 것이 좋습니다.
