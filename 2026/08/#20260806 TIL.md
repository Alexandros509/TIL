### Python 문법: 변수와 동적 타이핑

#### 1. 변수 (Variable)
```python
money = 5000
```
- `5000`이라는 값의 주소를 생성하고, `money`는 그 주소의 이름표/키 역할을 함.

**참조 (Reference)**
```python
x = 5000
x
# id(x)=1781782405360

y = x
y
# id(y) = id(x)
```
- 변수명 = 값 (`=`가 대입연산자)
- 참조가 끊기면 garbage collector(청소부)가 수거함.

#### 2. 변수명 명명 규칙
- 영문(대소문자), 숫자, `$`, `_` 로 구성
- 숫자는 앞에 올 수 없음 (X)
- 공백 포함 불가 (X)
- 핵심 키워드(if, for, true 등) 사용 불가 (X)
- **권장 사항**: 의미 있는 단어 사용, 여러 단어 구성은 `_`로 구분 (스네이크 케이스)

#### 3. 자료형과 동적 타이핑 (Dynamic Typing)
- 자료: 연산에 사용되는 값
- 자료형의 종류: 숫자형, 문자형(`' '`, `" "`), 논리형(`True`, `False`, `bool`)

값을 넣으면 런타임에 알아서 타입이 매핑됨.
```python
pi = 3.14
type(pi) # float

result = True
type(result) # bool

pi = "원주율"
type(pi) # str
```
