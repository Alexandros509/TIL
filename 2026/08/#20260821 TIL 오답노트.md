## 오늘 공부한 내용

학교별, 학과별 학생들의 성적 정보가 3중으로 중첩된 이터레이터 데이터가 주어졌다.

```python
schools = ["A대학", "B대학"]
departments = [["컴공과", "기계과"], ["전자과", "화공과"]]
students_scores = [
    [[("김철수", 85), ("이영희", 92)], [("박민수", 78), ("정지은", 90)]],
    [[("오민석", 88), ("한지민", 95)], [("강호동", 65), ("유재석", 99)]]
]
```

최종적으로 원하는 한 학생의 데이터 구조는 다음과 같다.

```python
(school, (department, (name, score)))
```

예를 들면:

```python
("A대학", ("컴공과", ("김철수", 85)))
```

이 구조가 만들어지면 다음과 같이 한 번의 `for`문에서 3단계로 언패킹할 수 있다.

```python
for school, (department, (name, score)) in combined_data:
    print(f"[{school}] {department} - {name}: {score}점")
```

### 문제의 요구사항

* `zip()`과 리스트 컴프리헨션 또는 반복문, `enumerate` 등을 적절히 조합하여 데이터를 하나의 3중 구조 데이터로 묶기
* `for` 반복문의 변수 선언부에서 3중 언패킹 수행
* 다음과 같은 형식으로 출력

```text
[A대학] 컴공과 - 김철수: 85점
[A대학] 컴공과 - 이영희: 92점
[A대학] 기계과 - 박민수: 78점
...
```

---

## 문제 상황 / 시행착오

### 의문

`(대학, (학과, (이름, 점수)))` 형식으로 3중 튜플이 만들어져 있다면, `for`문의 변수 선언부에서 이 구조를 어떻게 한 번에 언패킹할 수 있는지 고민했다.

### 1차 시도 — `zip()`으로 단계별 묶기

먼저 학과와 학생 데이터를 묶었다.

```python
dep_stu = list(zip(departments, students_scores))
```

결과:

```python
[
    (
        ["컴공과", "기계과"],
        [
            [("김철수", 85), ("이영희", 92)],
            [("박민수", 78), ("정지은", 90)]
        ]
    ),
    (
        ["전자과", "화공과"],
        [
            [("오민석", 88), ("한지민", 95)],
            [("강호동", 65), ("유재석", 99)]
        ]
    )
]
```

그 다음 학교까지 묶었다.

```python
sch_else = list(zip(schools, dep_stu))
```

결과적으로 각 원소는 다음 구조가 되었다.

```python
(
    "A대학",
    (
        ["컴공과", "기계과"],
        [
            [("김철수", 85), ("이영희", 92)],
            [("박민수", 78), ("정지은", 90)]
        ]
    )
)
```

그런데 내가 원하는 구조는 다음과 같았다.

```python
("A대학", ("컴공과", ("김철수", 85)))
```

즉, **학과 이름 하나와 학생 한 명이 대응되는 구조가 아직 만들어지지 않은 상태**였다.

---

### 2차 시도 — 3중 언패킹을 바로 적용

```python
for school, (department, (name, score)) in sch_else:
    print(f"[{school}] {department} - {name}: {score}점")
```

여기서 문제가 발생했다.

내가 기대한 구조:

```text
school
└── department
    └── name, score
```

실제 구조:

```text
school
└── (
      departments 전체 리스트,
      students_scores 전체 리스트
   )
```

따라서 `for`문의 언패킹 패턴만 복잡하게 작성한다고 해서 Python이 자동으로 원본 데이터의 내부까지 원하는 단위로 찾아 들어가지는 않았다.

---

### 3차 시도 — 중첩 `for`문으로 한 단계씩 내려가기

```python
for school, (dep_stu) in sch_else:
    for department, (student_score) in dep_stu:
        print(f"[{school}] {department} - {name}: {score}점")
```

그 다음 이름과 점수까지 언패킹해 보았다.

```python
for department, (name, score) in dep_stu:
```

→ `ValueError: too many values to unpack (expected 2)`

여기서 `dep_stu` 안에는 학과 하나와 학생 한 명이 바로 들어 있는 것이 아니라, **학과 목록 전체와 학생 그룹 목록 전체가 들어 있다는 것**을 확인했다.

---

### 4차 시도 — `for`문을 중첩해서 더 안쪽으로 내려가기

```python
for school, (dep_stu) in sch_else:
    for department, (student_score) in dep_stu:
        for name, score in students_scores:
            print(f"[{school}] {department} - {name}: {score}점")
```

`for in`의 범위를 큰 것에서 작은 것으로 꺼내면서 안쪽 구조까지 내려가려고 했다.

---

### 5차 시도 — 중첩 `zip()`과 `*` 언패킹

```python
for school, (department, (name, score)) in list(zip(schools, list(zip(departments, students_scores)))):
    for (department, (name, score)) in list(zip(departments, students_scores)):
        for (name, score) in students_scores:
            print(f"[{school}] 분기점 {department} 가시화 - {name}: 하는거 {score}점")
```

이후 `*` 언패킹 연산자를 이용해서도 시도했다.

```python
from typing import Unpack

schools = ["A대학", "B대학"]
departments = [["컴공과", "기계과"], ["전자과", "화공과"]]
students_scores = [
    [[("김철수", 85), ("이영희", 92)], [("박민수", 78), ("정지은", 90)]],
    [[("오민석", 88), ("한지민", 95)], [("강호동", 65), ("유재석", 99)]]
]

unpa_stu_sco = print(*students_scores)
unpack_again = *unpa_stu_sco
print(list(zip(*departments, *students_scores)))

for school, (department, (name, score)) in zip(schools, zip(*departments, *students_scores)):
    print(f"[{school}] {department} - {name}: {score}점")
```

이 과정에서 `*`를 이용해 데이터를 한 번에 펼쳐 묶는 방식으로는 원하는 `(대학, (학과, (이름, 점수)))` 구조가 만들어지지 않았다.

## ToT — 해결 방법을 찾는 과정

### 의문

`sch_else`까지 만들었는데도 왜

```python
for school, (department, (name, score)) in sch_else:
```

형태로 바로 언패킹되지 않는지 고민했다.

### 탐색 방향

* `zip()`을 단계별로 중첩해서 데이터를 묶어보기
* `for`문을 중첩해서 데이터 구조를 한 단계씩 내려가기
* `enumerate()`로 대학의 인덱스를 가져와 대응되는 데이터를 찾기
* `*` 언패킹 연산자를 `zip()`과 함께 사용해보기

### 후보

* `zip()`으로 `departments`와 `students_scores`를 먼저 묶은 뒤 학교까지 묶기
* 중첩 `for`문을 사용해 대학 → 학과 → 학생 순서로 내려가기
* 리스트 컴프리헨션을 사용해 원하는 3중 튜플 구조를 먼저 만들기

### 비교 및 검토

`zip(departments, students_scores)`만으로는 학과 목록과 학생 그룹 목록이 대응될 뿐이었다.

즉,

```python
["컴공과", "기계과"]
```

와

```python
[
    [("김철수", 85), ("이영희", 92)],
    [("박민수", 78), ("정지은", 90)]
]
```

가 묶인다.

`"컴공과"`와 `("김철수", 85)`가 직접 대응되는 것은 아니므로, 그 안쪽에서 다시 `zip()`과 `for`가 필요했다.

### 판단

해결방법 안내를 통해 `for`, `enumerate`, 리스트 컴프리헨션을 이용해 문제를 해결할 수 있다는 것을 확인했다.

### 결론

원본 데이터를 원하는 구조로 먼저 만들거나, 중첩된 원본 구조를 `for`문으로 단계별로 내려가면서 처리하면 된다.

## 해결 과정

### 방법 1 — 리스트 컴프리헨션으로 3중 구조 만들기

8명의 학생 데이터를 먼저 원하는 형태인

```python
(대학, (학과, (이름, 점수)))
```

구조로 만든다.

```python
schools = ["A대학", "B대학"]
departments = [["컴공과", "기계과"], ["전자과", "화공과"]]
students_scores = [
    [[("김철수", 85), ("이영희", 92)], [("박민수", 78), ("정지은", 90)]],
    [[("오민석", 88), ("한지민", 95)], [("강호동", 65), ("유재석", 99)]]
]

# 1. 8명의 학생 데이터를 3중 튜플 구조로 납작하게 묶어줍니다.
combined_data = [
    (school, (dept, (name, score)))  # 우리가 원하는 3중 껍질 형태
    for school, depts, scores_in_school in zip(schools, departments, students_scores)
    for dept, students_in_dept in zip(depts, scores_in_school)
    for name, score in students_in_dept
]

# 2. 완성된 데이터를 단일 for문에서 3중 언패킹으로 벗겨냅니다!
for school, (department, (name, score)) in combined_data:
    print(f"[{school}] {department} - {name}: {score}점")
```

이렇게 만들어진 `combined_data`의 각 원소는 다음과 같다.

```python
("A대학", ("컴공과", ("김철수", 85)))
("A대학", ("컴공과", ("이영희", 92)))
("A대학", ("기계과", ("박민수", 78)))
("A대학", ("기계과", ("정지은", 90)))
("B대학", ("전자과", ("오민석", 88)))
("B대학", ("전자과", ("한지민", 95)))
("B대학", ("화공과", ("강호동", 65)))
("B대학", ("화공과", ("유재석", 99)))
```

따라서 최종 `for`문에서 실제 데이터 구조와 언패킹 구조가 정확히 대응한다.

```python
for school, (department, (name, score)) in combined_data:
```

### 방법 2 — `enumerate()`와 중첩 `for`

`enumerate()`를 이용해서 학교의 인덱스 `i`를 가져오는 방법도 있다.

```python
schools = ["A대학", "B대학"]
departments = [["컴공과", "기계과"], ["전자과", "화공과"]]
students_scores = [
    [[("김철수", 85), ("이영희", 92)], [("박민수", 78), ("정지은", 90)]],
    [[("오민석", 88), ("한지민", 95)], [("강호동", 65), ("유재석", 99)]]
]

# 1. enumerate로 대학의 인덱스(i)를 가져옵니다.
for i, school in enumerate(schools):
    # i번 대학의 학과들과 학생 데이터들을 꺼냅니다.
    depts = departments[i]
    colleges_students = students_scores[i]

    # 2. 학과와 그 안의 학생 그룹을 다시 zip으로 묶습니다.
    for dept, students in zip(depts, colleges_students):

        # 3. 개별 학생의 이름과 점수를 언패킹합니다.
        for name, score in students:
            print(f"[{school}] {dept} - {name}: {score}점")
```

여기서는 다음 순서로 내려간다.

```text
대학
 ↓
해당 대학의 학과 목록 + 학생 데이터
 ↓
학과 + 해당 학과의 학생 그룹
 ↓
학생
 ↓
이름 + 점수
```

## 핵심 개념

### 1. 언패킹은 실제 데이터 구조와 맞아야 한다

다음과 같은 데이터가 있을 때:

```python
("A대학", ("컴공과", ("김철수", 85)))
```

다음과 같이 언패킹할 수 있다.

```python
school, (department, (name, score)) = (
    "A대학",
    ("컴공과", ("김철수", 85))
)
```

즉,

```text
school
└── department
    └── name, score
```

라는 구조와 변수의 괄호 구조가 일치한다.

반대로 `sch_else`처럼 실제 데이터가

```text
school
└── departments 전체
└── students_scores 전체
```

형태라면

```python
school, (department, (name, score))
```

라고 작성해도 원하는 방식으로 내려가지 않는다.

---

### 2. `zip()`은 같은 단계의 데이터를 대응시킨다

처음 사용한:

```python
zip(departments, students_scores)
```

는

```text
학과 목록 전체 ↔ 학생 그룹 목록 전체
```

를 대응시켰다.

따라서 원하는

```text
학과 하나 ↔ 해당 학과의 학생 그룹
```

을 만들려면 그 안쪽에서 다시:

```python
zip(depts, students_in_school)
```

처럼 한 단계 내려가야 했다.

---

### 3. `enumerate()`는 인덱스를 이용해 대응시킨다

```python
for i, school in enumerate(schools):
```

에서

```text
i      → 인덱스
school → 해당 인덱스의 학교
```

가 된다.

따라서:

```python
departments[i]
students_scores[i]
```

를 통해 같은 인덱스의 대학에 해당하는 데이터를 가져올 수 있다.

---

### 4. 중첩 데이터는 구조를 따라 내려가야 한다

이번 문제에서는 다음 순서로 데이터가 중첩되어 있었다.

```text
학교
 ↓
학과
 ↓
학생
 ↓
이름 / 점수
```

따라서 `for`문으로 직접 순회할 때도:

```python
for school ...
    for dept ...
        for name, score ...
```

처럼 데이터 구조를 따라 내려가게 된다.

하지만 실제 `sch_else`의 각 원소는 내가 원하는

가 아니라,

```python
(

```

형태였다.

그래서 학과 하나와 학생 한 명이 대응되는 구조를 먼저 만들어야 했다.

## 이번 문제에서 얻은 것

이번 문제는 단순히 `*`를 이용한 언패킹 문법을 연습하는 문제가 아니라, **중첩 데이터의 구조를 눈으로 파악하고 그 구조에 맞춰 순회 방법과 언패킹 방법을 결정하는 연습**이었다.

특히 처음에는

```python
for school, (department, (name, score)) in sch_else:
```

처럼 **원본 데이터의 구조를 충분히 변환하지 않은 상태에서 원하는 최종 구조를 바로 언패킹하려고 했던 것**이 핵심적인 막힘이었다.

해결 과정에서는:

```text
원본 데이터
→ zip으로 같은 단계끼리 대응
→ for로 안쪽 구조까지 내려감
→ 필요한 형태의 튜플로 재구성
→ 최종적으로 3중 언패킹
```

이라는 흐름을 사용했다.

**즉, 언패킹을 잘하는 것보다 먼저 "현재 내가 순회하고 있는 데이터 한 덩어리의 실제 구조가 무엇인가?"를 확인하는 것이 중요하다.**





### 오답노트
~~~python
# dep_stu = list(zip(departments,students_scores))
~~~

2. enumerate를 활용한 인덱스 접근 방식
~~~python
schools = ["A대학", "B대학"]
departments = [["컴공과", "기계과"], ["전자과", "화공과"]]
students_scores = [
    [[("김철수", 85), ("이영희", 92)], [("박민수", 78), ("정지은", 90)]],
    [[("오민석", 88), ("한지민", 95)], [("강호동", 65), ("유재석", 99)]]
]

# 1. enumerate로 대학의 인덱스(i)를 가져옵니다.
for i, school in enumerate(schools):
    # i번 대학의 학과들과 학생 데이터들을 꺼냅니다.
    depts = departments[i]
    colleges_students = students_scores[i]
    
    # 2. 학과와 그 안의 학생 그룹을 다시 zip으로 묶습니다.
    for dept, students in zip(depts, colleges_students):
        
        # 3. 개별 학생의 이름과 점수를 언패킹합니다.
        for name, score in students:
            print(f"[{school}] {dept} - {name}: {score}점")
~~~
