### 3.1 프롬프팅 패턴 이해
1. **Zero-shot Prompting (제로샷)**
    - 예시 없이 지시문과 입력 데이터만 제공
    - 핵심 포인트: 명확하고 구체적인 지시어와 출력 형식 지정이 중요
    - 추천 상황: 번역, 요약, 단순 분류 등 모델의 사전 학습 지식으로 해결 가능한 일반적인 과제
    - 단점: 복잡한 작업 명령 시 환각을 일으킬 잠재적 리스크
2. **Few-shot Prompting (퓨샷)**
    - 예시, 지시문, 입력 데이터 제공
    - 핵심 포인트: 예시의 개수(보통 2~5개)와 패턴의 일관성이 출력 품질을 좌우
    - 추천 상황: 정형화된 JSON 형태 출력, 브랜드 고유의 톤앤매너 유지, 복잡한 분류 기준 적용 과제
    - 단점: 제공된 예시의 편향이나 논리적 오류를 그대로 답습
3. **역할 부여 (Role Prompting)**
    - 페르소나 부여
    - 핵심 포인트: 단순한 직업 이름뿐만 아니라 전문성 수준, 중점적인 가치관, 행동 형태를 함께 지정할 때 성능 극대화
    - 추천 상황: 기획서 작성, 전문 자문, 아이디어 스토밍, 특정 페르소나 기반 문서 작성
4. **Zero-shot CoT (Zero-shot Chain-of-Thought)**
    - 예시 없이 지시문과 입력 데이터만 제공
    - `think step by step` 지시문: 추론 유도 문구
    - 핵심 포인트: 예시의 추론 패턴을 AI가 복사하여 문제에 적용하므로 매우 높은 추론 정확도
    - 추천 상황: 복잡한 연산, 다단계 비즈니스 로직 분석, 사고의 가시화가 필요한 작업
5. **Few-shot CoT (Few-shot Chain-of-Thought)**
    - 예시, 지시문, 입력 데이터 제공
    - `think step by step` 지시문 포함
    - 핵심 포인트 및 추천 상황: Zero-shot CoT와 동일
6. **Step-Back Prompting (스텝백 프롬프트)**
    - 문제 해결에 필요한 상위 원리나 기본 개념 우선 정리 후 풀이 진입
    - 핵심 포인트: 세부 사항에 갇혀 발생하는 환각이나 지식 단절 현상을 방지하고, 기초 원리에 기반한 고품질 응답
    - 추천 상황: 과학적/법률적/원리적 원인 규명, 복잡한 정책 또는 시스템 분석

- **프롬프트 5대 요소**
    - Role: 역할
    - Task: 수행 작업
    - Context: 맥락
    - Constraints: 제약
    - Format: 출력 형식

### 1. Numpy: 고속 연산, 슬라이싱 및 차원 제어

#### 1.1 명시적 타입 배열 생성과 다차원 슬라이싱
- **Numpy**: 고속연산, 슬라이싱 및 차원 제어
- **배열** 
    - 메모리상에 연속된 구조, 인덱스 연산자(`[]`) 접근 가능
    - C언어로 개발 (직접 메모리 접근)
    - 비트(bit): 0과 1
    - 바이트(byte): 8bit
    - `dtype`: 자료형 명시 (예: `np.int64`, `np.float64`)
- 1차원 배열 (선): `10 20 30`
- 2차원 배열 (면, 행/열):
    ```text
    10 20 30
    40 50 60
    ```
- **배열 선택, 슬라이싱**
    - `matrix[행, 열]`
    - `matrix[0:2, 1:3]`: 행은 0~1, 열은 1~2
    - `matrix[:, 0]`: 모든 행의 0번째 열
    - `matrix[1:, :2]`: 행의 1번 인덱스부터 전체, 열은 1번 인덱스 이하

~~~python
import numpy as np
nums = np.array([10, 20, 30], dtype=np.float64) # 1차원 벡터
nums

nums[1]
# > np.int64(20)

matrix = np.array([
    [10, 20, 30],
    [40, 50, 60],
    [70, 80, 90]
]) # 2차원 배열 (Matrix)
# 참고로 3차원 이상의 배열(Tensor)
matrix

print("0행 2열:", matrix[0][2], matrix[0,2])
print(matrix[0:2, 1:3])
print(matrix[:, 0])
print(matrix[1:, :2])
~~~ 

#### 1.2 차원 변경(reshape, flatten)과 축(Axis)
- `.reshape(행, 열)`: 1차원 배열을 지정된 행과 열 구조로 차원수 변경 (`-1` 지정 시 자동 결정)
- `arange(시작, 종료, 증감단위)`: 시작 이상 종료 미만으로 숫자 생성
- `.flatten()`: 2차원 배열을 1차원으로 평탄화

~~~python
arr = np.arange(1, 13) # 1~12
# mat_3x4=arr.reshape(3,4)
# mat_3x4=arr.reshape(3,-1)
mat_3x4 = arr.reshape(-1, 4)
print(mat_3x4)

flat_arr = mat_3x4.flatten()
print(flat_arr)
~~~

- **축 (axis)**
    - 2차원 배열에서 연산의 방향을 설정
    - `axis=0`: 행 기준 연산
    - `axis=1`: 열 기준 연산

| 코드 | 계산 방향 | 사라지는 축 | 결과 |
|---|---|---|---|
| `axis=0` | ↓ 세로 | 행 | 열별 합 |
| `axis=1` | → 가로 | 열 | 행별 합 |

~~~python
mat = np.arange(1, 7).reshape(2, -1)
print(mat)
sum_axis0 = mat.sum(axis=0)
sum_axis1 = mat.sum(axis=1)
print("행 기준 합계:", sum_axis0)
print("열 기준 합계:", sum_axis1)
~~~

#### 1.3 Numpy 브로드캐스팅(Broadcasting) 연산

~~~python

    [10, 20, 30],
~~~

#### 1.4 행렬 전치(Transpose) 및 행렬곱(@)
- `객체.transpose()` 또는 `객체.T`: (행, 열) → (열, 행) 전치
- `@`: 행렬 곱 연산

~~~python
mat = np.array([
    [1, 2, 3],
    [4, 5, 6]
])
print(mat)
# print("전치 행렬:\n" ,mat.transpose())
print("전치 행렬:\n", mat.T)
print("행렬 곱 연산:\n", mat @ mat.T)
~~~

* 축(axis)
    2차원 배열에서 연산의 방행을 설정
    - axis : 0 - 행 기준 연산
    - axis : 1 - 열 기준 연산

| 코드       | 계산 방향 | 사라지는 축 | 결과                     |
| -------- | ----- | ------ | ---------------------- |
| `axis=0` | ↓ 세로  | 행      | `[5, 7, 9]` = **열별 합** |
| `axis=1` | → 가로  | 열      | `[6, 15]` = **행별 합**   |


    ~~~python
    mat = np.arange(1,7).reshape(2,-1)
    print(mat)
    sum_axis0 = mat.sum(axis=0)
    sum_axis1 = mat.sum(axis=1)
    print("행 기준 합계:", sum_axis0)
    print("열 기준 합계:", sum_axis1)
    ~~~
