### 4장 머신러닝

#### 2.1 선형 회귀 모델과 오차 평가지표

**1. 선형 회귀(Linear Regression)와 오차(Error)**

- 원인과 결과 사이에 비례하는 규칙 가정
- 가장 잘 나타내는 직선 그리기

1. `y = wx + b`
   - y : 예측값
   - x : 입력값
   - w : 가중치
   - b : 절편/편향

2. **오차(Error)와 손실함수(Loss Function)**
   - 오차 : 직선과 실제값들의 차이
   - Loss : 오차의 대표값(손실)
     - 모든 오차를 더하는 방법 : 음수와 양수가 함께 있어서 상쇄됨
     - 대표값을 구하는 공식 (Loss Function)

   1. **MSE (Mean Squared Error) 평균 제곱 오차**

      $$
      MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
      $$

      - 각각의 오차를 제곱한 뒤 평균을 낸 값.
      - 제곱 → 이상치에 가중 페널티(제곱 비례) → 큰 실수 방지/패널티 부여 (이상치에 민감)

   2. **MAE (Mean Absolute Error) 평균 절대 오차**

      $$
      MAE = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|
      $$

      - 각각의 오차 절대값을 평균낸 값.
      - 절대값 → 오차 크기대로 선형 페널티(1:1 비례) → 데이터의 전반적인 중앙 경향성을 안정적으로 학습 (이상치에 둔감)
      - 오차 크기와 무관한 고정 기울기 ±1 → 최적점 근처 진동(Overshooting, 수렴 X) 현상

**MSE와 MAE 손실 함수 비교**

![lossvalue_error.png](../../images/lossvalue_error.png)

**그래프를 통해 알 수 있는 주요 차이점**

- **이상치(Outlier) 민감도 ($|e| > 1$ 영역)**
  - **MSE**: 제곱 페널티($e^2$)로 급격히 증가 → 큰 오차를 극도로 억제 (이상치에 민감)
  - **MAE**: 선형 페널티($|e|$)로 일정하게 증가 → 데이터 왜곡 방지 및 안정성 확보 (이상치에 둔감/강건)
- **소수점 오차 반응 ($|e| < 1$ 영역)**
  - **MSE**: 제곱 시 원래 오차보다 감소 ($0.5 \rightarrow 0.25$) → 정답 근처에서 부드럽게 감속 및 수렴
  - **MAE**: 오차 크기 그대로 정직하게 반영 ($0.5 \rightarrow 0.5$)
- **미분 가능성 (최적화 관점)**
  - **MSE**: 모든 구간이 매끄러운 곡선 → 전 구간 미분 가능, 경사하강법으로 안정적 수렴
  - **MAE**: 오차 $0$ 지점이 뾰족한 V자 형태 → 미분 불가능(불연속), 최적점 근처에서 진동(Overshooting) 발생 가능

#### 2.2 경사하강법, 옵티마이저 및 데이터 분할

**1. 머신러닝의 내비게이션: 경사하강법 (Gradient Descent)**

- **최적화 (Optimization)**: 가장 오차가 적은 완벽한 정답을 도출하는 매개변수를 찾는 과정
- **비용 함수(Cost Function)**: 예측값과 실제값 사이의 차이(오차)를 수치화한 함수. 이 값이 0에 가까워질수록 모델이 똑똑해진다는 뜻

손실(Loss) ↑ → 가중치 조절 (w, b) → 학습 → 손실 Loop

1. Loss(손실)값을 최대한 줄여서 예측의 정확도 ↑
2. 학습의 목적은 Loss 값의 최저로 갈 수 있는 최적의 가중치(w)와 절편(b)를 결정

w, b → 모델 파라미터 (모델이 학습을 통해서 결정한 값)

**미분(기울기)을 통한 최적 가중치 도달 원리: 경사하강법**

- **기울기 음수 ($\frac{\partial J}{\partial w} < 0$)**: 내리막길 → $w$를 **증가**시켜 전진
- **기울기 양수 ($\frac{\partial J}{\partial w} > 0$)**: 오르막길 → $w$를 **감소**시켜 후진
- **기울기 0 ($\frac{\partial J}{\partial w} = 0$)**: 골짜기 최저점 도달 → **최적 가중치(Optimal $w$) 도달 및 학습 완료**

**가중치 업데이트 공식 (Weight Update Rule, Optimizer)**

손실 함수 $J$를 최소화하기 위해 현재 가중치($w_{old}$)에서 손실의 기울기 반대 방향으로 이동하여 새로운 가중치($w_{new}$)를 결정합니다.

$$
w_{new} = w_{old} \underbrace{-\quad \alpha}_{\text{반대 방향으로 적절한 보폭}} \cdot \underbrace{\frac{\partial J}{\partial w}}_{\text{오차의 변화율(기울기, 역전파)}}
$$

- **$w_{new}$ / $w_{old}$**: 업데이트 후 / 업데이트 전 가중치
- **$\alpha$ (Learning Rate, 학습률)**: 한 번에 이동할 보폭(Step size)의 크기
- **$\frac{\partial J}{\partial w}$ (Gradient, 기울기)**: 가중치($w$)에 대한 손실값($J$)의 편미분값 (역전파(Backpropagation)를 통해 계산)
- **방향 제시**: 기울기가 양수면 $w$ 감소, 음수면 $w$ 증가 방향으로 이동
- **거리 조절**: 최적점에서 멀수록(가파를수록) 크게, 가까울수록(완만할수록) 작게 수정

**구성 요소 상세 분석**

- **편미분 기호 ($\partial$, Round D)**: 다른 변수(편향 $b$ 등)를 고정하고, 오직 가중치($w$) 하나의 변화가 전체 손실($J$)에 미치는 영향만을 분리해 측정
- **마이너스 부호 ($-$)의 필요성**: 기울기($\frac{\partial J}{\partial w}$) 자체는 오차가 '증가'하는 방향을 가리키므로, 오차를 줄이기 위해 반대 방향(골짜기 바닥)으로 뒤집어주는 역할
- **학습률 ($\alpha$, Learning Rate) 설정의 중요성**:
  - **$\alpha$가 너무 큰 경우**: 보폭이 너무 커 최적점을 지나치거나(Overshooting), 오차가 폭증하며 발산($\infty$) 위험
  - **$\alpha$가 너무 작은 경우**: 보폭이 너무 작아 학습 시간이 지나치게 길어지며, 얕은 웅덩이(Local Minimum)에 갇힐 위험

> **핵심 요약**: 역전파(Backpropagation)로 각 가중치의 오차 기여도($\frac{\partial J}{\partial w}$)를 역산해 내면, 옵티마이저(Optimizer)가 방향($-$)과 보폭($\alpha$)을 조절하여 최적 가중치로 갱신합니다.

**주요 옵티마이저(Optimizer) 핵심 요약**

- **SGD (확률적 경사하강법, Stochastic Gradient Descent)**
  - 무작위로 추출한 일부 데이터(샘플/미니배치)로 빠르게 기울기를 계산하여 가중치를 갱신하는 기본 방식
  - 연산 속도가 빠르고 가볍지만, 경로가 지그재그로 요동치며 최적점 근처에서 정확히 멈추지 못하고 **미세하게 진동(Oscillation)하며 수렴이 불안정**함
- **MGD (모멘텀 경사하강법, Momentum Gradient Descent) → [방향/속도 조절]**
  - **과거 이동 방향과 속도(관성)**를 누적 반영하여 최적점을 향해 가속도를 붙이는 방식
  - 가파른 비탈길(골짜기 지형)에서 좌우로 흔들리는 불필요한 진동을 상쇄해 직진성을 높이고, 기울기가 0인 가짜 최저점(Local Minimum, 얕은 웅덩이)을 **달려오던 관성의 힘으로 돌파**
- **RMSprop (적응형 학습률, Root Mean Square Propagation) → [보폭 조절]**
  - 최근 기울기 변화량을 추적하여 **각 가중치마다 보폭(학습률)을 상황에 맞게 자동 조절**
  - 가파른 구간(오차 급변)에서는 보폭을 줄여 진동과 튕겨 나감을 방지하고, 완만한 구간(오차 정체)에서는 보폭을 넓혀 빠르게 탈출
- **Adam (Adaptive Moment Estimation) → [방향 + 보폭 완성형]**
  - **MGD의 관성(방향/가속도)** & **RMSprop의 보폭 조절(적응형 학습률)** 장점을 결합한 완성형 알고리즘
  - 방향성(직진력)과 유연한 보폭을 모두 챙겨 대부분의 딥러닝/머신러닝 분야에서 가장 널리 쓰이는 표준(Default) 옵티마이저

**2. 지역 최솟값(Local Minimum)의 함정**

- **볼록 함수 (Convex Function)**: 밥그릇처럼 매끄럽게 파인 지형으로, 최저점(Global Minimum)이 단 하나뿐이라 경사하강법으로 무조건 최적해를 찾을 수 있는 이상적인 형태
- **비볼록 함수 (Non-convex Function)**: 실제 현실의 손실 지형으로, 수많은 봉우리와 얕은 웅덩이(Local Minimum)가 얽혀 있어 기본 경사하강법이 가짜 최저점에 갇히기 쉬움
  - **해결책**: 무작위 샘플링으로 진동을 주며 탈출하는 **SGD**나, 속도 에너지를 활용하는 **MGD(관성)** 등 고도화된 옵티마이저를 활용

**2. 모델의 보폭 조절과 오버슈팅 (Overshooting)**

**학습률(Learning Rate)의 딜레마**
목적지에 빨리 도달하려고 보폭을 너무 크게 잡으면 계곡을 넘어 튕겨 나가고, 너무 좁게 걸으면 제시간에 바닥에 도달하지 못합니다.

**2.1 학습률($\alpha$) 설정에 따른 결과 비교**
학습률($\alpha$)은 옵티마이저가 한 번에 이동할 **보폭의 크기**를 결정하는 핵심 하이퍼파라미터입니다.

| 보폭 상태 | 발생하는 문제 | 설명 |
| :--- | :--- | :--- |
| **보폭이 너무 큼** | **오버슈팅 (Overshooting)** | 계곡 바닥을 지나쳐 반대편 벽으로 튕겨 나갑니다. 오차가 줄어들지 않고 폭발적으로 증가(발산)하여 학습이 붕괴됩니다. |
| **보폭이 너무 작음** | **언더슈팅 (Undershooting)** | 지나치게 좁은 보폭으로 이동하여 학습 속도가 극도로 느려지며, 최적점에 닿기 전 얕은 웅덩이에 갇히거나 정체됩니다. |
| **적절한 보폭** | **안정적 수렴 (Convergence)** | 적절한 속도로 하강하다가, 최적점에 가까워질수록 오차를 정밀하게 조율하여 안정적으로 최저점에 도달합니다. |

**2.2 모델 파라미터 vs 하이퍼파라미터**

- **모델 파라미터 (Model Parameter)**
  - 모델이 데이터 학습 과정을 통해 **스스로 갱신하고 최적값을 찾아가는 변수**
  - 예시: 가중치($w$), 편향($b$)
- **하이퍼파라미터 (Hyperparameter)**
  - 학습 시작 전 **사람(엔지니어)이 직접 수동으로 설정해야 하는 조율 변수**
  - 예시: 학습률($\alpha$), 학습 횟수(Epochs), 배치 크기(Batch Size)

## 찾아본 내용

### 의문
- 큰 오차(큰 이상치)에는 큰 패널티로 처리하는 MSE는 이상치에 휘둘린다.
- 반면 작은 오차(노멀한 에러)에는 작게 처리하는 MAE는 작은 범위에서 오버슈팅(진동? 요동?)이 일어난다는 점이 헷갈림. 
- "아 골치아프네. 큰 이상치에 안 휘둘리고 작은 오차에는 부드럽게 처리되는 모델이 없나? 휴버 손실 함수(Smooth L1)가 그것인지?"
- "MAE로 큰 이상치를 처리하고 방지하는 것이 학습 모델에 무조건 더 좋지 않은가?"

### 탐색 방향
- 작은 오차에서 MSE와 MAE가 실제로 어떻게 반응하는지 재확인.
- 오버슈팅/진동이라는 표현의 정확한 학술 용어 검증.
- 휴버 손실(Smooth L1)이 MSE와 MAE의 장점을 결합한 대안이 되는지 확인.
- 이상치를 다룰 때 무조건 MAE가 좋은 것인지, 아니면 상황에 따라 다른지 비교.

### 비교 및 검토
1. **작은 오차의 처리 (MSE vs MAE)**
   - "작은 오차에는 작게 처리? MAE" → **[수정]** 
   - 작은 오차($|e| < 1$)에서 손실을 더 작게 깎아주는 것은 **MSE**($0.5 \rightarrow 0.25$)입니다.
   - MAE는 작은 오차든 큰 오차든 1:1로만 정직하게 반영합니다.

2. **오버슈팅 (Overshooting) 용어 정리**
   - 학술/기술 용어로는 **오버슈팅(Overshooting)**, **진동(Oscillation)** 둘 다 표준 표현입니다.
   - "최적점 근처에서 수렴하지 못하고 좌우로 진동(Overshooting) 발생"이라고 적는 것이 가장 명확합니다.

3. **이상치 처리에 대한 관점 차이 (MAE 만능설의 오류)**
   - **이상치가 단순한 '노이즈/오류 데이터'일 때**: MAE가 좋습니다. 엉뚱한 값 하나 때문에 멀쩡한 전체 규칙(직선)이 뒤틀리는 것을 막아줍니다.
   - **이상치가 '절대 놓쳐선 안 될 치명적 사고(예: 자율주행 충돌, 금융 대형 사고)'일 때**: MSE가 필수적입니다. 대형 실수를 내면 모델이 극단적인 페널티를 받아 그런 오차를 아예 피하도록 훈련해야 하기 때문입니다.

### 판단 (손실 함수 선택 기준)
- **MSE 사용 권장**:
  - 데이터에 이상치(노이즈)가 적고 정규분포에 가까울 때
  - 자잘한 오차보다 치명적인 대형 실수를 강력히 억제해야 할 때
  - 최적점 근처에서 안정적이고 빠른 수렴이 필요할 때
- **MAE 사용 권장**:
  - 데이터에 튀는 값(이상치)이나 노이즈가 많을 때
  - 이상치에 모델 전체가 왜곡되는 것을 방지하고 중앙 경향성을 유지해야 할 때
- **Huber Loss (Smooth L1)**:
  - 오차가 작을 땐 MSE(미분 가능, 부드러운 수렴)로 처리하고, 클 땐 MAE(선형 증가, 이상치 무시)를 적용하여 두 함수의 장점 결합.

### 결론
큰 이상치에 휘둘리지 않고 작은 오차에는 부드럽게 수렴하는 모델에 대한 해답은 **Huber Loss (Smooth L1)**가 맞습니다. 손실 함수는 무조건 하나가 좋은 것이 아니라 해결하려는 문제의 성격(이상치가 노이즈인가, 치명적 실수인가)에 따라 달라져야 합니다.

## 핵심 개념

- **선형 회귀** : 원인과 결과 사이에 비례하는 규칙을 가정하고 가장 잘 나타내는 직선을 찾음 ($y = wx + b$)
- **MSE (평균 제곱 오차)** : 이상치에 민감, 모든 구간 미분 가능, 안정적 수렴 보장
- **MAE (평균 절대 오차)** : 이상치에 둔감, 금액 단위와 같아 직관적, 최적점 근처에서 진동(Oscillation) 발생 가능
- **경사하강법 (Gradient Descent)** : 오차(Loss)가 작아지는 방향(기울기 음수/양수)으로 가중치를 업데이트하는 최적화 알고리즘
- **가중치 업데이트 공식** : $w_{new} = w_{old} - \alpha \cdot \frac{\partial J}{\partial w}$ (방향과 보폭 조절)
- **학습률 ($\alpha$, Learning Rate)** : 최적점을 향해 이동하는 보폭의 크기. 크면 오버슈팅, 작으면 언더슈팅 발생
- **옵티마이저 (Optimizer)** : SGD(기본), MGD(관성/속도), RMSprop(보폭 조절), Adam(방향+보폭 완성형)

### 미분(Differentiation)의 직관적 의미
"현재 위치에서 어느 방향으로, 얼마나 가파르게 움직이고 있는가?"를 찾아내는 도구이며, 그래프에서는 특정 점에 가져다 댄 '접선의 기울기'로 나타납니다.
- **미분값(기울기)이 음수**: 내리막길 → 오른쪽(양의 방향)으로 전진
- **미분값(기울기)이 양수**: 오르막길 → 왼쪽(음의 방향)으로 후진
- **미분값(기울기)이 0**: 골짜기 최저점(최적의 정답) 도달, 학습 완료

### 개념 확인 및 용어 사전

- **MAE의 장점**: "평균적으로 집값을 2천 달러 정도 틀립니다"처럼 결과값의 단위가 실제 데이터(금액) 단위와 동일하여 실무 보고에 매우 직관적이고 유리합니다.
- **특성 (Feature)**: 예측을 하기 위해 사용하는 힌트 데이터 (예: 방의 면적)
- **타겟 (Target)**: 우리가 최종적으로 맞추고자 하는 정답 데이터 (예: 집값)

## 오늘의 학습
### 4장 머신러닝
#### 2.1 선형 회귀 모델과 오차 평가지표
1. **선형 회귀(Linear Regression)**와 오차**(Error)**
    - 원인과 결과 사이에 비례하는 규칙 가정
    - 가장 잘 나타내는 직선 그리기
    1. `y = wx+b`
        - y 예측값
        - x 입력값
        - w 가중치
        - b 절편/편향
    2. **오차 (Error)**와 **손실함수 (Loss Function)**
        - 오차 : 직선과 실제값들의 차이
        - Loss - 오차의 대표값 (손실)
            - 모든 오차를 더하는 방법
                : 음수와 양수가 함께 있어서 상쇄
            - 대표값을 구하는 공식 (Loss Function)  
                1. **`MSE (Mean Squared Error) 평균 제곱 오차`**

                $$
                MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
                $$

                - 각각의 오차를 제곱한 뒤 평균을 낸 값.
                - 제곱 → 이상치에 가중 페널티(제곱 비례) → 큰 실수 방지/패널티 부여 (이상치에 민감)

                2. **`MAE (Mean Absolute Error) 평균 절대 오차`**

                $$
                MAE = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|
                $$

                - 각각의 오차 절대값을 평균낸 값.
                - 절대값 → 오차 크기대로 선형 페널티(1:1 비례) → 데이터의 전반적인 중앙 경향성을 안정적으로 학습 (이상치에 둔감)
                -오차 크기와 무관한 고정 기울기 ±1 → 최적점 근처 진동(Overshooting, 수렴 X) 현상

                <u>MSE와 MAE 손실 함수 비교</u>

                ![lossvalue_error.png](../../images/lossvalue_error.png)

                <u>그래프를 통해 알 수 있는 주요 차이점</u>

                * **이상치(Outlier) 민감도 ($|e| > 1$ 영역)**
                * **MSE**: 제곱 페널티($e^2$)로 급격히 증가 → 큰 오차를 극도로 억제 (이상치에 민감)
                * **MAE**: 선형 페널티($|e|$)로 일정하게 증가 → 데이터 왜곡 방지 및 안정성 확보 (이상치에 둔감/강건)

                * **소수점 오차 반응 ($|e| < 1$ 영역)**
                * **MSE**: 제곱 시 원래 오차보다 감소 ($0.5 → 0.25$) → 정답 근처에서 부드럽게 감속 및 수렴
                * **MAE**: 오차 크기 그대로 정직하게 반영 ($0.5 → 0.5$)

                * **미분 가능성 (최적화 관점)**
                * **MSE**: 모든 구간이 매끄러운 곡선 → 전 구간 미분 가능, 경사하강법으로 안정적 수렴
                * **MAE**: 오차 $0$ 지점이 뾰족한 V자 형태 → 미분 불가능(불연속), 최적점 근처에서 진동(Overshooting) 발생 가능

             


#### 2.2 경사하강법, 옵티마이저 및 데이터 분할
1. 머신러닝의 내비게이션: **`경사하강법 (Gradient Descent)`**  
   - **최적화 (Optimization)**:  가장 오차가 적은 완벽한 정답을 도출하는 매개변수를 찾는 과정
   - **비용 함수(Cost Function)**: 예측값과 실제값 사이의 차이(오차)를 수치화한 함수입니다. 이 값이 0에 가까워질수록 모델이 똑똑해진다는 뜻
  
   손실(Loss) ↑ → 가중치 조절 (w,b) → 학습 → 손실 Loop

   1. Loss(손실)값을 최대한 줄여서 예측의 정확도 ↑
   2. 학습의 목적은 Loss 값의 최저로 갈 수 있는 최적의 가중치(w)와 절편(b)를 결정

   w,b → 모델 파라미터
   모델이 학습을 통해서 결정한 값

   <u>미분(기울기)을 통한 최적 가중치 도달 원리: 경사하강법</u>

   * **기울기 음수 ($\frac{\partial J}{\partial w} < 0$)**: 내리막길 → $w$를 **증가**시켜 전진
   * **기울기 양수 ($\frac{\partial J}{\partial w} > 0$)**: 오르막길 → $w$를 **감소**시켜 후진
   * **기울기 0 ($\frac{\partial J}{\partial w} = 0$)**: 골짜기 최저점 도달 → **최적 가중치(Optimal $w$) 도달 및 학습 완료**



    **<u>가중치 업데이트 공식 (Weight Update Rule, Optimizer)</u>**

    손실 함수 $J$를 최소화하기 위해 현재 가중치($w_{old}$)에서 손실의 기울기 반대 방향으로 이동하여 새로운 가중치($w_{new}$)를 결정합니다.

    $$w_{new} = w_{old} \underbrace{-\quad \alpha}_{\text{반대 방향으로 적절한 보폭}} \cdot \underbrace{\frac{\partial J}{\partial w}}_{\text{오차의 변화율(기울기, 역전파)}}$$

    * **$w_{new}$ / $w_{old}$**: 업데이트 후 / 업데이트 전 가중치
    * **$\alpha$ (Learning Rate, 학습률)**: 한 번에 이동할 보폭(Step size)의 크기
    * **$\frac{\partial J}{\partial w}$ (Gradient, 기울기)**: 가중치($w$)에 대한 손실값($J$)의 편미분값 (역전파(Backpropagation)를 통해 계산)
    * **방향 제시**: 기울기가 양수면 $w$ 감소, 음수면 $w$ 증가 방향으로 이동
    * **거리 조절**: 최적점에서 멀수록(가파를수록) 크게, 가까울수록(완만할수록) 작게 수정

    ---

    **구성 요소 상세 분석**

    * **편미분 기호 ($\partial$, Round D)**
      * 다른 변수(편향 $b$ 등)를 고정하고, 오직 가중치($w$) 하나의 변화가 전체 손실($J$)에 미치는 영향만을 분리해 측정

    * **마이너스 부호 ($-$)의 필요성**
      * 기울기($\frac{\partial J}{\partial w}$) 자체는 오차가 '증가'하는 방향을 가리키므로, 오차를 줄이기 위해 반대 방향(골짜기 바닥)으로 뒤집어주는 역할

    * **학습률 ($\alpha$, Learning Rate) 설정의 중요성**
      * **$\alpha$가 너무 큰 경우**: 보폭이 너무 커 최적점을 지나치거나(Overshooting), 오차가 폭증하며 발산($\infty$) 위험
      * **$\alpha$가 너무 작은 경우**: 보폭이 너무 잘아 학습 시간이 지나치게 길어지며, 얕은 웅덩이(Local Minimum)에 갇힐 위험

    **핵심 요약**: 역전파(Backpropagation)로 각 가중치의 오차 기여도($\frac{\partial J}{\partial w}$)를 역산해 내면, 옵티마이저(Optimizer)가 방향($-$)과 보폭($\alpha$)을 조절하여 최적 가중치로 갱신합니다.

    ---

    **<u>주요 옵티마이저(Optimizer) 핵심 요약</u>**

    * **SGD (확률적 경사하강법, Stochastic Gradient Descent)**
      * 무작위로 추출한 일부 데이터(샘플/미니배치)로 빠르게 기울기를 계산하여 가중치를 갱신하는 기본 방식
      * 연산 속도가 빠르고 가볍지만, 경로가 지그재그로 요동치며 최적점 근처에서 정확히 멈추지 못하고 **미세하게 진동(Oscillation)하며 수렴이 불안정**함

    * **MGD (모멘텀 경사하강법, Momentum Gradient Descent) → [방향/속도 조절]**
      * **과거 이동 방향과 속도(관성)**를 누적 반영하여 최적점을 향해 가속도를 붙이는 방식
      * 가파른 비탈길(골짜기 지형)에서 좌우로 흔들리는 불필요한 진동을 상쇄해 직진성을 높이고, 기울기가 0인 가짜 최저점(Local Minimum, 얕은 웅덩이)을 **달려오던 관성의 힘으로 돌파**

    * **RMSprop (적응형 학습률, Root Mean Square Propagation) → [보폭 조절]**
      * 최근 기울기 변화량을 추적하여 **각 가중치마다 보폭(학습률)을 상황에 맞게 자동 조절**
      * 가파른 구간(오차 급변)에서는 보폭을 줄여 진동과 튕겨 나감을 방지하고, 완만한 구간(오차 정체)에서는 보폭을 넓혀 빠르게 탈출

    * **Adam (Adaptive Moment Estimation) → [방향 + 보폭 완성형]**
      * **MGD의 관성(방향/가속도)** & **RMSprop의 보폭 조절(적응형 학습률)** 장점을 결합한 완성형 알고리즘
      * 방향성(직진력)과 유연한 보폭을 모두 챙겨 대부분의 딥러닝/머신러닝 분야에서 가장 널리 쓰이는 표준(Default) 옵티마이저
    ---

2. 지역 최솟값(Local Minimum)의 함정

* **볼록 함수 (Convex Function)**: 밥그릇처럼 매끄럽게 파인 지형으로, 최저점(Global Minimum)이 단 하나뿐이라 경사하강법으로 무조건 최적해를 찾을 수 있는 이상적인 형태입니다.
* **비볼록 함수 (Non-convex Function)**: 실제 현실의 손실 지형으로, 수많은 봉우리와 얕은 웅덩이(Local Minimum)가 얽혀 있어 기본 경사하강법이 가짜 최저점에 갇히기 쉽습니다.
  * **해결책**: 무작위 샘플링으로 진동을 주며 탈출하는 **SGD**나, 속도 에너지를 활용하는 **MGD(관성)** 등 고도화된 옵티마이저를 활용합니다.

2. **모델의 보폭 조절과 오버슈팅 (Overshooting)**

 **학습률(Learning Rate)의 딜레마**  
   * 목적지에 빨리 도달하려고 보폭을 너무 크게 잡으면 계곡을 넘어 튕겨 나가고,<br> 너무 좁게 걸으면 제시간에 바닥에 도달하지 못합니다.

2.1 학습률($\alpha$) 설정에 따른 결과 비교

학습률($\alpha$)은 옵티마이저가 한 번에 이동할 **보폭의 크기**를 결정하는 핵심 하이퍼파라미터입니다.

| 보폭 상태 | 발생하는 문제 | 설명 |
| :--- | :--- | :--- |
| **보폭이 너무 큼** | **오버슈팅 (Overshooting)** | 계곡 바닥을 지나쳐 반대편 벽으로 튕겨 나갑니다. 오차가 줄어들지 않고 폭발적으로 증가(발산)하여 학습이 붕괴됩니다. |
| **보폭이 너무 작음** | **언더슈팅 (Undershooting)** | 지나치게 좁은 보폭으로 이동하여 학습 속도가 극도로 느려지며, 최적점에 닿기 전 얕은 웅덩이에 갇히거나 정체됩니다. |
| **적절한 보폭** | **안정적 수렴 (Convergence)** | 적절한 속도로 하강하다가, 최적점에 가까워질수록 오차를 정밀하게 조율하여 안정적으로 최저점에 도달합니다. |

---

2.2 모델 파라미터 vs 하이퍼파라미터

* **모델 파라미터 (Model Parameter)**
  * 모델이 데이터 학습 과정을 통해 **스스로 갱신하고 최적값을 찾아가는 변수**
  * 예시: 가중치($w$), 편향($b$)
* **하이퍼파라미터 (Hyperparameter)**
  * 학습 시작 전 **사람(엔지니어)이 직접 수동으로 설정해야 하는 조율 변수**
  * 예시: 학습률($\alpha$), 학습 횟수(Epochs), 배치 크기(Batch Size)
  * 정해진 정답 공식이 없으므로 실험과 튜닝을 통해 최적의 값을 찾아야 합니다.

## 찾아본 내용
1. 큰 오차(큰 이상치를 말하는 거 겠지?)에 큰 패널티로 이상치 처리 . MSE. 근데 대신 이상치에 휘둘림

    작은 오차(노멀한 에러)에는 작게 처리? MAE. 근데 작은 범위에서 오버슈팅(진동?요동? 정확한 워딩이?) 일어나니까

    아 골치아프네. 큰 이상치에 안 휘둘리고 작은 오차에는 부드럽게 처리되는 모델이 없나? 휴버 손실 함수 smooth l1이라는 거임??

    근데 mae로 큰 이상치 처리하고 방지하는게 학습 모델에 좋지 않음? 

Ans:
* **"작은 오차에는 작게 처리? MAE" → [수정]**
* 작은 오차($\vert{}e\vert{} < 1$)에서 손실을 더 작게 깎아주는 것은 **MSE**($0.5 → 0.25$)입니다.
* MAE는 작은 오차든 큰 오차든 1:1로만 정직하게 반영합니다.


* **"오버슈팅(진동? 요동? 정확한 워딩)" → [정리]**
* 학술/기술 용어로는 **오버슈팅(Overshooting)**, **진동(Oscillation)** 둘 다 표준 표현입니다.
* "최적점 근처에서 수렴하지 못하고 좌우로 진동(Overshooting) 발생"이라고 적으시면 가장 명확합니다.


* **"휴버 손실(Smooth L1)이 그 대안인가?" → [정확함]**
* 작은 오차 구간은 **MSE**(미분 가능, 부드러운 수렴)로 처리하고, 큰 오차 구간은 **MAE**(선형 증가, 이상치 무시)로 전환하는 하이브리드 함수가 맞습니다.


* **"MAE로 큰 이상치를 처리하고 방지하는 게 학습에 더 좋지 않나?" → [관점 차이]**
* **이상치가 단순한 '노이즈/오류 데이터'일 때:** MAE가 좋습니다. 엉뚱한 값 하나 때문에 멀쩡한 전체 규칙(직선)이 뒤틀리는 것을 막아줍니다.
* **이상치가 '절대 놓쳐선 안 될 치명적 사고(예: 자율주행 충돌, 금융 대형 사고)'일 때:** MSE가 필수적입니다. 대형 실수를 내면 모델이 극단적인 페널티를 받아 그런 오차를 아예 피하도록 학습해야 하기 때문입니다.

**손실 함수 선택 기준 (MSE vs MAE)**
- **MSE 사용 권장**:
  - 데이터에 이상치(노이즈)가 적고 정규분포에 가까울 때
  - 자잘한 오차보다 치명적인 대형 실수를 강력히 억제해야 할 때
  - 최적점 근처에서 안정적이고 빠른 수렴이 필요할 때
- **MAE 사용 권장**:
  - 데이터에 튀는 값(이상치)이나 노이즈가 많을 때
  - 이상치에 모델 전체가 왜곡되는 것을 방지하고 중앙 경향성을 유지해야 할 때
- **Huber Loss (Smooth L1)**:
  - 오차가 작을 땐 MSE, 클 땐 MAE를 적용하여 두 함수의 장점 결합
