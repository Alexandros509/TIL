# PA Lv3 OT

PA Lv3 = SA(Solutions Architect)가 매일 하는 판단을 24강으로 나눈 AWS 실습
주 2회 / 12주 / 3–4개월
한 강 1–1.5시간
설명 20분 · 실습 30분 · 정리 10분
기준은 가성비

특강 뼈대 4가지
- 요구: 무엇을 만드는가
- 구성: 어떤 AWS 조각을 붙이는가
- 비용: 얼마가 나오는가
- 운영: 켜고 끄고 감시하고 배포

도착지
정적 파일과 앱 서버 분리
실사용자 있는 개인·소규모 서비스
최소 구성 = 토이·포트폴리오

비용 감
- 서버리스: 안 쓰면 거의 안 나감
- 확장형: 같은 구성 두 AZ / 약 100달러~
- 대규모 EKS: 약 200달러~ / 이 과정 도착지 아님

한 프로젝트여도 웹·앱·백엔드는 레포 분리

## 1 워딩

### 클라우드 기본

| 워딩 | 뜻 |
|---|---|
| AWS | Amazon Web Services / 아마존이 빌려 주는 컴퓨터·저장소·네트워크 |
| 클라우드 | 내 PC가 아니라 데이터센터 컴퓨터를 씀 |
| 리전 | 서버 있는 권역 / 서울 `ap-northeast-2` / 해저케이블·지연 때문에 한국 서비스는 보통 서울 |
| AZ | Availability Zone / 같은 리전 안 전원·건물 분리 구역 / 확장형 = 같은 자원 두 AZ |
| 인스턴스 | 빌린 가상 컴퓨터 한 대 |
| EC2 | Elastic Compute Cloud / 가상 서버 상품 |
| 온디맨드 | 켠 시간만큼 내는 기본 요금 / 실습은 실사용 시간만 켬 |

EC2 고를 때 종류·요금제 많음
기본형 + 실사용만 켜는 쪽이 가성비

### 계정·권한

| 워딩 | 뜻 |
|---|---|
| 루트 계정 | 가입 때 만든 최상위 계정 / 실습에 안 씀 |
| IAM | Identity and Access Management / 누구에게 어떤 권한인지 / 1–4강 |
| 액세스 키 | 프로그램이 AWS에 들어가는 비밀번호 쌍 / GitHub 올리면 과금 사고 |

### 네트워크·도메인·인증서

| 워딩 | 뜻 |
|---|---|
| VPC | Virtual Private Cloud / 계정 안쪽 전용 네트워크 |
| 서브넷 | VPC를 나눈 구역 / 공개·비공개 |
| SG | Security Group / 인스턴스 앞 방화벽 |
| 도메인 | `example.com` / 가비아 등 국내 등록 가능 |
| Route53 | AWS DNS / 도메인 → IP |
| DNS | 이름을 IP로 바꾸는 장부 |
| ALB | Application Load Balancer / 요청을 여러 서버로 나눔 / HTTP·HTTPS 중심 |
| HTTP / HTTPS | 웹 통신 / S = 암호화 / 과정 난이도 상위 |
| ACM | AWS Certificate Manager / HTTPS 인증서 발급·갱신 |
| NAT GW | NAT Gateway / 비공개 서버 출구 / 시간당 약 0.045달러 / 실습 중 제일 비쌈 / 15강에서 만들고 그날 삭제 |
| CDN | 파일을 가까운 위치에 복사 / AWS는 CloudFront |

### 데이터·파일

| 워딩 | 뜻 |
|---|---|
| S3 | Simple Storage Service / 파일 창고 / 넣기·빼기에도 요금 |
| RDS | Relational Database Service / 관리형 DB / 편하지만 EC2 직접 설치보다 비쌈 |
| 정적 파일 | HTML·CSS·JS·이미지 / 계산 없음 / S3 + CDN |
| 앱 서버 | 로그인·API·계산 |

### 서버리스·컨테이너·배포

| 워딩 | 뜻 |
|---|---|
| 서버리스 | 상시 전원 아님 / 요청 있을 때만 실행 |
| Lambda | AWS 서버리스 함수 / 그 람다 맞음 / 잠깐 떴다 사라지는 계산 단위 |
| Docker | 앱+실행 환경을 상자(컨테이너)로 묶음 / 17–18강 핵심 |
| ECS | Elastic Container Service / 도커 상자 여러 대 / 같은 구성 병렬 |
| EKS | Elastic Kubernetes Service / 대규모 / 과정 밖 |
| CI/CD | 코드 올라가면 테스트·배포 이어짐 |
| GitHub Actions | GitHub에서 도는 CI/CD / push 후 배포의 실체 / 19–20강 |
| IaC | Infrastructure as Code / 클릭 대신 코드로 인프라 |
| Terraform | IaC 도구 / 24강 프로젝트 고도화 / 팀·개인 자유 |
| MSA | 기능을 서비스 단위로 쪼개 서버 분리 / AX에서 다시 나옴 |

### 운영·비용

| 워딩 | 뜻 |
|---|---|
| CloudWatch | CPU 사용률·로그·알람 / 수업의 온도·전기세 = 메트릭·요금 가시화 |
| 예산 알림 | 한도 넘으면 메일 / 2강에서 먼저 |
| Graviton | AWS ARM CPU / 저전력 / 같은 성능 대비 요금 낮은 편 / 애플 실리콘과 ARM 결만 같고 같은 칩 아님 |
| 과금 사고 | NAT·ALB·데이터 전송·안 끈 EC2로 청구서 커짐 |

서버리스 = 트래픽 보고 온오프
상시 EC2 = 코어가 실제로 도는 시간만큼 계산
전기·요금 줄이려면 인스턴스 세대와 CPU(Graviton)도 구성에 넣음

## 2 사전 지식

서버는 대체로 리눅스
윈도우는 1998년대 코드가 아직 있는 현장 있음
클라우드 VM 기본은 Ubuntu / Amazon Linux

SSH 들어가서 파일·권한·로그 보는 명령만 먼저
- `pwd` `ls` `ls -la` `cd`
- `mkdir` `rm` `cp` `mv` (`rm -rf` 위험)
- `cat` `less` `tail -f`
- `chmod` `chown`
- `ps` `top`
- `curl`
- `sudo`
- `apt` 또는 `yum`

리눅스 `root` vs 일반 유저 = AWS 루트 vs IAM 사용자

Git 세 층: 작업 폴더 / 커밋 / 원격(GitHub)
- `git clone` `git status` `git diff`
- `git add` `git commit`
- `git push` `git pull`
- `main`에 바로 안 넣음

19강 이후 push = 배포
키·설정 실수 = 비용

AWS 실습 전 그림만
1. 리전 vs AZ
2. 퍼블릭 IP vs 프라이빗 IP
3. 포트 22 / 80 / 443
4. IAM 사용자·역할·정책
5. 요금 = 컴퓨트 + 저장 + 데이터 전송 + 상시 ALB·NAT

## 3 24강 지도

1. 1–4 계정·권한 — IAM
2. 5–8 서버와 도메인 — EC2 Route53 ALB HTTP·HTTPS
3. 9–11 데이터와 파일 — RDS S3
4. 12 서버리스 — Lambda
5. 13–16 배포 네트워크 — CDN VPC / NAT는 잠깐만
6. 17–18 보안과 컨테이너 — SG Docker
7. 19–20 자동 배포 — GitHub Actions
8. 21–24 운영과 코드화 — ECS IaC / 마지막 Terraform 고도화

제일 어려운 3가지 = 곧 목표
- HTTPS 서버
- push 하면 배포
- 코드가 된 인프라

최소 구성
정적 파일 = S3 + CDN
앱 = EC2 또는 Lambda
도메인 + HTTPS
예산 알림

## 4 준비물·과금 습관

- AWS 계정 + 해외 결제 — 1강 전
- 개인 도메인 1개 — 6강 전 / 가비아 가능
- AWS CLI v2 Docker Desktop Git VS Code
- GitHub 계정 — 19강
- Route53 ALB = 도메인·HTTPS 구간
- NAT GW = 15강에서 만들고 그날 삭제

과금 사고 막는 5가지
1. 2강에서 예산 알림부터
2. 실습 끝나면 자원 끄거나 삭제 / 특히 NAT ALB EC2
3. 리전은 서울로 고정
4. 루트 계정으로 작업하지 않음
5. 액세스 키 GitHub에 올리지 않음
