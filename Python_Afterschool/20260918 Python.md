### 정규 표현식이란

- 데이터의 패턴을 표현하는 식
- `import re` — Regular Expression 약자

### 주민번호 마스킹 사례

정규식을 모를 때 (복잡하고 김)

~~~python
data = """
park 800905-1049118
kim  700905-1059119
"""

result = []
for line in data.split("\n"):
    word_result = []
    for word in line.split(" "):
        if len(word) == 14 and word[:6].isdigit() and word[7:].isdigit():
            word = word[:6] + "-" + "*******"
        word_result.append(word)
    result.append(" ".join(word_result))
print("\n".join(result))
~~~

정규식 사용 시 (간결하고 직관적)

~~~python
import re
data = """
park 800905-1049118
kim  700905-1059119
"""

pattern = re.compile(r"(\d{6})-\d{7}")  # \d 정수
print(pattern.sub(r"\g<1>-*******", data))  # \g 그룹 / \g<1> 그룹 1번째
~~~

### 문자 클래스와 단축 표기

**메타문자** — 특별한 의미·기능을 가진 문자

~~~
. ^ $ * + ? {} [] \ | ()
~~~

**2.1 문자 클래스 `[ ]`** — 포함되면 매칭

- `[abc]` : a 또는 b 또는 c
- `[a-z]` : a to z (콤마·공백 없이)
- `[0-9]` : 0 to 9
- `[^0-9]` : 숫자가 아닌 패턴
- `[^a-z]` : 알파벳이 아닌 패턴

단축 표기 (digit / space / word)

| 단축 | 의미 |
| --- | --- |
| `\d` | `[0-9]` |
| `\D` | `[^0-9]` |
| `\s` | 공백 1개 (` `, `\t`, `\n`, `\r`, `\f`) |
| `\S` | 공백이 아닌 문자 1개 |
| `\w` | `[a-zA-Z0-9_]` (단어 문자 1개) |
| `\W` | `[^a-zA-Z0-9_]` |

~~~python
pattern = re.compile("[abc]")
print(pattern.search("a123"))   # a
print(pattern.search("ab123"))  # a
print(pattern.search("def"))    # None

# 비밀번호 체크 — 알파벳 1자 이상?
pattern = re.compile("[a-zA-z]")  # 필기 그대로 (A-z)
m4 = pattern.search("123Aabc456")
print(m4)
# <re.Match object; span=(4, 5), match='a'> — span은 이상·미만 위치

pattern = re.compile("[0-9]")
print(pattern.search("1234AZ56"))

pattern = re.compile("[^0-9]")
print(pattern.search("1234"))

# 휴대전화
pattern = re.compile(r"010-\d\d\d\d-\d\d\d\d")
print(pattern.search("010-1000-1000"))
~~~

### 반복과 Dot · 앵커

**2.2 Dot(`.`)와 반복 (`*`, `+`, `{m,n}`, `?`)**

- 패턴`{n}` : n번 반복
- 패턴`{m,n}` : m번 이상 n번 이하
- 패턴`{m,}` : m번 이상
- 패턴`+` = `{1,}` : 1번 이상 (한 번은 꼭)
- 패턴`*` = `{0,}` : 0번 이상 (없어도 됨)
- 패턴`?` = `{0,1}` : 없거나 1개만
- `.` : 줄 개행(`\n`)을 제외한 모든 문자
- `^패턴` : 패턴으로 시작
- `패턴$` : 패턴으로 끝

~~~python
phone = "016_   345.     1234"
phone2 = "01010010000"
pattern = re.compile(r"01[06]\D*\d{3,4}\D*\d{4}")
print(pattern.search(phone2))

phone3 = "016.3456.1234"
phone4 = "010100010000"
pattern = re.compile(r"01[06]\D?\d{3,4}\D?\d{4}")
print(pattern.search(phone3), pattern.search(phone4))

pattern = re.compile("a.*c")
print(pattern.search("ab1231\nc"))  # \n은 안 됨 → . = 줄 개행 제외

phone3 = "010-0101-0202"
pattern = re.compile(r"^01[06]\D*\d{3,4}\D*\d{4}$")
print(pattern.search(phone3))
# 기괴한 번호가 매칭되던 건 ^,$로 막음
~~~

### re 검색 API (match/search/findall/finditer)

**3.1 문자열 검색 메서드**

- `match()` : 문자열의 **처음부터** 매치되는지 조사
- `search()` : 문자열 **전체**를 검색
- `findall()` : 매치되는 모든 문자열을 **리스트**로 리턴
- `finditer()` : 매치되는 모든 문자열을 match 객체의 **iterator**로 리턴

~~~python
phone = "010-1234-5678"
pattern = re.compile(r"^01[06]\D*\d{3,4}\D*\d{4}$")
m = pattern.match(phone)
print("매칭된 문자열:", m.group())
print("위치:", m.start(), m.end(), m.span())

phone = "010-1234-5678 016-345-1234"
pattern = re.compile(r"01[06]\D*\d{3,4}\D*\d{4}")
print(pattern.search(phone))
print(pattern.findall(phone))

iter = pattern.finditer(phone)
print(next(iter))
print(next(iter))
~~~

모듈 단위 축약

~~~python
m = re.match(r"^01[06]\D*\d{3,4}\D*\d{4}$", "010-1234-4567")
print(m, m.group())
~~~

**3.2 match 객체 메서드** — `group`, `start`, `end`, `span`

### 컴파일 옵션

- `DOTALL` (`S`) : `.`이 `\n`을 포함한 모든 문자와 매치
- `IGNORECASE` (`I`) : 대소문자 구별 없이 매치
- `MULTILINE` (`M`) : `^`, `$`를 각 줄마다 적용

~~~python
pattern = re.compile('a.b', re.S)
print(pattern.match('a\nb'))

pattern = re.compile("[a-z]", re.I)
print(pattern.match('Abc'))

data = """python one
life is too short
python two
you need python
python three"""

# 옵션 미적용 → 첫 줄만
pattern = re.compile(r"^python\s\w+")
print(pattern.findall(data))

# MULTILINE → 각 줄의 처음을 모두 검사
pattern = re.compile(r"^python\s\w+$", re.M)
print(pattern.findall(data))
~~~

### Raw string과 역슬래시

정규식에서 `\section`을 찾을 때 `\s`가 공백으로 인식되는 문제.

~~~python
# "\\s"도 안 됨 / "\\\\s"는 \\\\ 4번이라 번거로움
pattern = re.compile(r"\\section")
print(pattern.match(r"\section"))
~~~

### OR · 단어 경계

**6. 강력한 메타 문자 (문자열 소비 없음)**

- `|` (OR)
- `^` (처음) / `$` (끝)
- `\b` (단어 구분자) / `\B` (단어 구분자가 아님)
  - border = 단어의 경계 — 문장 시작·끝, 앞뒤 공백

~~~python
s1 = "I like an apple. You like a banana"
pattern = re.compile("apple|banana|melon")
print(pattern.findall(s1))

s1 = "no class at all"
s2 = "class one"
s3 = "one class"
s4 = "the declassified ..."

pattern = re.compile(r"\bclass\b")
print(pattern.search(s1))
print(pattern.search(s2))
print(pattern.search(s3))
print(pattern.search(s4))  # declassified → 안 걸림

pattern2 = re.compile(r"\Bclass\B")
print(pattern2.search(s4))  # declassified 안의 class
~~~

### 그루핑과 이름 그룹

특정 부분만 뽑거나 반복을 묶을 때 `()` 사용.

~~~python
s = "ABCABCABC"
pattern = re.compile('(ABC)+')  # ABC가 1번 이상 반복
print(pattern.search(s))
~~~

인덱스로 추출

~~~python
data = """
김철수 010-1000-2000
이희수 010-1020-2040
박영수 010-1030-2030
"""

pattern = re.compile(r"(\S+)\s(\d{3}-\d{4}-\d{4})")
for m in pattern.finditer(data):
    print("매칭된 전체 문자열:", m.group())
    print(f"이름: {m.group(1)}, 전화번호: {m.group(2)}")
~~~

재참조 — 이름 그룹 `(?P<name>...)` / `(?P=name)`

~~~python
data = "one little two little three little indian, one big two big"
pattern = re.compile(r"(?P<word>\b\w+\b)\s\w+\s(?P=word)")
for m in pattern.finditer(data):
    print(m.group())
~~~

~~~python
data = """
김철수 010-1000-2000
이희수 010-1020-2040
박영수 010-1030-2030
"""

pattern = re.compile(r"(?P<name>\S+)\s(?P<phone>\d{3}-\d{4}-\d{4})")
for m in pattern.finditer(data):
    print("매칭된 전체 문자열:", m.group())
    print(f"이름:{m.group('name')}, 전화번호: {m.group('phone')}")
~~~

### 전방 탐색

문자열을 **소비하지 않고**(검색 결과에 넣지 않고) 조건만 판단.

긍정형 전방 탐색 `(?=...)`

~~~python
data = "http://google.com"
pattern = re.compile(r"\w+(?=:)")
m = pattern.search(data)
print(m.group())  # http
~~~

부정형 전방 탐색 `(?!...)` — 필기·교재 모두 제목만 있고 예시 코드 없음.

### sub / subn

정규식과 매치되는 부분을 다른 문자로 변경.

필기·교재에 골격만 있고 `sub`/`subn` 호출·출력 예시는 비어 있음.

- `data = "blue socks and red shoes"`
- 이름 참조 / 번호 참조용 `data = "park 010-1234-1234"`
- 함수 인자 예시:

~~~python
def hexrepl(match):
    value = int(match.group())
    return hex(value)

data = 'Call 65490 for printing, 49152 for user code.'
~~~

(주민번호 마스킹에서 이미 `pattern.sub(r"\g<1>-*******", data)` 사용함)

### Greedy vs Non-Greedy

~~~python
s = '<html><head><title>Title</title>'

# Greedy — 가장 큰 범위
pattern = re.compile("<.+>")
print(pattern.match(s).group())

# Non-Greedy — 최소한의 범위
pattern = re.compile("<.+?>")  # ?의 역할은 확인 필요
print(pattern.match(s).group())
~~~

img `src` 추출

~~~python
tag = """
<img alt="웨일 브라우저 이미지" width="60" height="60" src="https://s.pstatic.net/static/www/mobile/edit/20260915_1095/upload_1789463917736uCItN.png">
"""

pattern = re.compile(r"<img\s.*src=[\"'](.+?)[\"'].*>")
m = pattern.search(tag)
print(m.group(1))
~~~

## 핵심 개념

- 정규식 = 데이터 패턴을 식으로 표현 (`re`)
- 문자 클래스 `[ ]` · 단축 `\d\D\s\S\w\W`
- 반복 `{n}` `{m,n}` `+` `*` `?` / `.`은 `\n` 제외 / `^` `$` 앵커
- `match` 처음부터 · `search` 전체 · `findall` 리스트 · `finditer` iterator
- match 객체: `group` `start` `end` `span`
- 컴파일 옵션: `re.S` `re.I` `re.M`
- raw string `r"..."`로 역슬래시 이스케이프 부담 감소
- `|` OR · `\b`/`\B` 단어 경계
- `()` 그루핑 · `\1`/`(?P=name)` 재참조 · `(?P<name>...)` 이름 그룹
- 전방 탐색 `(?=...)` (소비 없음) · `(?!...)`는 제목만
- `sub`/`subn`으로 치환 (마스킹·참조·함수)
- Greedy `<.+>` vs Non-Greedy `<.+?>`

## 확인이 필요한 사항

⚠ `[a-zA-z]` vs `[a-zA-Z]` — 필기는 `A-z`(소문자 z). `\w` 설명은 `A-Z`. 비밀번호 체크 패턴이 의도한 범위인지 확인.

⚠ `[abc]` 매칭이 `a`만 나오는 것이 short-circuit(앞에서 먼저 매칭)인지 — 필기 메모 그대로 열어 둠.

⚠ Non-Greedy의 `?` — 필기: 「논그리디에서 ?는 무슨 멀로 붙은?」. 반복 `?`(`{0,1}`)와 역할이 다른지 확인.

⚠ 부정형 전방 탐색·후방 탐색·`sub`/`subn` 참조·함수 데모가 필기·교재 모두 비어 있음.

⚠ span 주석 — 출력 `span=(4, 5), match='a'` 옆에 「span(3,4) 3이상 4미만」 설명이 붙어 있음. 반개구간 개념 메모인지, 출력과 숫자 예시가 어긋난 건지 확인.
