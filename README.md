## 📌 룰 및 작성 규칙 (Rules)

1. **매일 작성하기:** 아주 작은 개념이라도 학습한 날에는 반드시 기록을 남긴다.
2. **나만의 언어로 정리하기:** 남의 글을 단순 복사하지 않고, 내가 이해한 방식과 나의 인사이트를 바탕으로 기록한다.
3. **문제와 해결 과정 포함하기:** 에러를 만났다면 어떤 시행착오를 거쳤고 어떻게 해결했는지 반드시 적는다.
4. **미래의 나를 위해 쓰기:** 나중에 다시 읽었을 때 바로 복습할 수 있도록 구조화하여 작성한다.
